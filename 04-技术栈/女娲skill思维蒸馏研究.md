## 一、是什么

**女娲.skill** 是开源的人物思维蒸馏技能——把乔布斯、马斯克、芒格、费曼等顶尖人物的**认知框架**提取成可运行的 AI Skill，让这些"思维顾问"给用户打工。

- 口号："你想蒸馏的下一个员工，何必是同事"
- 灵感来源：同事.skill（把离职同事蒸馏成AI技能，几天破5000星）
- 作者：花叔（AI Native Coder，独立开发者，代表作小猫补光灯 AppStore 付费榜 Top1）
- 许可证：MIT
- 兼容 Runtime：Claude Code、Codex、Cursor、OpenClaw、**Hermes Agent**、CodeBuddy、Workbuddy、Gemini CLI、OpenCode 等 50+（README 明确标注支持 Hermes）

## 二、核心机制

输入一个名字 → 女娲自动完成：

**1. 六路并行采集**（6个 Agent 同时跑，各自存档）
- 著作、播客/访谈、社交媒体、批评者视角、决策记录、人生时间线

**2. 三重验证提炼**（观点要成为心智模型必须全过）
- 跨 2+ 领域出现过（不是随口一说）
- 能推断对新问题的立场（有预测力）
- 不是所有聪明人都会这么想（有排他性）

**3. 构建 Skill**（写入 SKILL.md）
- 3-7 个心智模型 + 5-10 条决策启发式 + 表达DNA + 价值观与反模式 + 诚实边界

**4. 质量验证**
- 拿 3 个此人公开回答过的问题测试，方向一致才通过
- 再用 1 个他没讨论过的问题测试，应表现适度不确定而非斩钉截铁

### 蒸馏的五层认知

| 层次 | 说明 |
|------|------|
| 怎么说话 | 表达DNA——语气、节奏、用词偏好 |
| 怎么想 | 心智模型、认知框架 |
| 怎么判断 | 决策启发式 |
| 什么不做 | 反模式、价值观底线 |
| 知道局限 | 诚实边界（蒸馏不了直觉/捕捉不了突变/只能基于公开信息） |

> 金句："一个不告诉你局限在哪的 Skill，不值得信任。"

## 六、对 Hermes 的适用性评估

1. **技术决策顾问**：用芒格/费曼/马斯克视角分析产品决策
2. **写作启发**：用纳瓦尔/Paul Graham 视角打磨文案
3. **已有 13+ 人物 Skill**：每个独立仓库，MIT 协议可直接用

### ⚠️ 顾虑

1. **仓库新**：Hermes 版是 2026-05 创建，0 星（个人 fork），质量需验证
2. **本质是角色扮演**："思维蒸馏"= 精选语录+认知框架，**不能当事实来源**
3. **对实际开发价值**低于 Spec Kit
