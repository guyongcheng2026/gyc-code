## 二、本轮排查出的三个真问题（勿重复踩）

1. **`waitForEndpoint` 喂错数据结构**（`src/gyccode/tool/browser.ts`）：`/json/version` 返回**对象**，却被按**数组**（`/json` 页面列表）解析。连接已 200 成功却判定"未就绪"并空转到超时。错误消息里的剩余秒数在 throw 时才算，稳定输出 `0s`，把排查方向误导到"浏览器起不来"。**教训：接口形状不匹配时，异常信息必须反映真实状态。**

2. **文件存在 ≠ 可执行**（本机真实故障）：Chrome 版本目录 `150.0.7871.47` 文件数为 0，只剩启动器 stub，启动即报 `side-by-side configuration is incorrect`；同机 Edge 正常。故新增 `locateAll()` + `launchAny()` 逐候选试启动。**推广到任何"按路径挑外部可执行文件"的逻辑（node/git/ffmpeg/ripgrep）。**

3. **prettier 会重排整个 import 区块**：`registry.ts` 本应只有 4 行 diff，prettier 后变成 **477 增 317 删**。已还原重做。**提交前必须 `git diff --numstat` 拦截意外的全文件格式化。**
