## P0 已修复

### 1. run 进程 429 后挂死不退出（"大计划执行一半退出"根因）
- 文件：`src/gyccode/session/retry.ts`
- 根因（双重）：
  1. `RETRY_MAX_DELAY = 2_147_483_647`（约 24.8 天）且 `delay()` 无条件遵循响应头 `retry-after`。opencode 免费模型 429 时返回 `retry-after: 46666`（≈13 小时），`Effect.retry` 直接 sleep 13 小时 → run 永久挂起（实测 150s+ 不退出，重试等待期间无任何日志）。
  2. 放弃重试路径 `Effect.gen` 内 `return Cause.done(...)` 是**成功值**而非调度停止信号，effect 4.0.0-beta.83 的 Schedule 解析为 `Invalid Input: undefined`。
- 修复：
  - `RETRY_ABANDON_AFTER_MS = 300_000`（5 分钟）：`retry-after` 超过视为非瞬时限流（额度耗尽），放弃重试直接报错。
  - `RETRY_MAX_DELAY_WITH_HEADERS = 60_000`（60s）：带 `retry-after` 头时的硬上限，替代原 24.8 天。
  - `Cause.done` 移到 step 函数同步返回（符合官方 `fromStepWithMetadata` 语义）。
  - `MAX_RETRY_ATTEMPTS = 5` 兜底，防止 429/5xx 无限重试。
- 验证：`gyc run "test ping" --model opencode/deepseek-v4-flash-free`（无 key 必 429）**8.2s 退出**，错误清晰显示 `Rate limit exceeded. Please try again later.`；服务端日志链路完整（stream error → process error → disposing instance）。

### 2. 配置文件带 UTF-8 BOM 解析失败
- 文件：`src/gyccode/config/parse.ts`
- 根因：`gyccode.json` 带 BOM（首字符 U+FEFF），jsonc-parser 报 `InvalidSymbol`，`ConfigParse.jsonc` 直接抛异常，配置加载失败。
- 修复：`jsonc()` 入口 `text.replace(/^\uFEFF/, "")` 容错。
- 验证：BOM 文件 `parsed OK model: opencode/deepseek-v4-flash-free`；活配置已去 BOM。
