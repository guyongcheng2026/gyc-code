# 知识库管理规则

## 写入规则

1. 只有当我明确说出「写入知识库」时，才将内容添加到知识库中
2. 所有知识页面统一使用 Markdown 格式
3. 为关键概念添加 [[双向链接]]
4. 严格按照 llm-wiki 的文件结构组织内容

## 检索规则

1. 只有当我明确说出「结合知识库」时，才先检索知识库再回答问题
2. 支持模糊召回——即使我只记得零碎信息也能找到
3. 返回结果需要标注来源笔记和关联链接

## 笔记质量规则

1. 提取核心观点和关键信息，不做逐字搬运
2. 识别重要的实体和概念，自动添加双向链接
3. 生成结构化的层级标题（H2/H3）
4. 保持简洁，每篇笔记聚焦一个主题
5. 在笔记底部注明「相关链接」和「创建日期」
