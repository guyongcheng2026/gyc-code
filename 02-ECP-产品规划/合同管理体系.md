# ECP合同管理体系

> 电子商城合同管理模块产品设计笔记
> 关联：前端原型 06-contract、招投标流程

## 一、业务全景

ECP合同管理覆盖合同全生命周期：

```
合同模板 → 合同起草 → 审批 → 签署 → 履行 → 变更 → 终止/归档
                                        ↓
                                 履约监督（里程碑/付款/交付）
```

### 1.1 合同分类

| 类型 | 说明 | 来源 |
|------|------|------|
| 框架协议 | 年度/长期供货协议 | 招投标结果/谈判 |
| 单次采购合同 | 单笔交易的正式合同 | 采购订单确认后生成 |
| 服务合同 | 技术服务/运维服务 | 招标/单一来源 |
| 保密协议 | 供应商准入时签署 | 供应商入驻流程 |
| 电子交易协议 | 平台注册即同意 | 在线点击生效 |

## 二、核心功能

### 2.1 合同模板

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 合同条款模板库 | 分品类/分场景的标准条款 | P0 |
| 模板变量替换 | {{供应商名称}}、{{合同金额}} 自动填充 | P0 |
| 条款版本管理 | 条款变更历史可追溯 | P1 |
| 合规审查 | 条款自动比对法务要求 | P1 |

### 2.2 合同签署

| 方式 | 适用 | ECP支持度 |
|------|------|----------|
| 电子签章 | 通用合同，效率优先 | ✅ 推荐主推 |
| CA数字证书 | 法律效力要求高的场景 | ⚠️ 需对接CA机构 |
| 纸质签署+扫描 | 过渡期供应商 | ✅ 兼容处理 |

**电子签章集成建议**：对接法大大/e签宝等电子签约平台，标准API即可。

### 2.3 合同履行监督

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 关键里程碑 | 交付/验收/付款节点跟踪 | P0 |
| 到期预警 | 合同到期前30/15/7天提醒 | P0 |
| 履行记录 | 关联的订单/验收/结算记录 | P0 |
| 变更管理 | 合同条款变更→审批→生效 | P1 |
| 终止/续签 | 到期自动续签/终止流程 | P1 |

## 三、合同与ECP其他模块的关联

```
供应商入驻 → 签署框架协议
      ↓
采购寻源 → 招标结果 → 生成采购合同
      ↓
订单执行 → 引用合同条款 → 履约跟踪
      ↓
验收结算 → 对照合同付款条件
      ↓
合同归档 → 评价供应商履约
```

## 四、数据模型

```
contract_id            PK
type                   enum: 框架/单次/服务/NDA/平台
title                  合同名称
supplier_id            FK → 供应商
buyer_id               FK → 采购方组织
total_amount           合同总金额
currency               CNY/USD
effective_date         生效日期
expiry_date            到期日期
status                 enum: 草稿/审批中/已生效/履行中/已终止/已归档
signed_at              签署时间
electronic_seal        电子签章ID
template_id            引用模板ID

contract_clause_id     PK
contract_id            FK
clause_type            条款类型
content                条款内容
version                版本号

contract_milestone_id  PK
contract_id            FK
milestone_type         enum: 交付/付款/验收
planned_date           计划日期
actual_date            实际完成日期
status                 待办/已完成/逾期
```

## 五、分阶段建议

| 阶段 | 功能 | 说明 |
|------|------|------|
| Phase 1 | 合同模板+电子签章+到期预警 | 基于已有合同条款，快速上线 |
| Phase 2 | 履行监督+变更管理+里程碑跟踪 | 对接订单/结算数据 |
| Phase 3 | 智能合同分析+条款合规审查 | AI辅助审查合同条款 |
