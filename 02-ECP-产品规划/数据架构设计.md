## 二、核心主数据（MDM）

### 2.1 物料/商品主数据

| 属性 | 说明 | 来源 |
|------|------|------|
| 物料编码 | 国网统一编码（14位/20位） | MDM主数据平台 |
| 物料描述 | 名称+规格+技术参数 | MDM |
| 物资分类 | 四级分类体系 | 国网物资分类标准 |
| 价格信息 | 含税/不含税/参考价 | 采购成交数据 |
| 技术参数 | 结构化技术参数（键值对） | 供应商填报+AI提取 |

**关键设计要点**：
- 物料编码统一是ECP与ERP顺畅集成的**前提条件**
- 建议ECP建立物资属性模型（类似电商的商品SPU/SKU体系）

### 2.2 供应商主数据

```
供应商ID → 基本信息（注册号/法人/开户行）
         → 资质（ISO/入网许可证/检测报告）
         → 绩效（准时率/合格率/价格指数）
         → 风险（涉诉/失信记录/经营异常）
```

### 2.3 组织主数据

- 采购方：国网省公司/地市公司/直属单位
- 供应商：注册供应商/潜在供应商
- 用户：采购人/审批人/财务/管理员

## 三、业务数据分布

| 业务域 | 核心表 | 存储 | 数据量预估 |
|--------|--------|------|-----------|
| 商品 | 商品目录/价格/库存 | MySQL/PostgreSQL | 亿级SKU |
| 采购订单 | 采购单/订单行项/物流 | MySQL | 月百万级 |
| 招投标 | 标书/报价/评分/中标 | MySQL | 年万级 |
| 供应商 | 供应商/资质/绩效 | MySQL | 十万级 |
| 结算 | 结算单/对账/发票 | MySQL/ClickHouse | 月百万级 |
| 日志 | 操作日志/审计日志 | Elasticsearch | 日千万级 |

## 四、数据治理

### 4.1 数据标准

| 标准项 | 内容 |
|--------|------|
| 编码体系 | 统一物料编码、供应商编码、订单编码 |
| 命名规范 | 数据库表名/字段名/API命名统一 |
| 枚举管理 | 状态/类型等枚举值统一管理 |
| 数据字典 | 主数据属性定义+取值规范 |

### 4.2 数据质量

| 维度 | 监控指标 | 目标值 |
|------|---------|--------|
| 完整性 | 必填字段填充率 | ≥99.5% |
| 准确性 | 物料属性准确率 | ≥98% |
| 一致性 | 跨系统数据一致率 | ≥99.9% |
| 及时性 | 数据同步延迟 | ≤5分钟 |
| 唯一性 | 主数据重复率 | ≤0.1% |

### 4.3 数据安全

| 安全措施 | 说明 |
|---------|------|
| 数据分级 | 公开/内部/敏感/绝密四级 |
| 访问控制 | 按角色/组织的数据权限（行级+列级） |
| 加密存储 | 敏感字段（银行账号/身份证）AES加密 |
| 审计日志 | 所有数据修改操作全量记录 |
| 数据脱敏 | 报表导出自动脱敏 |

## 五、分阶段建设

| 阶段 | 任务 | 产出 |
|------|------|------|
| 1期 | 主数据标准化+业务DB建设 | 物料编码统一、核心交易库 |
| 2期 | 数据仓库+报表体系 | 采购看板、供应商画像 |
| 3期 | 数据中台+实时计算 | ClickHouse实时报表 |
| 4期 | 数据治理工具体系 | 数据质量监控、血缘分析 |
