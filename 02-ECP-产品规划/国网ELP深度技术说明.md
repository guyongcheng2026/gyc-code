# 国网ELP（电力物流服务平台）深度技术说明

> 本文是五E一中心深化系列第四篇，聚焦ELP的技术架构、四共融模式及与ECP的物流协同机制。
> 元信息：创建时间2026-07-20，基于公开技术论文、国网新闻稿及行业知识汇总

## 一、业务架构深度

### 1.1 ELP定位

ELP（Electric Logistics Platform，电力物流服务平台）是国家电网专门为**电力物资物流**打造的专业化平台，解决电力物资运输中的"大件难运、紧急难送、偏远难达"问题。

**核心功能**：
1. **运输管理**：运输计划编制→调度→跟踪→签收，含大件运输方案编制
2. **仓储管理**：区域中心库+周转库+现场库三级仓储体系
3. **配送管理**：最后一公里配送（变电站/施工现场直达）
4. **物流可视化**：运输过程全程可视化（GPS/北斗）

### 1.2 三级仓储体系

| 层级 | 名称 | 功能 | 典型位置 |
|------|------|------|---------|
| **一级** | 区域中心库 | 省级集中存储，覆盖500km半径 | 省会城市 |
| **二级** | 周转库 | 区域性中转配送，覆盖200km半径 | 地级市 |
| **三级** | 现场库 | 施工现场/变电站临时存放 | 项目现场 |

**物资流转**：供应商 → 中心库（质检/暂存）→ 周转库（分拣/配送）→ 现场库（安装前存放）→ 领用安装

### 1.3 业务流程（以变压器运输为例）

```
ECP订单确认发货
  ↓
ELP创建运输计划
  ├─ 运输方案评估（车板/铁路/海运？是否需要运输保险？）
  ├─ 车辆调度（平板车/特种车辆）
  └─ 路径规划（限高限重路段识别/避开施工区域）
  ↓
GPS装车确认（重量/尺寸/捆绑加固拍照）
  ↓
运输过程监控
  ├─ 位置追踪（GPS/北斗，10秒级更新）
  ├─ 状态监控（振动/倾斜/温度传感器）
  ├─ 电子围栏（偏离路线自动告警）
  └─ 预计到货时间动态更新
  ↓
到货与签收
  ├─ 到货确认（GPS+拍照+双人签字）
  ├─ ECP状态更新（物流完成）
  └─ ELP结算（运输费用核算）
```

## 二、技术架构深度

### 2.1 四共融架构（来自公开论文）

ELP基于"四共融"技术架构设计：

| 维度 | 名称 | 说明 |
|------|------|------|
| **第一共融** | 云化中台（中心云+边缘云） | 中心云统一管理，边缘云在区域中心库本地部署，离线可用 |
| **第二共融** | 云边协同 | 边缘节点本地决策（如自动调度算法），云端全局优化 |
| **第三共融** | 营配贯通 | 与营销系统（i国网）和配电系统数据打通，施工领料/配送一体化 |
| **第四共融** | 近远通信 | 近场（蓝牙/NFC/RFID）+ 远场（4G/5G/北斗短报文）异构组网 |

### 2.2 核心技术栈

| 技术领域 | 选型 | 说明 |
|---------|------|------|
| **物流算法** | 自研路径优化引擎 | 考虑限高/限重/限行区域/施工封路的路径规划 |
| **GPS定位** | 北斗+GPS双模 | 高精度定位，支持无信号区的北斗短报文 |
| **车载终端** | 自研智能终端 | 集成GPS/传感器/摄像头/电子围栏 |
| **RFID/条码** | RFID标签+手持PDA | 出入库批量扫描 |
| **仓储管理** | 自研WMS | 支持立体货架/自动分拣/AGV对接 |
| **数据存储** | 时序数据库+GIS数据库 | 轨迹数据、车辆状态时序数据 |

### 2.3 物流跟踪数据流

```
车载终端（每10秒采集）
  ├─ 经纬度（北斗+GPS）
  ├─ 速度/方向
  ├─ 加速度（判断急刹/碰撞）
  ├─ 车门状态（防盗）
  └─ 温湿度（敏感设备）
  ↓
4G/5G → ELP云端 → 数据处理（轨迹拟合/围栏判定）
  ↓
ECP接口 → 采购方可查看实时物流状态
ESC接口 → 供应链运营大屏展示物流态势
```

## 三、应用架构深度

### 3.1 功能模块

| 模块 | 功能 | 用户 |
|------|------|------|
| **运输管理** | 运输计划、调度派车、运单管理、电子回单 | 物流调度员 |
| **仓储管理** | 入库/出库/盘点/转库/报废 | 仓库管理员 |
| **配送管理** | 配送计划、路径优化、签收确认 | 配送员 |
| **物流可视化** | 实时跟踪看板、轨迹回放、异常告警 | 各方用户 |
| **费用结算** | 运费计算、对账、支付 | 财务/物流供应商 |
| **供应商协同** | 发货通知预填、物流服务商管理 | 供应商/物流商 |

### 3.2 与ECP协同的业务场景

| ECP操作 | ELP响应 | 业务价值 |
|---------|---------|---------|
| 供应商发货通知 | 创建运单，调度车辆 | 物流提前准备，减少等待 |
| 到货验收 | 电子回单确认，运费触发 | 物流费用自动结算 |
| 紧急采购 | 优先调度，加急配送 | 急用物资最快到达 |
| 退换货物流 | 逆向物流调度 | 处理流程闭环 |

## 四、对远光ECP的启示

### 4.1 ELP模式的借鉴价值

1. **物流可视化是刚需**：采购方（尤其是工程物资）最关心"货到哪了"，ELP的全程可视化值得远光ECP参考
2. **三级仓储网络**：电力物资仓储体系复杂，远光ECP如果涉及仓配物流，可参考ELP的分级模式
3. **物联网集成**：GPS+传感器的状态监控适合高价值设备

### 4.2 远光ECP可接入的物流能力

```
方案A：自建轻量物流跟踪（推荐起步方案）
  └─ 供应商发货时填写物流单号
  └─ 对接快递100/菜鸟等物流API自动跟踪
  └─ ECP内展示物流轨迹

方案B：对接ELP（如果对接国网体系）
  └─ ECP发货数据推ELP
  └─ ELP物流状态回传ECP

方案C：自建物流模块（适合MRO电商业务）
  └─ 参考ELP的仓储/配送/可视化架构
  └─ 自研WMS+TMS，支持第三方物流对接
```

### 4.3 差异化机会

- **电商化即时配送**：ELP侧重工程大件物资，远光ECP在MRO类物资（办公用品、劳保、低值易耗品）可提供类似京东的次日达/定时达体验
- **物流成本透明**：每种物流方案实时展示运费，让采购方决策时能比较不同运输方案的成本
