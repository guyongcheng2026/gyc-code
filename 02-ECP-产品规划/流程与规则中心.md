# 流程与规则中心

> 对应章节：PPT v6.0 第十三章（P58-P59）

---

## 核心定位

流程与规则中心是 ECP 的「业务大脑」，将传统 ERPs 中固化在代码里的业务规则抽取为可配置的规则引擎，实现业务逻辑与代码解耦。

## 三大能力

### 1. 规则引擎

| 规则类型 | 说明 | 配置途径 |
|---------|------|---------|
| 审批阈值 | 金额/品类分段审批（如>50万需集团审批） | 规则中心界面 |
| 采购限制 | 供应商范围/品类限制/预算上限 | 规则配置 |
| 预算规则 | 年度预算/项目预算/科目预算控制 | 预算模块联动 |
| 合规规则 | 强制招标/询比价/单一来源合规检查 | 监管要求 |

### 2. 流程融合

```
商城流程 → OA审批 → ERP执行
         ↕          ↕
      规则引擎    数据同步
```

ECP 不取代现有 OA/ERP，而是通过流程中心实现跨系统编排：
- 商城发起采购申请 → OA 审批流 → ERP 生成采购订单
- 状态变更通过 Webhook/消息队列实时同步

### 3. 时效管理（SLA）

| 环节 | 时限 | 超期处理 |
|------|:----:|---------|
| 需求审核 | 2工作日 | 超期提醒 |
| 采购审批 | 3工作日 | 自动删单 |
| 供应商发货 | 5工作日 | 记录违约 |
| 收货验收 | 3工作日 | 自动确认 |
| 发票开具 | 10工作日 | 影响信用评分 |
| 对账确认 | 5工作日 | 自动确认 |

## 技术要点

- 规则引擎推荐轻量级实现（Groovy Script / Drools / 自研表达式引擎）
- 流程中心与各微服务通过事件总线解耦
- 规则变更支持灰度发布和版本回溯
