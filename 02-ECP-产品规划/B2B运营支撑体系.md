# B2B运营支撑体系

> 对应章节：PPT v6.0 第十四章（P60-P61）

---

## 定位

B2B 运营支撑体系是区别于传统 B2C 电商的核心差异。ECP 面向央企/国企采购场景，需要提供面向企业级客户的运营管理能力。

## 四大运营支柱

### 1. 促销与激励机制

| 机制 | 说明 | 适用场景 |
|------|------|---------|
| 满减优惠 | 大额采购：满10万减5000 | 集中采购节 |
| 阶梯报价 | 批量采购：数量越多单价越低 | 框架协议执行 |
| 框架协议价 | 长期合作：协议期内固定优惠 | 战略供应商 |
| 新品推广 | 新上架商品：限时折扣 | 商品上线推广 |
| 供应商让利 | 库存清理：限时秒杀 | 尾货/清仓 |

### 2. 售后服务与工单

```
发起 → 响应 → 处理 → 验收
```

- 采购方发起售后工单（退换货/维修/投诉）
- 供应商在规定时限内响应
- 处理完成后需采购方验收确认
- 超时未响应自动升级至平台运营介入

### 3. 数据安全与合规

| 安全维度 | 技术方案 |
|---------|---------|
| 传输加密 | TLS 1.3 |
| 数据加密 | SM2/SM4（国密） |
| 数据脱敏 | 运行时脱敏 + 存储加密 |
| 审计日志 | 登录/操作/数据/权限 四维审计 |

### 4. 运营审计

- 操作审计：谁在什么时间做了什么操作
- 数据审计：关键数据变更轨迹（商品价格、订单状态等）
- 权限审计：角色权限变更记录、越权访问告警
- 定期审计报告：按月/按季度自动生成

## 与B2C运营的区别

| 维度 | B2B（ECP） | B2C（淘宝/京东） |
|------|-----------|-----------------|
| 采购决策 | 多人审批，流程驱动 | 个人决策，冲动消费 |
| 定价方式 | 框架协议/阶梯报价/招标 | 固定价格/促销 |
| 售后服务 | 工单+合同约束 | 退换货政策 |
| 支付方式 | 账期/银企直连/票据 | 在线支付 |
| 合规要求 | 招投标法/审计合规 | 消费者保护法 |
