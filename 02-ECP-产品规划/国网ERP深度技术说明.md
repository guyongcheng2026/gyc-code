# 国网ERP（企业资源计划）深度技术说明

> 本文是五E一中心深化系列第三篇，聚焦国网ERP的技术架构、与ECP的采购到付款闭环、以及与五E中心的协同机制。
> 元信息：创建时间2026-07-20，基于SAP行业知识、已入库的SAP MM笔记及公开信息汇总

## 一、业务架构深度

### 1.1 ERP在国网的定位

国家电网采用 **SAP S/4HANA** 作为核心ERP平台，覆盖**财务、物资、项目、设备、人力资源**五大核心领域。ERP是五E一中心中唯一一个**既管理实物又管理资金**的系统，承担着**业财一体化**的核心角色。

**核心定位**：企业资源统一管理平台，实现"账实相符、业财一体"。

### 1.2 国网ERP核心模块（推断，基于SAP行业标准）

| 模块 | 标准SAP模块 | 国网业务域 | 一级功能 |
|------|------------|-----------|---------|
| **物资管理** | SAP MM | 物资采购、库存、仓储 | 采购申请→采购订单→收货→发票校验 |
| **财务管理** | SAP FI/CO | 会计核算、成本控制、预算管理 | 总账、应收应付、固定资产、项目成本 |
| **项目管理** | SAP PS | 电网建设项目管理 | WBS结构→预算分配→进度→决算 |
| **设备管理** | SAP PM | 设备运行维护 | 设备台帐→检修计划→工单→费用归集 |
| **资产会计** | SAP AA | 固定资产全生命周期 | 资产购置→折旧→转移→报废 |
| **人力资源** | SAP HR | 组织人事/薪酬/考勤 | 员工主数据→组织架构→工资核算 |

### 1.3 核心业务流程：采购到付款（P2P）

```
ECP                 ERP
│                   │
│  合同签署          │
│    ↓               │
│  推送PO到ERP ─────→│  接收PO、生成采购订单
│                   │    └→ 预制会计凭证 (GR/IR)
│                   │
│  供应商发货         │
│  登记物流 ────────→│  仓库收货 (MIGO)
│                   │    └→ 移动类型101入库
│                   │    └→ 库存更新
│                   │
│  到货验收 ────────→│  质量检验 (QM模块)
│                   │    └→ 判定合格/不合格
│                   │
│  供应商开票         │
│  发票提交 ────────→│  发票校验 (MIRO)
│                   │    └→ GR/IR清帐
│                   │    └→ 生成应付账款
│                   │
│                   │  付款执行 (F110)
│                   │    └→ 银行接口
│                   │    └→ 付款给供应商
│                   │
│  付款状态 ←────────│  付款回传
│    └→ 合同执行关闭  │
```

### 1.4 物料管理深度

国网物资管理在SAP MM模块上的特殊应用：

| 业务场景 | SAP MM 功能 | 说明 |
|---------|-------------|------|
| **工程项目物资** | 项目库存（Project Stock） | 物资指定到具体项目WBS，专料专用 |
| **批次管理** | Batch Management | 每批物资可追溯（供应商批次号+收货日期） |
| **寄售库存** | Consignment Stock | 供应商存放但未结算的库存，消耗后结算 |
| **有货采购** | Stock Transport Order | 电网内跨省调用，省间调拔 |
| **紧急采购** | Contract Release | 基于框架协议释放采购订单，简化流程 |
| **强制序列化** | Serial Number management | 关键设备（变压器、开关等）单台跟踪 |

## 二、应用架构深度

### 2.1 系统部署架构

```
SAP S/4HANA (核心ERP)
    │
    ├─ FI/CO ─── 财务管理 (总账/应付/应收/资产/成本)
    ├─ MM ────── 物资管理 (采购/库存/仓储/发票)
    ├─ SD ────── 销售管理 (废旧物资处置/闲置资产调拨)
    ├─ PS ────── 项目管理 (基建/技改/大修项目)
    ├─ PM ────── 设备维护 (巡检/检修/抢修工单)
    └─ QM ────── 质量管理 (来料检验/过程检验)
    
集成外围：
    ├─ ECP ─── 采购合同/订单/发票信息
    ├─ EIP ─── 供应商质量数据参考（不直接存储）
    ├─ ELP ─── 物流状态跟踪（非核心）
    ├─ e物资 ── 移动端库存操作/盘点
    ├─ ESC ─── 供应链运营数据（提供分析源）
    ├─ 财务公司 ── 银企直连支付
    └─ HR系统 ── 组织/人事/考勤
```

### 2.2 关键事务代码（参考SAP行业标准）

| TCode | 功能 | 所属模块 | 使用角色 |

| MIGO | 收货/发货/转储 | MM | 仓库管理员 |
| MIRO | 发票校验 | MM-FI | 财务 |

## 三、技术架构深度

### 3.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **ERP核心** | SAP S/4HANA 1909+ | 部署在国网信通云，HANA内存数据库 |
| **集成平台** | SAP PO/PI | 与ECP等外围系统接口，支持IDoc/RFC/SOAP |
| **身份认证** | 统一身份认证（集成i国网AD域） | 单点登录 |
| **报表** | SAP Fiori + SAC (SAP Analytics Cloud) | Fiori前端，SAC自助分析 |
| **移动端** | SAP Fiori Mobile + i国网 | 移动审批、库存查询 |
| **主数据管理** | SAP MDG (Master Data Governance) | 物料主数据/供应商主数据统一管理 |

### 3.2 与ECP接口方式

| 类型 | 协议/格式 | 说明 |
|------|----------|------|
| PO推送 | RFC/IDoc ORDERS05 | ECP创建订单后实时或批量推送ERP |
| 收货确认 | RFC/IDoc DESADV05 | ERP收货后回传ECP |
| 发票校验 | RFC/IDoc INVOIC02 | ERP过账发票后回传ECP |
| **备选方案** | REST/JSON API（SAP API Management） | 国网可能自研封装层 |

### 3.3 数据集成特点

- **实时性要求**：采购订单需要近实时（分钟级）同步，因为ECP和ERP的数据一致性直接影响履约进度
- **双向确认**：数据推送需ACK确认机制，防止丢单
- **异常处理**：接口异常时两个系统都保留本地记录，人工核对

## 四、与各中心的协同关系

### 4.1 ECP ↔ ERP（核心闭环）

```
ECP（采购方视角）                            ERP（企业资源视角）
┌──────────────────────┐           ┌──────────────────────┐
│  采购需求发布          │           │  物料需求计划 (MRP)  │
│  供应商投标报价        │           │  库存/在途/安全库存   │
│  评标定标             │           │  预算控制             │
│  合同签署 ──PO──→    │           │  采购订单 (ME21N)     │
│  到货验收 ←──收货──    │           │  收货 (MIGO)          │
│  发票确认 ←──发票──    │           │  发票校验 (MIRO)      │
│  付款申请 ←──付款──    │           │  付款执行 (F110)      │
└──────────────────────┘           └──────────────────────┘
```

### 4.2 EIP ↔ ERP

| 场景 | EIP→ERP | ERP→EIP |
|------|---------|---------|
| 质量数据参考 | 出厂试验数据在ERP QM模块可查看 | PO物料信息同步至EIP原材料追踪 |
| 验收协同 | 到货抽检结果回传EIP，与出厂数据对照 | 订单/物料主数据同步 |

### 4.3 e物资 ↔ ERP

| 场景 | 操作 | 说明 |
|------|------|------|
| 移动收货 | e物资扫码 → 触发ERP收货(MIGO) | 仓库人员扫码确认，无需桌面端 |
| 库存盘点 | e物资盘点 → 回传ERP差异调整 | 现场盘点，差异自动过账 |
| 移库操作 | e物资发货 → 触发ERP转储(MT) | 库间调拨，实时更新库存 |

## 五、对远光ECP的启示

### 5.1 ERP集成经验

1. **双向数据校验**：ECP与ERP的PO同步，建议采用"推送+确认"机制，防止数据不一致
2. **GR/IR闭环**：收货与发票校验在ERP完成，ECP只需获取结果状态，无需处理财务细节
3. **物料主数据共享**：ECP与ERP共用物料编码体系，可通过MDM实现一致

### 5.2 差异化机会

1. **云原生ERP集成**：国网SAP较厚重，远光ECP若采用云原生架构，与云ERP（如用友YonSuite、金蝶云星空）集成更轻便
2. **采购到付款全链路可视化**：提供从需求→招标→合同→订单→收货→发票→付款的全流程实时看板
3. **移动端深度融合**：将审批、验收、盘点等操作与微信/钉钉/i国网深度集成

### 5.3 参考集成方案

```
远光ECP ←→ SAP S/4HANA（IDoc/RFC）
           ↓
远光ECP ←→ 用友NC Cloud（REST API）
           ↓
远光ECP ←→ 金蝶云星空（REST/WebService）

建议：设计标准化的集成适配器层，一套ECP对接多种ERP
```
