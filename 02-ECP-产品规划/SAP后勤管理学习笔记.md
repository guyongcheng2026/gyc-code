## 二、各模块知识点详解

### 2.1 MM（Materials Management）物料管理

**MM 是 SAP 后勤的核心模块**，覆盖从物料主数据到采购、库存、发票校验的全链条。

#### 2.1.1 物料主数据（Material Master）

| 概念 | 说明 | ECP 映射 |
|------|------|---------|
| 物料编码 | 全局唯一 18/40 位编码 | ECP `material_code` 字段 |
| 物料类型 | 原材料/半成品/成品/备件/服务 | ECP 商品类型（物资/服务/工程） |
| 视图划分 | 采购视图/库存视图/财务视图/技术视图 | ECP 商品详情多 Tab 展示 |
| 批量管理 | 批次级别（厂牌/生产日期/效期） | ECP 批次追溯模块 |
| 单位转换 | 基本单位 → 采购单位 → 库存单位 | 前端显示单位换算 |

> **ECP 对应**：ECP 商品表 `product` 中的 `material_code` + `category_id` 组合构成物料主数据映射。商品详情中的多 Tab（基本信息/规格参数/库存信息/资质文件/价格信息）对应 MM 的视图划分。

#### 2.1.2 采购管理（Purchasing）

**核心业务流程**：

```
采购申请(PR) → 寻源(Source) → 采购订单(PO) → 收货(GR) → 发票校验(IV)
    ↑                ↑               ↑            ↑           ↓
  需求触发       询比价/招标     订单确认      质检+入库   财务付款
```

| 采购类型 | SAP 单据 | 业务场景 | ECP 对应 |
|---------|---------|---------|---------|
| 标准采购 | PR→PO | 日常采购 | 普通下单流程 |
| 框架协议 | 合同/计划协议 | 长期合作、分批供货 | 框架协议→订单 |
| 寄售采购 | 寄售信息记录 | 供应商管理库存 | 寄售/代销模式 |
| 转储采购 | 库存调拨单 | 内部组织间调拨 | 跨仓调拨 |
| 服务采购 | 服务采购订单 | 工程/咨询服务 | 服务类订单 |

**ECP 规划中的寻源采购（第 5 章）** 完整对应了 SAP 的寻源方式：公开招标、邀请招标、竞争性谈判、询价采购、单一来源、框架协议采购。

#### 2.1.3 库存管理（Inventory Management）

| 库存类型 | SAP 概念 | ECP/WMS 对应 |
|---------|---------|-------------|
| 非限制库存 | 自由可用库存 | 正常库存 |
| 质检库存 | 待检区库存 | 待检库存 |
| 冻结库存 | 不可用库存 | 冻结/锁定库存 |
| 在途库存 | 已发货未收货 | 在途物资 |
| 寄售库存 | 供应商库存存我方 | 代销库存 |

**关键事务**：收货（MIGO）→ 预留/发料（MB1A）→ 转储（MB1B）→ 盘点（MI01/MI04/MI07）→ 库存转移过账

> **ECP 库存分析**：ECP 的库存管理需集成 WMS，实现 5 种库存类型的可视化。当前规划文档中涉及收货入库（WMS）、库存查询、库存预警，建议补全**质检库存**和**冻结库存**的状态管理。

#### 2.1.4 发票校验（Invoice Verification）

- 三单匹配原则：采购订单 × 收货单 × 发票
- 差异处理：数量差异、价格差异、日期差异
- 批准冻结：超出容差范围的发票自动冻结
- ECP 对应：结算环节的**对账功能**（三单匹配 → 自动结算）

### 2.2 SD（Sales and Distribution）销售与分销

#### 核心流程

```
询价(Inquiry) → 报价(Quotation) → 销售订单(SO) → 发货(DN) → 开票(Billing)
```

| 概念 | 说明 | ECP 映射 |
|------|------|---------|
| 客户主数据 | 售达方/送达方/付款方 | ECP 采购方/供应商 |
| 销售组织 | 企业内负责销售的单元 | ECP 各运营组织 |
| 定价过程 | 条件技术（价格+折扣+附加费+税费） | ECP 价格引擎（原价/折扣/服务费/运费/税率） |
| 交货单 | 触发实物物流的单据 | 配送发货单 |
| 装运点 | 实物发运的地点 | ECP 仓库/配送点 |
| 开票计划 | 分期或按里程碑开票 | ECP 结算计划 |

**ECP 下单选购（第 7 章）** 核心对应 SD 的销售订单管理，包括：

- 购物车 → SD 销售订单创建
- 审批流 → SD 订单审批（可配置容差限额）
- 订单拆分 → SD 分批交货（Split Delivery）
- 价格计算 → SD 条件技术（Condition Technique）

### 2.3 PP（Production Planning）生产计划

**适用场景**：非纯贸易型电力物资企业涉及自主生产或委外加工。

| 概念 | 说明 | ECP 关联 |
|------|------|---------|
| BOM（物料清单） | 产品结构树 | 商品组装/套餐配置 |
| 工艺路线 | 工序顺序 | 订单履约流程 |
| MRP（物料需求计划） | 自动生成采购/生产建议 | 补货预警→采购单自动触发 |
| 生产订单 | 生产执行指令 | — |
| 产能评估 | 工作中心负荷计算 | 供应商产能可视化 |

> **本次 ECP 不做生产环节**，但如果有**委外加工**场景（如定制品组装），PP 的委外加工子模块（Subcontracting）可供参考。

### 2.4 QM（Quality Management）质量管理

| 概念 | 说明 | ECP/WMS 对应 |
|------|------|-------------|
| 检验计划 | 检验规范、抽样标准 | 质量验收标准模板 |
| 检验批 | 一次检验的执行单位 | 到货质检批次 |
| 缺陷记录 | 不合格品处理 | 质量不合格流程（退货/换货/让步接收） |
| 质检证书 | 供应商/第三方检测报告 | 资质文件管理 |
| 动态抽样 | 历史质量决定抽检频次 | 供应商预警→抽检频率自动调整 |

**ECP 质量流程建议**：当前规划文档涉及质检但不深入。建议参考 SAP QM 的**检验批+缺陷处理+动态抽样**三位一体模型，将质量数据纳入供应商评价体系。

### 2.5 WM / EWM（仓库管理）

| SAP 概念 | 说明 | ECP WMS 对应 |
|---------|------|-------------|
| 仓位管理 | 库区/货架/层/位编码 | WMS 货位管理 |
| 上架策略 | 就近/固定/随机/分类存储 | 商品推荐上架规则 |
| 拣配策略 | FIFO/FEFO/按批/按供应商 | 出库拣货策略 |
| 盘点方法 | 周期性/连续/抽盘 | 库存盘盈盘亏 |
| 波次管理 | 合并拣货提效 | 配送波次规划 |
| 交叉转运 | 不入库直达出库 | 直发/越库配送 |

**关键区别**：SAP EWM（Extended Warehouse Management）是 WM 的升级版，支持更复杂的仓储自动化（AGV/ASRS）和实时仓库控制。ECP WMS 对标的是 EWM 级别功能。

### 2.6 PM（Plant Maintenance）工厂维护

适用于电力企业设备维修管理：

| 概念 | 说明 |
|------|------|
| 功能位置 | 设备安装位置（如：某某变电站） |
| 设备主记录 | 变压器、开关柜等核心资产 |
| 维护计划 | 定期保养计划（年/季/月） |
| 维护订单 | 检修任务单（含物料+人工+成本） |
| 维修通知单 | 故障报修单 |

> **ECP 关联**：如商城上架**备品备件**（MRO），则需对接 PM 模块的维护计划→备件采购申请自动触发。

### 2.7 LE（Logistics Execution）物流执行

| 概念 | 说明 | ECP 映射 |
|------|------|---------|
| 运输计划 | 装运点、承运商、路线 | 配送调度 |
| 发货单 | 实物出库凭证 | 配送发货单 |
| 装运确认 | 司机签收、货物出运 | 发货确认 |
| 交货证明（POD） | 客户签收回单 | 电子签收 |
| 运费结算 | 承运商运费核算 | 物流费用计算 |

## 四、与 ECP 项目的深度融合分析

### 4.1 ECP 现状 vs SAP 标准（差距分析）

| ECP 环节 | SAP 标准参考 | 现有程度 | 改进空间 |
|---------|-------------|---------|---------|
| 商品类目 | MM 物料分类+视图划分 | ✅ 4级类目已建 | 补充物料类型和属性视图 |
| 寻源采购 | MM 6种寻源方式 | ✅ 已覆盖 | 增加框架协议执行跟踪 |
| 评标定标 | SRM 评标模板 | ✅ 评分弹窗 | 增加供应商澄清交互 |
| 合同管理 | 采购合同+计划协议 | ⚠️ 基本覆盖 | 补充自动续签/变更审批 |
| 订单审批 | SD 审批策略（条件技术） | ⚠️ 有审批流 | 建议按金额+品类组合策略 |
| 仓储库存 | WM/EWM 仓位+上架+拣配 | ⚠️ WMS规划中 | 需细化仓位策略 |
| 质量检验 | QM 检验批+缺陷+动态抽样 | ❌ 未深入 | 建议二期补充 |
| 履约评价 | MM 采购信息记录+供应商评估 | ⚠️ 有评价方案 | 建议用量化评分卡 |
| ERP 集成 | 接口标准（RFC/IDoc/API） | ⚠️ 已规划 | 需定义具体映射表 |

### 4.2 关键设计建议

#### 建议一：框架协议执行跟踪（对标 SAP 计划协议）

SAP 的计划协议（Schedule Agreement）通过**交货计划（Delivery Schedule）**实现框架协议下的分批供货。ECP 可参考：

```
框架协议签订 → 创建交货计划(月度/周)
              → 首批确认(数量+日期)
              → 后续释放(JIT/JIT2)
              → 执行跟踪(累计交货量/合同余额)
```

#### 建议二：条件技术驱动定价（对标 SAP SD Condition Technique）

SAP 的定价条件技术高度灵活，ECP 的**价格引擎**可参考：

```
定价过程 = 条件表(Table) → 访问顺序(Access Sequence) → 条件类型(Condition Type)
                                                                   ↓
折扣阶梯/运费规则/税费规则/服务费规则 → 条件记录维护 → 自动计算
```

#### 建议三：三单匹配+自动结算（对标 MM 发票校验）

```
采购订单(PO) ← 匹配 → 收货单(GR) ← 匹配 → 发票(Invoice)
        差异分析 → 容差检查 → 自动结算 / 手动冻结
```
