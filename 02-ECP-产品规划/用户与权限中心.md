# 用户与权限中心

> 对应章节：PPT v6.0 第十二章（P56-P57）

---

## 五级组织架构

```
集团 → 省公司 → 市公司 → 县公司 → 班组
```

ECP 多租户模式下，组织层级决定了数据隔离范围和数据权限边界。

## 6类账号体系

| 账号类型 | 归属 | 主要用途 |
|---------|------|---------|
| 员工账号 | 采购方 | 日常采购、审批、查询 |
| 供应商账号 | 供应方 | 商品管理、订单处理、对账 |
| 运营账号 | 平台方 | 商品审核、供应商审核、运营管理 |
| 审计账号 | 平台方 | 审计日志、合规检查 |
| 系统账号 | 平台方 | 接口调用、内部服务 |
| 临时账号 | 外部 | 短期访问、紧急采购 |

## 三级权限模型

- **菜单权限**：可见/不可见页面
- **按钮权限**：增/删/改/导/审
- **数据权限**：本组织/下级组织/全部

## 8类角色体系

| 角色 | 权限范围 |
|------|---------|
| 超级管理员 | 运营方-全部权限 |
| 租户管理员 | 央企/国企-本租户全部权限 |
| 采购员/采购经理 | 采购方-采购申请/审批 |
| 供应商/供应商管理员 | 供应方-商品/订单/对账 |
| 审计员 | 运营方-审计日志/合规检查 |
| 运营人员 | 运营方-商品审核/供应商审核 |
| 财务人员 | 对账/结算/发票 |
| 访客 | 公开信息查看 |

## 角色互斥规则

- 采购 ≠ 审批（防止舞弊）
- 财务 ≠ 采购（职责分离）
- 商品上架 ≠ 商品审核（四眼原则）
