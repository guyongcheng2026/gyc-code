## 二、技术架构

**架构模式**: 微服务 + 三中台（业务/技术/数据）+ 云原生

### 四大中心

| 中心 | 英文 | 职能 |
|------|------|------|
| 统一认证中心 | UAC | 用户、权限、组织管理 |
| 计费结算中心 | BRC | 计费、结算、发票、对账 |
| 交易中心 | TC | 商品、订单、支付核心交易 |
| 工作流中心 | WFC | 审批流、业务流程编排 |

### 技术栈
- 前端: Vue3 + Element Plus + TypeScript + Vite
- 后端: Flask → 微服务（Java/Spring Cloud 规划中）
- 数据库: SQLite（原型）/ 生产待定
- 前端原型: 纯CDN引入，无构建工具，主题色 `#0B7266`

## 三、7大业务环节（全链路闭环）

```
① 寻源采购 → ② 上架部署 → ③ 下单选购 → ④ 配送供货 → ⑤ 支付结算 → ⑥ 履约评价 → ⑦ 供应商管理
```

### ① 寻源采购
- 5大类寻源方式（公开招标/邀请/询价/单一来源/框架协议/竞价）
- 评标模型（技术分+商务分+价格分，权重可配置）
- 智能推荐供应商（基于历史采购数据+信用评分）
- 参考: [[01-学习笔记/控制论读书笔记|控制论-反馈闭环]] → 中标数据应反哺寻源策略

### ② 上架部署
- 中标结果→解析→AI辅助分类→审核→发布

### ③ 下单选购 ⭐（一期核心）
- 搜索/分类浏览 → 购物车 → 审批流 → 拆单 → 订单生成
- 搜索架构: 分词+倒排索引+排序规则（含伪代码实现）
- 审批路由: 按金额/部门/品类自动判断

### ④ 配送供货
- 订单全生命周期（待发货→已发货→已收货→已签收）
- 收货验收（数量+质量+匹配采购订单）

### ⑤ 支付结算
- 多支付渠道（电e宝/银企直联/汇票/账期）
- 发票管理 + 对账清分

### ⑥ 履约评价
- 4维评分模型（质量/交付/服务/价格）
- S/D 分级体系，动态调整

### ⑦ 供应商管理 ⭐（一期核心）
- 6步入驻流程（注册→资质→审核→签约→上架→考核）
- 供应商数字化门户（自主维护商品/订单/对账）
- 信用评估模型 + 自动升降级
