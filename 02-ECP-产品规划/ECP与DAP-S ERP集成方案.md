# ECP与DAP-S ERP集成方案

> ECP（电子商城）与 DAP-S（远光新一代ERP）的集成体系设计
> 关联：ECP与ERP区别.md、DAP-S应用架构学习要点.md

## 一、集成定位

ECP与DAP-S是**互补关系**而非替代关系：

| 系统 | 定位 | 负责模块 |
|------|------|---------|
| **ECP** | 交易前台 | 采购寻源、订单、供应商协同、合同、交易结算 |
| **DAP-S** | 管理后台 | 采购计划、预算控制、库存管理、财务核算、人力 |

**核心原则**：ECP管交易，DAP-S管控核。数据单向为主，状态双向同步。

## 二、集成场景全景

```
DAP-S                                    ECP
  采购计划 ──────→  采购需求同步
  预算释放 ←──────  订单确认
  供应商主数据 ──→  供应商同步
  物料主数据 ──→  商品目录同步
  库存视图 ←──────  在途库存
                    采购订单确认 ──→  AP应付暂估
  付款结果 ←──────  结算单同步
  会计凭证 ←──────  交易凭证自动生成
```

## 三、核心集成接口

### 3.1 主数据同步

| 数据 | 方向 | 同步方式 | 说明 |
|------|------|---------|------|
| 供应商主数据 | DAP-S → ECP | 准实时/定时 | 供应商注册/变更/冻结状态同步 |
| 物料/物资目录 | DAP-S → ECP | 准实时 | 统一物料编码、分类、属性 |
| 组织架构 | DAP-S → ECP | 定时 | 采购方组织、部门、人员 |
| 合同数据 | 双向 | 准实时 | 合同审批后同步至ECP执行 |

### 3.2 业务单据流转

| 单据 | 方向 | 内容 |
|------|------|------|
| 采购申请 | DAP-S → ECP | 采购需求→ECP生成订单 |
| 采购订单确认 | ECP → DAP-S | 订单确认后同步ERP生成采购单 |
| 到货验收 | ECP → DAP-S | 收货确认→ERP更新库存 |
| 退货单 | ECP → DAP-S | 逆向物流→ERP库存扣减 |
| 结算单 | ECP → DAP-S | 结算确认→ERP应付账款 |
| 付款结果 | DAP-S → ECP | 付款成功→ECP更新订单状态 |

### 3.3 集成技术选型

| 维度 | 推荐方案 | 备选 |
|------|---------|------|
| 集成方式 | 异步消息（RabbitMQ/RocketMQ） | 同步API（高并发场景慎用） |
| 数据格式 | JSON（标准结构） | XML（遗留系统兼容） |
| 事务一致性 | 最终一致性+对账补偿 | 分布式事务（XA，不推荐） |
| 异常处理 | 重试+死信队列+人工干预 | 直接失败+告警 |
| 监控 | 集成链路追踪 | 日志聚合分析 |

## 四、关键设计要点

### 4.1 最终一致性设计

```
ECP提交订单 → 发消息 → DAP-S处理
    ↓                              ↓
  本地状态：待同步               本地状态：处理中
    ↓                              ↓
  定时对账：检查同步状态 ←──── 处理完成，回调通知
    ↓
  异常单 → 人工介入
```

### 4.2 对账机制

每日T+1自动执行ECP与DAP-S的数据对账：

| 对账项 | 精度 | 处理 |
|--------|------|------|
| 订单状态 | 订单级别 | 不一致→重新同步 |
| 库存数量 | SKU级别 | 差异→出具差异报告 |
| 结算金额 | 结算单级别 | 差异→标记待人工确认 |

### 4.3 异常处理

```
正常流程 → 消息发送 → 消费成功 → 状态同步
                                     ↓
失败流程 → 重试3次（间隔1m/5m/15m）
             ↓
          仍失败 → 死信队列
             ↓
          告警通知 → 人工干预
```

## 五、分阶段实施

| 阶段 | 集成内容 | 复杂度 |
|------|---------|--------|
| 1期 | 采购订单同步+物料/供应商主数据 | ⭐⭐ 基础必经 |
| 2期 | 库存视图+结算同步+发票入账 | ⭐⭐⭐ |
| 3期 | 合同双向同步+预付款+质保金 | ⭐⭐ |
| 4期 | 全面对账自动化+智能异常处理 | ⭐⭐⭐⭐ |

## 六、风险与治理

| 风险 | 影响 | 应对 |
|------|------|------|
| 网络中断 | 数据不一致 | 本地队列缓存+恢复后补发 |
| 数据重复 | 业务异常 | 幂等设计（消息ID去重） |
| 字段映射错误 | 数据不一致 | 自动化集成测试+监控告警 |
| 版本升级不兼容 | 接口异常 | 接口版本化管理+灰度发布 |
