## 二、盈科数码动力（盈动）崛起（🔬）

### 2.1 前身与借壳上市
- 李泽楷创立**盈科拓展集团（盈科控股）**（eastmoney）
- **1999年5月4日**：以盈科名义**借壳"得信佳"上市**，注入**数码港（Cyberport）构想及数个地产项目**，总价值 **24.6亿港元**，得信佳易名为**盈科数码动力（盈动）**（sina / wenku）
- 数码港 = 李泽楷提出的香港高科技园区计划，是盈动早期核心资产故事

### 2.2 互联网热潮中爆发
- 1999-2000 全球互联网狂热，盈动股价飙升，迅速崛起为**香港第八大公司**，李泽泽楷身价直逼其父李嘉诚（eastmoney）
- 早期还曾用**卫星电视**起步（4亿美元退出）（wenku）

## 三、2000年世纪并购：盈动收购香港电讯（🔬 标志性杠杆收购）

### 3.1 背景
- 香港电讯（HK Telecom）有**百年历史**，原第一大股东为英国**大东电报局（Cable & Wireless）**
- **2000年2月**：大东有意接受**新加坡电信**收购香港电讯 → 在香港社会引起忧虑（gecib）

### 3.2 竞价过程
- 盈动 vs 新加坡电信 **竞相收购大东持有的香港电讯 54% 股权**
- **涉资约 3000亿港元**（docin / wenku）
- **2000年2月29日**：盈动以"**收购条件更为合理**"胜出，击退新电信（docin）

### 3.3 合并结果
- 盈科数码动力 + 香港电讯 → 合并为 **电讯盈科（PCCW）**，2000年成立
- 合并后拥有香港最大宽频网络、年盈利逾百亿（max.book118）
- 这是**亚洲标志性杠杆收购（LBO）案例**，李泽楷一战成名

### 3.4 时间线
```
1989 李泽楷回港，和记黄埔任职
  │ 创立盈科拓展
1999.5 借壳得信佳 → 盈科数码动力(盈动)，注数码港(24.6亿)
  │ 互联网热潮，市值飙，香港第8大公司
2000.2 杠杆收购香港电讯(3000亿) 击退新电信
  ▼
电讯盈科 PCCW(0008.HK) 成立
  │ 2008 重组至香港电讯(HKT)
  ▼
PCCW = 综合环球控股(电讯+媒体+IT+物业)
  │ 合资
  ▼
石化盈科(中石化 × PCCW, 易派客开发商)
```

## 五、对易派客/石化盈科研究的溯源价值

1. **石化盈科外方基因**：PCCW 源自李泽楷盈动——一家**靠资本运作+科技叙事+系统集成**起家的香港 IT 巨头。这解释了石化盈科为何具备承建易派客的**港资市场化 IT 能力**，而非纯央企技术风格。
2. **合资结构闭环**：中石化（产业场景）× PCCW（IT资本/系统整合）的组合，是易派客"央企+合资IT+阿里云"路线的起点。
3. **对比启示**：易派客走产业互联网路线；PCCW 本身是香港市场化 telecom/IT 巨头，其电商/平台基因间接赋能石化盈科——但易派客的实际技术底座是阿里云（见 [[石化盈科与易派客开发史]] 第五章刘依群演讲），PCCW 提供的是**资本与港资 IT 管理背景**。
