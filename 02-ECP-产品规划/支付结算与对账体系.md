# ECP支付结算与对账体系

> 电子商城支付结算模块产品设计笔记
> 关联：订单生命周期、供应商结算

## 一、业务全景

ECP支付结算的核心链路：

```
采购订单 → 确认收货 → 生成结算单 → 对账 → 发票 → 付款 → 完成
                                                ↑
                                         供应商发起对账
```

### 1.1 结算模式

| 模式 | 适用场景 | 结算周期 | 特点 |
|------|---------|---------|------|
| 账期结算 | 框架协议供应商 | 月结/季结 | 按周期汇总已确认收货订单 |
| 单笔结算 | 零星采购/紧急采购 | 单笔完成后 | 每笔订单单独结算 |
| 预付款 | 大型设备/定制物资 | 合同约定 | 按合同阶段付款（预付款+进度款+尾款） |
| 质保金 | 工程项目/设备采购 | 验收后N月 | 按合同比例留存，到期结清 |

## 二、对账体系

### 2.1 对账流程

```
T+1 系统生成采购明细对账单
     ↓
供应商登录系统 → 核对订单金额 → 确认/申诉
     ↓
双方确认 → 生成结算单 → 推送ERP
     ↓
财务审核 → 安排付款 → 完成
```

### 2.2 对账能力

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 自动对账 | T+1自动生成对账单（订单级） | P0 |
| 差异处理 | 对账不符→标记差异→人工处理 | P0 |
| 在线确认 | 供应商在线确认/申诉 | P0 |
| 多币种 | 跨境采购多币种结算 | P2 |
| 分批结算 | 一张订单分多次结算 | P1 |
| 折扣处理 | 提前付款折扣处理 | P2 |

### 2.3 对账数据模型

```
settlement_id        PK
settlement_period    YYYY-MM
seller_id            FK → 供应商
total_amount         结算总金额
order_count          订单笔数
status               enum: 待对账/双方确认/差异中/已结算/已付款
created_at
confirmed_at         双方确认时间
paid_at              付款时间

settlement_item_id   PK
settlement_id        FK
order_id             FK → 采购订单
order_amount         订单金额
confirmed_amount     确认金额
difference_reason    差异原因（若有）
status               待对账/已确认/有差异
```

## 三、资金管理

### 3.1 资金流向

```
采购方（国网省公司）
     ↓ 付款
ECP资金平台（中间账户/银行托管）
     ↓ 清分
供应商A     供应商B     供应商C
```

### 3.2 关键能力

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 资金归集 | 采购方→ECP统一支付 | P0 |
| 自动清分 | 按结算单自动分账给各供应商 | P0 |
| 资金追溯 | 每笔资金流水可追溯至采购订单 | P0 |
| 账期管理 | 供应商账期设置+到期提醒 | P1 |
| 逾期预警 | 超过账期未结算→自动告警 | P1 |
| 支付凭证 | 对接银行回单/电子凭证 | P1 |

## 四、与ERP的结算集成

ECP与DAP-S（远光ERP）的结算集成是核心优势：

```
ECP端                       DAP-S端
  结算单  ───同步──→  AP应付模块
  付款单  ←──同步──   付款结果回传
  对账单  ───导出──→  财务核销
  凭证    ←──同步──   会计凭证编号
```java代码实现]

### 4.1 集成要点

1. **单据编号规则统一** — ECP结算单号与ERP应付单号映射
2. **状态同步** — 结算→付款全程状态回传（ECP可查付款进度）
3. **凭证回溯** — 采购订单→结算单→付款单→会计凭证一条链

## 五、结算报表与KPI

| 报表 | 用途 |
|------|------|
| 应付款汇总 | 按供应商/账期展示未付款金额及账龄 |
| 对账差异报表 | 对账差异清单及处理进度 |
| 结算周期分析 | 从对账到付款的平均周期分析 |
| 供应商账龄分析 | 各供应商账款账龄分布（30/60/90天） |

**相关KPI**：
- 对账及时率（采购订单确认后3日内完成对账的比例）
- 结算周期（从收货→付款的平均天数）
- 对账差异率（有差异对账单占总对账单比例）

## 六、分阶段实施

| 阶段 | 功能 | 依赖 |
|------|------|------|
| Phase 1 | T+1自动对账+在线确认+基础结算 | 订单数据标准化 |
| Phase 2 | 自动清分+账期管理+资金追溯 | 银行接口/ERP集成 |
| Phase 3 | 供应链金融+预付款+质保金 | 金融牌照/风控 |
