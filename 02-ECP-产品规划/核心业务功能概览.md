# 核心业务功能概览

> 对应章节：PPT v6.0 第五章~第十章（P40-P53）
> 涵盖：寻源采购、上架部署、下单选购、配送供货、支付结算、履约评价

---

## 第五章 寻源采购环节

### 6种采购方式对比

| 采购方式 | 适用金额 | 流程复杂度 | 周期 |
|---------|:--------:|:---------:|:----:|
| 协议采购 | ≤5万 | 低 | 1-2天 |
| 询比价 | 5-50万 | 中 | 3-5天 |
| 邀请招标 | 50-200万 | 较高 | 7-15天 |
| 公开招标 | ≥200万 | 高 | 15-30天 |
| 单一来源 | 特殊场景 | 低 | 按需 |
| 竞价采购 | 大宗商品 | 中 | 1-3天 |

**业务流**：采购需求 → 选择采购方式 → 供应商报价/投标 → 评审 → 定标 → 生成订单

### 与原有系统的衔接
- 寻源结果实时同步 ERP 采购订单
- 历史采购数据用于智能推荐最优采购方式

## 第六章 上架部署环节

### 商品上架流程
```
供应商提交 → 运营审核 → 定价审核 → 上架 → 巡检
```

### 商品审核规则
- **基本信息**：名称、规格、品牌、品类（必填）
- **资质文件**：营业执照、生产许可、检测报告
- **价格审核**：与历史成交价对比，异常浮动预警
- **自动审核**：标准品类符合条件自动通过，新品/高价值人工审核

---

## 第七章 下单选购环节（一期核心）

### 购物流程
```
选购 → 购物车 → 采购单 → 审批流 → 生成订单 → 确认
```

### 结算流程
- 购物车内商品按供应商分组 → 合并运费 → 预算校验 → 提交审批
- 审批通过后生成正式订单，通知供应商发货

---

## 第八章 配送供货环节

### 配送模式
| 模式 | 说明 |
|------|------|
| 供应商直送 | 供应商直接发货到采购方 |
| 平台配送 | ECP 物流配送 |
| 自提 | 采购方自行提货 |
| 混合 | 部分直送+部分平台配送 |

### 库存预警机制
- 安全库存阈值：低于阈值自动提醒供应商补货
- 滞销品预警：超过库龄自动降价/清仓
- 实时库存查询：对接 WMS 系统

---

## 第九章 支付结算环节

### 支付方式
- 银企直连（对公转账）
- 账期支付（30/60/90天）
- 票据支付（承兑汇票）
- 供应链金融（保理/融资）

### 对账流程
```
商城账单 → 供应商确认 → 差异调整 → 结算 → 开票 → 付款
```

## 第十章 履约评价环节

### 评价维度
| 维度 | 权重 | 评分标准（1-5分） |
|------|:----:|:----------------:|
| 产品质量 | 30% | 合格率、退换货率 |
| 交付及时性 | 25% | 按时到货率 |
| 服务态度 | 15% | 响应速度、沟通效率 |
| 价格竞争力 | 15% | 与市场均价对比 |
| 合规经营 | 15% | 资质有效期、违规记录 |

### 考核等级与处理
| 等级 | 评分区间 | 处理措施 |
|:----:|:--------:|---------|
| A级 | 4.5-5.0 | 优先推荐、降低保证金 |
| B级 | 3.5-4.4 | 正常运营 |
| C级 | 2.5-3.4 | 警告、限制品类 |
| D级 | <2.5 | 暂停合作、整改 |
