**标题**：产品规划总览

产品规划总览
核心目标：打造适用于央国企的企业数智化采购平台，专注连接集团内部采购单位与认证外部供应商，以 阳光合规、集约管控、降本增效、生态协同为核心竞争力，构建覆盖供应商入驻、商品上架、寻源、下单、合同履约到财务结算等十三大业务环节的一站式数智化采购解决方案，实现供应链上下游的高效协同与价值整合。
01  政策驱动：万亿级市场窗口期
• 国资 53 号文要求央企搭建集团级一站式采购商城
• 中国 B2B 采购数字化市场预计 2026 年达 3.2 万亿元
• 99 家央企 + 数千家地方国企构成核心目标客群
工作思路
• 【对标标杆】深度借鉴国网"九中心一商城"、南网赫兹商城、中石化易派客等同类产品
• 【聚焦垂直】深耕央国企寻源采购数智化，构建"合规 + 履约"双重壁垒
• 【开放生态】通过标准 API 融入企业现有 IT 生态（ERP / OA / MDM）
• 【AI 原生】坚持AI原生设计理念，把“需求预测、供应商匹配、评标决策、风险预警、供应链分析”等场景，让AI深度融入商城业务全链路，从源头构建原生智能化的企业电子商城。
实施计划
• 第一阶段（0-12 个月）：核心系统上线，发展种子客户
• 第二阶段（12-24 个月）：能力扩张，沉淀交付方法论
• 第三阶段（24-36 个月）：生态完善，实现规模化盈利

NW电子商城现状分析
NW商城由 赫兹工业品商城 和 赫兹乐购 两大业务板块构成，前者面向企业/工业客户提供 B2B 一站式采购服务，后者是面向NW电网及生态企业内部员工提供生活福利与助农帮扶平台。
赫兹工业品商城
面向电力垂直行业的B2B综合服务电商平台，以电力工业品交易和解决方案为核心，服务于南方电网大集体企业、控股公司及外部市场行业用户。
核心交易模式：
• 购物车直接下单：标准化商品一键加购、快速下单
• 寻源比（竞）价采购：采购方发布定制需求，供应商参与竞价，加速招标流程
• 框架协议采购：按协议价格与分配方案进行目录化采购
赫兹乐购（南网个人商城）
面向NW电网及生态企业内部员工的一站式生活服务平台，主要用于企业福利采购和一般劳动防护用品电商化采购。
核心业务场景：
• 员工福利商城：积分兑换、节日福利、劳保用品
• 乡村帮扶助农：对接乡村振兴产品，助力农产品上行
• 消费帮扶专区：展示帮扶成效、消费统计、溯源信息
借鉴价值：NW商城在企业采购全链路、特色交易模式、消费帮扶场景等方面的实践经验，可作为本产品规划的重要参考。
