# ECP营销与促销体系

> 电子商城B2B场景下的营销与促销策略设计笔记

## 一、B2B营销的特殊性

ECP的营销不是面向C端冲动消费，而是面向企业采购决策：

| C端营销 | B2B营销（ECP） |
|---------|----------------|
| 冲动消费驱动 | 理性采购决策 |
| 个人用户 | 多人决策（采购+审批+财务） |
| 满减/秒杀/拼团 | 协议价/批量折扣/账期优惠 |
| 积分/会员等级 | 采购量价挂钩 |

## 二、ECP可用的促销工具

| 工具 | 说明 | 适用场景 |
|------|------|---------|
| 批量阶梯价 | 采购量越大，单价越低 | MRO耗材批量采购 |
| 组合打包价 | A+B组合优惠价 | 常用物料组合包 |
| 协议价管理 | 供应商为特定客户设专属价 | 框架协议执行 |
| 限时促销 | 供应商发起的限时折扣 | 库存清理/新品推广 |
| 满额免运费 | 采购额达标免物流费 | 鼓励合并下单 |

## 三、定价策略

ECP的定价模型是B2B多维度价格体系：

```
基准价（供应商挂牌价）
    ↓
协议价（框架协议谈判结果）
    ↓
阶梯价（采购量×折扣）
    ↓
促销价（限时折扣）
    ↓
采购方最终价（以上叠加）
```

**关键设计**：不同采购方看同一商品可见不同价格（基于协议），这是ECP的基础能力，不是促销。

## 四、推荐做法

ECP的"营销"应该定位为**采购效率提升工具**，而非C端促销：
- 商品推荐（智能推荐替代品/升级品/配套品）
- 采购清单优化（建议合并订单降低采购成本）
- 供应商的阶梯报价展示（量大价优可视化）
