## 二、DAP 标准业务架构（业务域全景）

整体分四层：**战略决策 → 核心资源 → 运营执行 → 协同交互**

### 战略决策层
- 全面预算（目标测算/标准成本/预算编审/执行控制/考核评价/预算调整/预算发布）
- 资本运营（股权项目遴选/所有者权益/投资后评价/产权登记/股权项目预算/独角兽管理/分支机构管理/上市公司管理/产权日常运营/资产评估/有限合伙）
- 风险防控（专项风险/风险管理/合规管理/管理视窗/内控管理/穿透式监管/风险闭环/监督场景/监管数据上报）
- 绩效管理（目标管理/绩效考核/查询分析）
- 综合计划（项目储备/总控安排/计划编制/预安排/执行检查/计划调整/统计报表）

### 核心资源层
- **人力资源**：组织/干部/人事/考勤/教育培训/薪酬管理
- **财务管理**：会计/税务/资金/电力交易/财政资金/抵消协同/金融业务/发票/成本/全量业务报账/往来/财务报表
- **供应链管理**：需求/采购/供应商履约/仓储/物流/废旧物资/服务/供应商关系/供货/物资精益
- **资产管理**：资产全周期
- **项目管理**：储备/前期/概预算/计划/施工/核算/里程碑/评价/验收转资/竣工决算
- **设备管理**：新增/变动/巡点检/缺陷/工单/两票/生产运行/退役处置
- **营销管理**：购电结算/计费账单/应收账务/收费资金/退费异常/经营分析稽核
- **信息管理**：搜集/平台/存储传输/安全/身份认证
- **综合管理**：经济法律/政工/纪检/工会/后勤/办公协同/产品协同/文档/档案/商旅

### 运营执行层 & 协同交互层
- 生产运行、安全管理、质量管理、业务执行流程
- 协同交互：产业协同、产品协同、办公协同

## 三、DAP-S 产品应用架构（落地模块）

在业务架构基础上，细化出**产品级功能模块**，亮点：

### 七大业务管理域
1. **战略管理**：全面预算、资本运营、绩效管理、综合计划
2. **财务管理**：会计核算、成本管理、发票、全量报账、往来、资金、共享、多维核算、利润中心、商旅、财政资金、电力交易
3. **资产管理**：资产卡片/变动/增资/折旧/退出/租赁/盘点
4. **物资管理**：需求/采购/库存/存货核算/废旧处置/供应商履约/供货
5. **工程管理**：项目前期/投资预算/新型竣工决算/工程核算/投资能力预测/分级审批
6. **设备管理**：台账/生产运行/巡点检/缺陷/工单/两票
7. **营销管理**：购电结算/计费账单/发票成本/经营分析支撑
8. **人资管理**：组织/教育/人事/考勤/薪酬/干部
9. **合同管理**：起草/变更/履行/模板/台账/待归档/风险预警
10. **风险管理**：专项风险/风控体系/合规/内控/穿透式监管/监管体系/智能监管应用/监管驾驶舱

### ⭐ 智能化亮点（AI 方向，重点关注）
- **超级入口**：统一智能交互门户
- **六大智能助手**：
  - 智能问数助手
  - 智能填单助手
  - 智能审核助手
  - 智能写作助手
  - 智能问规助手
  - 智能报告助手
  - 资金排程助手
- **智能体中心**：智能体统一管理平台
- **经营分析**：经营全景/管控/自助分析/预测/报告/财务视窗/智能问数
- **协同生态**：银企协同、税企协同、政企协同、企企协同

## 四、DAP-S 财务管理应用架构（财务纵深）

财务是 DAP-S 最成熟的领域，模块化最细：

### 核心模块
| 模块 | 关键功能 |
|------|---------|
| 会计核算 | 账务处理/调整期/协同抵消（关联交易协同、期末抵销、管理口径抵销）/智能月结/账务锁定 |
| 成本管理 | 归集/产品成本计算/分摊/月末结转/分析/预测/分电压成本核算/收入成本还原 |
| 发票管理 | 进项（提交）/销项（开具） |
| 全量业务报账 | 成本费用/其他收入/采购结算 |
| 财务报表 | 编报/锁定/查询 |
| 往来管理 | 清账/坏账确认/坏账准备/账销案存追索 |
| 资金管理 | 收入/融资/支出/运作/账户/资金预算/多维分析/银企协同 |
| 共享管理 | 任务/质量/知识/信用/绩效/满意度/运营监控 |
| 资产管理 | 卡片/变动/增资/折旧/退出/租赁/盘点 |
| 金融业务 | 保险/财务公司/信托/投资/债权/基金/买入返售/债券/股票/融资租赁 |
| 电力交易 | 省内购电/可再生能源/跨省跨区/发电/售电发行/用户缴费/购电账单/购电成本支付 |
| 财政资金 | 预算编制下达/执行/结转结余 |
| 涉税业务 | 税基溯源/纳税申报/专项 |
| 利润中心 | 账务处理/查询/报表/国际化核算 |
| 综合管理 | 队伍建设/文化阵地/办公协同 |

### ⭐ 财务智能化特征
- 智能月结、智能安防
- 多维核算（分电压、收入成本还原）
- 国网商旅云 APP 集成（差旅费报账）
- 国际化核算业务处理（出海支撑）

## 五、年度规划 vs 未来的差异

| 维度 | 年度规划（当前） | 未来 |
|------|----------------|------|
| 业务域 | 基础 9 域 | 增加**质量管理**（质量计划/保证/控制/改进/客户反馈）、**安健环**（安全/健康/环保）、**生产管理**（计划/物料需求/工艺/工序/能力） |
| 产品架构 | 现有模块 | 新增安全环保、质量管理、生产管理三大模块 |
| 财务架构 | 基本一致 | 增加智能安防、国际化核算扩展 |
| 智能化 | 六大助手+智能体中心 | 延续并深化，协同生态（银企/税企/政企/企企）更完善 |

**关键演进方向：** 从「财务+人资+物资+项目」核心四域，向「质量+安健环+生产」运营域扩展，形成覆盖战略→资源→运营→协同的完整闭环。

## 六、与 ECP 电子商城的关联思考

| DAP-S 模块 | ECP 对应 | 可借鉴点 |
|-----------|---------|---------|
| 物资管理（需求/采购/供应商/仓储/废旧） | 国网商城采购交易 | 供应商履约、供货管理、废旧处置流程 |
| 合同管理（起草/履行/风险预警） | 商城合同 | 合同风险预警可接入 |
| 智能助手体系 | 商城智能客服/导购 | 超级入口+智能问数思路可直接复用 |
| 协同生态（银企/企企） | 支付对接 | 银企协同模式参考 |

> 注：ECP 偏「交易前台」，DAP-S 偏「管理后台」，两者是前台交易+后台管控的互补关系。

---

## 七、一句话总结

**DAP-S 是远光面向大型集团（国家电网）的新一代企业资源管理系统，以「标准业务架构→产品应用架构→财务纵深架构」三层展开，当前已覆盖战略/财务/物资/工程/设备/人资/营销/合同/风险九大域，并以「六大智能助手+智能体中心+超级入口」为 AI 化核心抓手，未来向质量/安健环/生产运营域扩展。**
