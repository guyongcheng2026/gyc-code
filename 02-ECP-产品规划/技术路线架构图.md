# 技术路线架构图（谷工确认版）

> 保存时间：2026-07-16
> 来源：谷工微信确认的技术路线总架构

```
┌─────────────────────────────────────────────────────────────┐
│  入口层                                                       │
│  微信(ClawBot/iLink)  ←→  Hermes 网关  ←→  Obsidian(笔记UI)  │
└──────────────┬──────────────────────────┬──────────────────┘
               │ 指令/消息                  │ 双向链接/图谱
               ▼                           ▼
        Hermes Agent(本地) ──────── 知识库(E:\谷勇成的知识库)
               │ 模型调用                (Obsidian vault)
               ▼
        OpenCode Zen (deepseek-v4-flash-free)
        + OpenRouter 自动切换(备用)
```

**说明：**
- 微信 ClawBot/iLink：手机端指令入口与结果接收
- Hermes 网关：消息中转 + 定时任务 + 记忆/技能调度
- Obsidian：笔记 UI 层，负责双向链接与知识图谱阅读
- 知识库：E:\谷勇成的知识库（Obsidian vault 实体）
- 模型层：OpenCode Zen 主用，OpenRouter 备用自动切换
