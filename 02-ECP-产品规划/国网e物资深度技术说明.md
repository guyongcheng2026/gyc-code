# 国网e物资（移动物资管理平台）深度技术说明

> 本文是五E一中心深化系列第五篇，聚焦e物资的移动端架构、离线能力、与ERP的协同及在五E一中心中的独特定位。
> 元信息：创建时间2026-07-20，基于"网上国网"超级APP公开信息及电力行业移动应用通用功能推断

## 一、业务架构深度

### 1.1 e物资的定位与特点

e物资是国网**移动物资管理**的核心平台，融合在 **"网上国网"超级APP** 中，面向一线仓库管理员、现场领料员、项目专责提供移动端物资操作能力。

**核心特征**：
1. **移动原生**：以APP/微信小程序形态部署，不依赖桌面端
2. **离线优先**：仓库/施工现场网络条件差，支持离线操作+在线同步
3. **轻量化**：不替代ERP的物资管理功能，而是补充移动场景
4. **扫码驱动**：以条码/二维码/RFID扫描为操作入口

### 1.2 核心功能

| 功能模块 | 操作 | 技术实现 |
|---------|------|---------|
| **移动收货** | 扫描运单/物料条码 → 确认收货 → 触发ERP收货(MIGO) | HTTP API + 离线队列 |
| **库存查询** | 按物料号/库位/批次查询实时库存 | 本地缓存 + 按需刷新 |
| **领料出库** | 扫描领料单 → 拣货 → 确认出库 | 条码扫描 + 移动打印 |
| **库存盘点** | 扫码盘点 → 差异记录 → 上传同步 | 离线缓存 + 批量上传 |
| **移库调拨** | 扫描调拨单 → 发货/收货确认 | 两步确认 + ERP同步 |
| **现场签收** | 大件物资现场到货拍照+GPS+签字 | 离线拍照 + 延期上传 |
| **报废处理** | 扫描报废物资 → 审批 → 实物处置 | 拍照留证 + 流程审批 |
| **消息推送** | 到货通知、领料提醒、审批催办 | APP推送 |

### 1.3 典型使用场景

**场景一：仓库现场收货**
```
货车到仓库
  ↓
仓库员打开e物资APP → 选择"收货"
  ↓
扫描送货单条码 → 自动调取ERP采购订单信息
  ↓
逐项扫描物料条码确认数量 → 异常项拍照留证
  ↓
（网络正常）→ 实时触发ERP MIGO收货过账
（网络离线）→ 本地缓存 → 网络恢复后自动批量同步
  ↓
打印收货标签 → 粘贴到货架/物资上
```

**场景二：施工现场领料**
```
项目专责在e物资提交领料申请
  ↓
仓库管理员收到推送通知 → 按领料单拣货
  ↓
现场领料员扫码确认 → GPS定位留证 → 电子签名
  ↓
库存自动扣减 → ERP库存实时更新
  ↓
领料单流转至项目成本核算
```

## 二、技术架构深度

### 2.1 APP技术架构

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **前端框架** | 混合APP（Native + H5）/ Flutter | 嵌入"网上国网"APP |
| **扫码引擎** | 自研/第三方（如紫光扫描引擎） | 条码/二维码/RFID |
| **离线存储** | SQLite本地数据库 + 文件缓存 | 离线操作数据暂存 |
| **同步引擎** | 自研离线队列 + 断点续传 | 网络恢复后自动同步 |
| **定位** | 北斗+GPS | 现场签收/巡检定位 |
| **推送** | 自研消息推送 / 接入i国网推送通道 | 实时通知 |

### 2.2 离线+在线同步架构

```
┌─────────────────────────────────┐
│  移动端（e物资APP）             │
├─────────────────────────────────┤
│  在线模式                      │
│  ├─ 实时调用REST API            │
│  └─ 实时同步ERP数据             │
├─────────────────────────────────┤
│  离线模式                      │
│  ├─ 操作日志写入本地SQLite       │
│  ├─ 扫码结果+拍照缓存本地       │
│  └─ 断网检测 → 排队等待          │
├─────────────────────────────────┤
│  网络恢复后                    │
│  ├─ 按时间戳顺序上传离线操作     │
│  ├─ 冲突解决（以现场操作为准）   │
│  └─ 同步完成后推送通知确认       │
└─────────────────────────────────┘
         ↓ 4G/5G/离线WiFi
┌─────────────────────────────────┐
│  服务端                         │
├─────────────────────────────────┤
│  API网关（认证鉴权/限流）        │
│  ├─ 操作日志服务                  │
│  ├─ 文件服务（图片/签字上传）      │
│  └─ 同步队列（防重复/防丢失）      │
├─────────────────────────────────┤
│  业务核心                       │
│  └─ 与ERP SAP接口（RFC/IDoc）    │
└─────────────────────────────────┘
```

### 2.3 数据同步保障

- **幂等设计**：同一操作上传两次不产生重复业务数据（通过本地GUID去重）
- **版本冲突**：服务器端记录数据版本号，客户端更新时检测版本是否过期
- **断点续传**：大文件（照片）分片上传，失败后可续传

## 三、与各中心的协同关系

### 3.1 e物资 ↔ ERP

| 场景 | e物资操作 | ERP操作 | 同步机制 |
|------|----------|---------|---------|
| 收货 | 扫描条码确认数量 | 触发MIGO收货过账 | REST API → SAP RFC |
| 出库 | 扫描拣货确认 | 触发移动类型发货 | 同上 |
| 盘点 | 扫描实盘数录入 | 生成盘点差异凭证 | 批量上传 → SAP处理 |
| 调拨 | 扫描调拨单确认 | 触发转储单 | 实时/离线后上传 |

### 3.2 e物资 ↔ ECP

| 场景 | 价值 |
|------|------|
| 到货签收拍照上传 | ECP采购方可在线查看到货现场照片+签字 |
| 领料消耗同步 | ECP可追踪物资最终去向（哪个工程/哪台设备） |

## 四、对远光ECP的启示

### 4.1 核心借鉴点

1. **离线优先设计**：电力行业仓库/施工现场网络条件复杂，移动端必须支持离线操作
2. **扫码驱动体验**：用二维码/条码一码到底，降低人工录入错误
3. **轻量化操作**：不需要完整ERP功能，移动端聚焦：确认/扫码/拍照/签字 四类操作
4. **与超级APP融合**：将物资功能嵌入企业已有的移动办公APP，避免用户安装多个APP

### 4.2 差异化的移动端机会

1. **微信小程序接入**：e物资是自研APP，远光ECP可基于微信小程序/企业微信，降低部署门槛
2. **AI辅助识别**：拍照识别物料铭牌（OCR）、语音录入物料编码
3. **AR增强现实**：扫描仓库货架，AR叠加显示库存信息（实验性功能）
4. **与电商式配送结合**：现场扫码签收后可评价供应商配送服务
