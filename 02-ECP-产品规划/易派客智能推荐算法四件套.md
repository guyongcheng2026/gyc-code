## 总览：四件套各管什么

| 算法 | 管什么 | 易派客落地位置 |
|------|--------|------------|
| ① 协同过滤 CF | 推"你像的人还买啥" | 采购员首页"猜你喜欢" |
| ② 知识图谱+GNN | 推"同类替代品" | 商品详情页"断供一键换货" |
| ③ 预算优化 LSTM | 管"划不划算、超不超预算" | 下单前"性价比+预算体检" |
| ④ 供应商评级 | 管"这货谁家靠谱" | 同货多供"推荐高评级供应商" |

**串联逻辑**：①②生成候选商品池 → ③过滤超预算/预警涨价/优先省钱 → ④每件候选货挑评分最高供应商 → 最终列表 = 相关 ∧ 买得起 ∧ 省钱 ∧ 高评级。

**底层依赖**（呼应易派客笔记）：MDM 主数据 + 易标准 EQE/信用认证，是②③④ 的直接数据源；图谱/评级质量 = 主数据治理质量。

## ① 协同过滤（Collaborative Filtering）

### 一句话
"和你买得差不多的人，还买了啥，就推给你。" 只看**人的行为**（谁买了啥），不分析商品本身长啥样。

### 公式逐字符
```
sim(u, v) = (R_u · R_v) / (||R_u|| × ||R_v||)
Top-N = argsort(sim)[:N]
```

- **R_u**：用户 u 的"行为向量"——用户×商品矩阵里 u 那一行，每格=该用户对商品的采购量（或买没买的0/1）。
- **分子 R_u · R_v**：点积（对应位置相乘再相加）。两人共同买过的商品，购买量相乘累加；越大共同偏好越强。
- **分母 ||R_u|| × ||R_v||**：两向量长度（模）之积，即 √(各分量平方和)。
- **结果 sim ∈ [-1, +1]**：+1 买得完全一样，0 毫无关系，-1 完全相反。
- **Top-N = argsort(sim)[:N]**：对其他用户按相似度降序排序取编号，取前 N 个作"最相似邻居"。

### 示例（采购员 A vs B vs C）
| 采购员 | 高压电缆 | 绝缘子 | 避雷器 | 金具 | 变压器 |
|--------|---------|--------|--------|------|---------|
| A | 100 | 50 | 20 | 0 | 0 |
| B | 80 | 40 | 0 | 30 | 0 |
| C | 10 | 0 | 0 | 0 | 5 |

- sim(A,B)=100·80+50·40+20·0+0·30+0·0 除以 (√12900 × √8900) ≈ 0.933
- sim(A,C)≈0.786 → A 和 B 更相似，优先参考 B
- B 买过而 A 没买的"金具(30)" → 推给 A

### 推荐流程
```
1. 建矩阵：拉全量采购记录 → 用户×商品行为矩阵 R
2. 算相似：对目标 u 和其余 v 算 sim(u,v)（只算有共同商品的人省算力）
3. 挑邻居：Top-N = argsort(sim)[:N]
4. 生成候选：收集 N 个邻居买过、u 没买的商品
5. 打分排序：pred(u,i)=Σ_{v∈邻居} sim(u,v)×R_v,i，降序取前 K
6. 出结果：前 K 个作推荐
```

### 可跑代码（Python）
```python
import numpy as np
# 行=用户, 列=商品, 值=采购量
R = np.array([
    [100, 50, 20,  0,  0],   # A
    [ 80, 40,  0, 30,  0],   # B
    [ 10,  0,  0,  0,  5],   # C
])
def cosine(u, v):
    dot = np.dot(R[u], R[v])
    nu, nv = np.linalg.norm(R[u]), np.linalg.norm(R[v])
    return 0.0 if (nu==0 or nv==0) else dot/(nu*nv)
def recommend(user_idx, N=2, K=3):
    sims = [(v, cosine(user_idx, v)) for v in range(R.shape[0]) if v!=user_idx]
    sims.sort(key=lambda x: x[1], reverse=True)
    neighbors = sims[:N]
    scores = {}
    for v, s in neighbors:
        for item in range(R.shape[1]):
            if R[user_idx,item]==0 and R[v,item]>0:
                scores[item] = scores.get(item,0) + s*R[v,item]
    return sorted(scores.items(), key=lambda x: x[1], reverse=True)[:K]
print(recommend(0))   # [(3, 27.99), (4, 3.93)]  商品3=金具, 商品4=变压器
```

### 设计要点
- 矩阵存值：采购数量比 0/1 更能体现偏好强度。
- 相似计算：离线 T+1 批算（全量 O(n²) 太重），存预计算邻居。
- 冷启动：新采购员无历史 → 用②商品CF 或同企业/同行业热门兜底。

## ② 知识图谱 + GNN（Knowledge Graph）

### 一句话
"把商品、供应商、品类、技术参数全连成一张大网，让机器自己学会每个节点长啥样，挖掘'表面不沾边、其实暗藏关系'的货，推同类替代品。"

### 图谱节点与边
| 节点类型 | 例子 |
|----------|------|
| 商品 Item | 高压电缆 ZR-YJV-3×120 |
| 供应商 Supplier | A厂、B厂 |
| 品类 Category | 电力电缆、控制电缆 |
| 技术参数 Spec | 铜、0.6/1kV、3芯、阻燃 |

边：商品—生产于→供应商；商品—属于→品类；商品—具有→技术参数；品类—父级→品类；参数—同值→参数。

### 公式逐字符
```
h = GNN(A, X)
score = sigma(h_i · h_j)
Top-N(score)
```
- **X**：节点原始特征矩阵（每行一节点，每列一特征）。
- **A**：邻接矩阵（节点×节点，A[i][j]=1 表示有边）。
- **h = GNN(A, X)**：图神经网络把每个节点"自己和邻居特征搅几轮"得到嵌入向量 H。经典 GCN 一层：H¹=ReLU(Ã·H⁰·W)。跑 K 层后 h_i 包含 2~K 步内所有关联节点信息 → 结构相似的节点学到的 h 也相似。
- **score = sigma(h_i · h_j)**：点积 + sigmoid 压缩到 0~1，当"相似概率"。
- **Top-N(score)**：对目标商品 i 和其他 j 算分，降序取前 N 个 = 隐性关联/替代品。

### 示例
商品"高压电缆"与"控制电缆"不直接相连，但都连"电力电缆"品类节点 + 共享"铜""0.6/1kV"参数节点（2步可达）→ GNN 学完后两者 h 接近 → 互为替代品。

### 可跑代码（PyTorch Geometric）
```python
import torch, torch.nn.functional as F
from torch_geometric.nn import GCNConv
from torch_geometric.data import Data
# 节点: 0电缆1,1电缆2,2电力电缆,3铜,4=0.6/1kV
edge_index = torch.tensor([[0,2],[2,0],[0,3],[3,0],[0,4],[4,0],
                         [1,2],[2,1],[1,3],[3,1],[1,4],[4,1]], dtype=torch.long).T
X = torch.rand((5, 16))                      # 5节点 16维初始特征
data = Data(x=X, edge_index=edge_index)
class GNN(torch.nn.Module):
    def __init__(s, i, h, o):
        super().__init__(); s.c1=GCNConv(i,h); s.c2=GCNConv(h,o)
    def forward(s, x, e):
        return s.c2(F.relu(s.c1(x, e)))
H = GNN(16,32,64)(data.x, data.edge_index)    # h = GNN(A, X)
def score(i,j): return torch.sigmoid(torch.dot(H[i],H[j])).item()
cands = {j: score(0,j) for j in range(5) if j!=0}
print(sorted(cands.items(), key=lambda x:x[1], reverse=True)[:1])  # 电缆1最像电缆2
```

### 设计要点
- GNN 选 GCN/GraphSAGE（工业品类图大，GraphSAGE 采样邻居更省算力）。
- 训练信号：链接预测（遮掉一条边让模型猜回），不用人工标。
- 在线：预计算 h 丢进 Faiss/Milvus 近邻搜，毫秒返回。
- 优势 vs CF：可解释（"同材质同电压"）；解决冷启动（新商品一连图谱就有位置）。
- 坑：图谱质量取决于主数据治理（"铜芯"和"CU"要归一）。

## ③ 预算优化（Budget Optimization + LSTM）

### 一句话
"先预判这货以后贵还是便宜，再算'比均价省了多少'，最后只推那些你预算真买得起的——省钱和买得起一次管住。"

### 公式逐字符
```
P_t = LSTM(X_{t-n:t})            # 价格预测
save = (P_avg - P_i) / P_avg    # 省钱率
score = save × budget_ok        # 最终打分
```
- **X_{t-n:t}**：商品过去 n 期价格序列 [价_{t-n}, ..., 价_t]。
- **P_t = LSTM(X)**：LSTM 读时间序列，吐出下期预测价。
- **save = (P_avg - P_i)/P_avg**：P_avg 历史均价，P_i 用预判价 P_t 才体现趋势。>0 省钱，<0 亏钱。
- **budget_ok**：P_t × 计划量 ≤ 剩余预算 则 1，否则 0（预算闸门）。
- **score = save × budget_ok**：相乘 → 省钱且买得起才高分；超预算或涨价立刻不好看。

### 示例
- 电缆：P_avg=98.3，LSTM 预判涨到 P_t=102.3 → save=-0.04，budget_ok=1 → score=-0.04（负分预警"要涨"）
- 控制电缆：P_avg=14.17，预判降到 P_t=9.0 → save=+0.365，budget_ok=1 → score=+0.365（高分推）

### 可跑代码（PyTorch，LSTM 演示）
```python
import torch, torch.nn as nn, numpy as np
seq_cable=[95,98,100,102,99,100]; seq_ctrl=[16,15,15,14,13,12]
Pavg_c=np.mean(seq_cable); Pavg_k=np.mean(seq_ctrl)
class LSTM(nn.Module):
    def __init__(s,i=1,h=16): super().__init__(); s.l=nn.LSTM(i,h,batch_first=True); s.f=nn.Linear(h,1)
    def forward(s,x): o,_=s.l(x); return s.f(o[:,-1,:])
# 演示用末值外推近似 LSTM 预判
Pt_c=seq_cable[-1]+2.3; Pt_k=seq_ctrl[-1]-3.0
def save(pa,pt): return (pa-pt)/pa
def bok(pt,q,left): return 1 if pt*q<=left else 0
bk_c=bok(Pt_c,3000,500000); bk_k=bok(Pt_k,20000,500000)
sc_c=save(Pavg_c,Pt_c)*bk_c; sc_k=save(Pavg_k,Pt_k)*bk_k
print(f"电缆 score={sc_c:+.3f}→预警(涨)  控制缆 score={sc_k:+.3f}→优先推(省)")
```

### 设计要点
- 序列粒度：月或采购批次（工业品按月波动）。
- 窗口 n：12~24 期。
- P_i 用预判价 P_t 才算趋势预警。
- 负分不隐藏改预警（"快涨价"是信号）。
- 冷启动：序列<6期时 save 改用同类均价差。
- 坑：budget_ok 必须在线实时算（剩余预算动态变）。

## ④ 供应商评级（Supplier Rating）

### 一句话
"给每个供应商打综合分——准时交货、质量合格、售后、价格、资质，五样按轻重各占比例搅一起，分高的供应商的货才值得推。"

### 公式逐字符
```
S = 0.3×Delivery + 0.25×Quality + 0.2×Service + 0.15×Price + 0.1×Qual
```
- 五系数权重和=1：**交货准时率最重(0.3)**，质量(0.25)次之，售后(0.2)，价格(0.15)，资质(0.1)最轻。符合工业品"能否按时到、到的是否合格比便宜点更重要"。
- 每维先归一化到 0~1：率类÷100；售后百分制÷100；价格用"比均价省的比例"夹到0~1；资质 AAA=1.0/AA=0.8/A=0.6/B=0.4/C=0.2。
- **Quality / Qual 两维 = 易标准 EQE / 信用认证分**，直接接入不重复造轮子。

### 示例
- A厂(归一化)：Delivery=0.98, Quality=0.99, Service=0.90, Price=0.05, Qual=1.0
  → S_A=0.3×.98+.25×.99+.2×.90+.15×.05+.1×1.0=**0.829**
- B厂：Delivery=0.80, Quality=0.85, Service=0.70, Price=0.15, Qual=0.6
  → S_B=**0.675**
- S_A>S_B → 同货推 A厂不推 B厂（便宜但准时/质量拉胯）。

### 可跑代码（Python）
```python
def normalize(s):
    d,q,s_,p,qual = s
    qm={"AAA":1.0,"AA":0.8,"A":0.6,"B":0.4,"C":0.2}
    return {"Delivery":d/100,"Quality":q/100,"Service":s_/100,
            "Price":max(0.0,min(1.0,p/100)),"Qual":qm.get(qual,0.0)}
W={"Delivery":0.3,"Quality":0.25,"Service":0.2,"Price":0.15,"Qual":0.1}
def score(n): return sum(W[k]*n[k] for k in W)
def grade(s):
    return "优质" if s>=0.85 else "合格" if s>=0.70 else "观察" if s>=0.50 else "预警"
A=normalize((98,99,90,5,"AAA")); B=normalize((80,85,70,15,"A"))
sA,sB=score(A),score(B)
print(f"A厂 S={sA:.3f} 级={grade(sA)}  B厂 S={sB:.3f} 级={grade(sB)}")
# 同货多供取高分: [('A厂',0.829),('B厂',0.675)]
```

### 设计要点
- 权重配置化（存库可改），真实该用历史退货率/客诉反推校准。
- 指标源接易标准 EQE/信用认证做 Quality/Qual。
- 一票否决：质量合格<0.8 直接不推（工业品次品代价大）。
- 冷启动新供应商：给"观察级"暂不高推。

## 落地总图（ECP/易派客智能推荐）

```
候选生成    ①协同过滤(首页猜你喜欢) + ②知识图谱(详情页替代品)
     │
     ▼
预算体检    ③LSTM(过滤超预算/预警涨价/优先省钱)
     │
     ▼
供应商筛选  ④评级(每件候选货挑S最高供应商)
     │
     ▼
最终列表 = 相关 ∧ 买得起 ∧ 省钱 ∧ 高评级
```

**底层基石**：MDM 主数据 + 易标准 EQE/信用认证（②③④ 直接数据源）；图谱/评级质量 = 主数据治理质量。
