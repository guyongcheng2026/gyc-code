# Debug

1. **Isolate**: Find the minimal reproduction case
2. **Reproduce**: Verify the bug can be triggered reliably
3. **Diagnose**: Trace root cause (logs, types, flow)
4. **Fix**: Apply minimal change that addresses root cause
5. **Verify**: Confirm fix resolves the issue without side effects
