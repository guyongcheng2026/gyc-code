# Stuck Detection & Recovery

When you suspect you are stuck (3+ rounds with no progress, repeated errors, going in circles):

## Diagnosis
1. What was the last successful action?
2. What have I tried since?
3. Why did those attempts fail?

## Recovery Strategies (try in order)
1. **Different approach**: Is there another way to accomplish this?
2. **Smaller steps**: Can I break this into smaller, testable pieces?
3. **Ask for help**: Formulate a clear question for the user
4. **Explore**: Use code exploration to understand the problem better
