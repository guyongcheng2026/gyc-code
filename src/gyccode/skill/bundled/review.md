# Code Review

When reviewing code, check:
1. **Correctness**: Does it do what it claims?
2. **Edge cases**: Null, empty, error states handled?
3. **Style**: Follows project conventions?
4. **Performance**: Any obvious bottlenecks?
5. **Security**: Any injection, path traversal, secret leaks?
