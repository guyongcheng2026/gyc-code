# 任务管理工具 (task-management)

## 工具概述
这个技能展示了如何增强pi agent的功能，通过提供任务管理工具来：
1. 创建任务用于长期运行的操作
2. 列出活动和已完成的任务
3. 获取特定任务的详细信息和结果
4. 更新任务属性和状态
5. 停止或取消正在运行的任务
6. 管理任务依赖和优先级
7. 与协调者-工作者模式和技能系统集成

## 当前限制
pi agent目前具有：
- 没有正式的任务管理系统
- 所有操作都是同步的，会阻塞用户交互
- 没有办法将长期运行的操作在后台进行
- 没有并行操作的能力
- 没有任务状态跟踪或结果检索
- 没有任务依赖管理

## 增强功能

### 1. 任务创建
- 创建用于各种操作的任务（代码编译、测试运行、文件处理等）
- 指定任务类型、所需工具和输入参数
- 设置任务优先级和资源限制
- 定义任务依赖（在当前任务之前必须完成的任务）
- 配置任务超时和重试策略

### 2. 任务列表和过滤
- 列出所有任务（活动的、已完成的、失败的、被取消的）
- 按状态过滤任务（进行中、已完成、失败等）
- 按类型过滤任务（编译、测试、部署等）
- 按时间过滤任务（最近创建的、最近更新的等）
- 按来源过滤任务（用户创建的、系统创建的、协调者创建的等）

### 3. 任务详细信息和结果
- 获取任务的完整信息（状态、进度、输入、输出等）
- 访问任务结果和输出（日志、生成的文件等）
- 查看任务执行历史和时间线
- 检查任务错误和失败详情
- 监控任务资源使用（CPU、内存、磁盘）

### 4. 任务更新和控制
- 更新任务属性（优先级、超时等）
- 暂停和恢复正在运行的任务
- 停止或取消任务（优雅地或强制地）
- 重试失败的任务
- 克隆任务以进行相似的操作

### 5. 任务依赖和工作流
- 定义任务依赖（任务B依赖于任务A的完成）
- 管理复杂的工作流和任务图
- 自动任务调度基于依赖关系
- 循环依赖检测和预防
- 依赖可视化和工作流图

### 6. 并行和异步操作
- 启动并行任务以提高性能
- 管理任务队列和工作池
- 平衡任务负载跨越可用资源
- 处理任务完成事件和通知
- 合并并行任务的结果

### 7. 与架构的集成
- 与协调者-工作者模式集成：
  - 协调者可以创建任务分配给工作者
  - 工作者可以报告任务进度和结果
  - 任务可以触发工作者的创建和销毁
- 与技能系统集成：
  - 技能可以注册任务类型和处理器
  - 任务可以使用特定技能的功能
  - 技能可以访问任务管理工具用于自身操作
- 与现有工具集成：
  - 任务可以使用所有现有工具（编辑、bash、搜索等）
  - 任务结果可以馈送到其他工具中

## 实现方法

这个技能提供了一个如何实现这些增强功能的蓝图。实际的实现需要：
1. 创建任务管理器核心组件
2. 实现任务创建、列表、获取、更新和停止功能
3. 添加任务依赖管理和工作流编排
4. 实现并行和异步操作支持
5. 添加任务状态跟踪和结果存储
6. 与现有架构（协调者-工作者模式）和技能系统集成
7. 提供用于管理任务的命令行界面

然而，这个技能可以通过以下方式使用：
1. 作为参考文档，用于了解应该实现什么
2. 作为教学工具，帮助用户理解任务管理工具的好处
3. 作为原型，这些增强功能可以在此基础上进行构建

## 任务生命周期

任务将经历以下状态：
1. **CREATED**：任务已创建但尚未开始
2. **QUEUED**：任务正在等待其依赖项完成
3. **RUNNING**：任务正在执行
4. **PAUSED**：任务已暂停（用户或系统请求）
5. **COMPLETED**：任务已成功完成
6. **FAILED**：任务由于错误而失败
7. **CANCELLED**：任务已被用户或系统取消
8. **TIMEOUT**：任务由于超过时间限制而失败

## 使用示例

### 示例1：长期运行的操作
用户输入：在后台编译整个代码库

任务管理响应：
```
正在创建编译任务...
任务ID: compile-20260907-113000-001
任务类型：代码编译
源码目录：/
构建命令：make all
优先级：普通
依赖：无
超时：30分钟
任务已创建并开始执行。
您可以使用 /task-management list 查看进度
或使用 /task-management get compile-20260907-113000-001 获取详细信息。
```

### 示例2：并行操作
用户输入：并行运行测试套件和代码 linting

任务管理响应：
```
正在创建测试任务...
任务ID: test-20260907-113000-002
任务类型：测试运行
测试目录：/
测试命令：npm test
优先级：高
依赖：无
超时：15分钟

正在创建linting任务...
任务ID: lint-20260907-113000-003
任务类型：代码linting
源码目录：/
lint命令：npm run lint
优先级：高
依赖：无
超时：10分钟

两个任务已创建并开始并行执行。
您可以使用 /task-management list 查看两个任务的进度。
```

### 示例3：任务依赖
用户输入：只有在测试通过后才部署应用程序

任务管理响应：
```
正在创建测试任务...
任务ID: test-20260907-113000-004
任务类型：测试运行
测试目录：/
测试命令：npm test
优先级：高
依赖：无
超时：15分钟

正在创建部署任务...
任务ID: deploy-20260907-113000-005
任务类型：应用程序部署
目标环境：生产
部署命令：npm run deploy
优先级：普通
依赖：test-20260907-113000-004（必须先成功完成）

两个任务已创建。
测试任务已经开始执行。
部署任务将在测试任务成功完成后自动开始。
您可以使用 /task-management list 查看两个任务的状态。
```

## 与pi agent的集成

要将这些增强功能集成到pi agent中：
1. 创建任务管理器核心组件
2. 实现任务创建、列表、获取、更新和停止功能
3. 添加任务依赖管理和工作流编排
4. 实现并行和异步操作支持
5. 添加任务状态跟踪和结果存傚
6. 与现有架构（协调者-工作者模式）和技能系统集成
7. 提供用于管理任务的命令行界面
8. 确保适当的错误处理和后备机制

此技能作为实施这些更改的规范和参考。
