# 增强LSP集成 (lsp-enhanced)

## 工具概述
这个技能展示了如何增强pi agent的代码编辑能力，通过集成语言服务器协议(LSP)来提供：
1. 自动补全建议
2. 转到定义和查找引用
3. 悬停信息显示类型和文档
4. 诊断（错误和警告）
5. 代码操作（快速修复、重构选项）
6. 工作区符号和文档符号

## 当前限制
pi agent目前的文件编辑和代码理解能力有限：
- 基础文本编辑没有上下文感知
- 没有自动补全或智能建议
- 没有转到定义或查找引用功能
- 没有实时诊断或错误检查
- 依赖于手动文件检查和基本的文本搜索

## 增强功能

### 1. 自动补全
- 上下文感知的建议（变量名、函数名、类名等）
- 语言特定的建议（Python中的模块导入、函数签名等）
- 文档字符串和类型信息集成
- 按相关性排序的建议列表

### 2. 导航功能
- 转到定义：跳转到符号的声明位置
- 查找引用：查找项目中所有对符号的引用
- 转到类型定义：跳转到类型的定义位置
- 转到实现：跳转到接口的实现位置

### 3. 悬停信息
- 悬停时显示类型信息
- 显示文档字符串和注释
- 显示符号的详细信息（参数、返回值等）
- 支持丰富的格式化（Markdown等）

### 4. 诊断和错误检查
- 实时错误检查（语法错误、类型错误等）
- 警告显示（未使用变量、潜在问题等）
- 错误和警告的视觉指示（下划线、图标等）
- 按严重性分类的问题列表
- 快速访问错误详情和修复建议

### 5. 代码操作
- 快速修复（自动建议的错误修复）
- 重构选项（提取方法、重命名变量等）
- 源代码组织（导入优化等）
- 上下文感知的代码生成

### 6. 符号和大纲
- 工作区符号：搜索项目中的所有符号
- 文档符号：显示当前文件的结构大纲
- 按类型过滤符号（函数、类、变量等）
- 快速导航到特定符号

## 支持的语言（初始实现）
- Python（使用pylsp或jedi语言服务器）
- 可扩展到其他语言（JavaScript/TypeScript、Java、Go等）

## 实现方法

这个技能提供了一个如何实现这些增强功能的蓝图。实际的实现需要：
1. 集成LSP客户端到pi agent中
2. 为支持的语言启动和管理语言服务器
3. 实现LSP协议的通信（通过stdio或TCP）
4. 将LSP响应集成到编辑器界面中
5. 提供适当的错误处理和后备机制

然而，这个技能可以通过以下方式使用：
1. 作为参考文档，用于了解应该实现什么
2. 作为教学工具，帮助用户理解LSP集成的好处
3. 作为原型，这些增强功能可以在此基础上进行构建

## 使用示例

### 示例1：Python自动补全
用户在编辑器中输入："import os\nos."

LSP响应：
```
自动补全建议：
- path：os.path模块
- environ：环境变量字典
- sep：路径分隔符
- walk：目录遍历函数
- makedirs：创建目录函数
```

### 示例2：转到定义
用户在函数调用上右键选择“转到定义”：
光标位置：result = calculate_sum(a, b)
跳转到：def calculate_sum(x, y): return x + y

### 示例3：悬停信息

光标位置：user_id: int = 123
悬停显示：
```
变量：user_id
类型：int
说明：用户唯一标识符
```

## 与pi agent的集成

要将这些增强功能集成到pi agent中：
1. 集成LSP客户端库（如vscode-languageserver-node或类似库）
2. 实现语言服务器管理器（启动、停止、重启服务器）
3. 将LSP请求/响应与编辑器界面集成
4. 添加自动补全触发器和建议显示
5. 实现转到定义、查找引用等导航功能
6. 添加诊断显示和错误标记
7. 实现代码操作菜单和快速修复功能
8. 提供语言特定的配置选项
9. 确保适当的错误处理和后备机制（当语言服务器不可用时）

此技能作为实施这些更改的规范和参考。
