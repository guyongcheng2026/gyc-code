# 增强Bash工具 (bash-enhanced)

## 工具概述
这个技能展示了如何增强pi agent的基本bash工具，增加以下功能：
1. 全面的权限检查系统
2. 命令语义分析以理解意图
3. 破坏性命令警告和确认提示
4. 路径验证和限制
5. 只读验证用于特定模式
6. 依赖安装限制
7. 改进的错误处理和日志记录

## 当前限制（基本bash工具）
pi agent当前的bash工具具有：
- 基本的安全防护（来自gcloud技能）
- 有限的命令验证
- 没有全面的权限系统
- 没有命令语义理解
- 没有针对破坏性命令的特殊处理

## 增强功能

### 1. 细粒度权限系统
实现基于角色的访问控制（RBAC）用于bash命令：
- 命令白名单/黑名单系统
- 按命令类别分组（文件操作、网络、系统等）
- 路径验证和限制（防止路径遍历攻击）
- 环境变量访问控制
- 用户可配置的权限策略

### 2. 命令语义分析
理解命令意图而不仅仅是字符串匹配：
- 区分只读操作和修改操作
- 识别潜在的危险操作（即使命令看起来安全）
- 理解命令上下文（例如，在项目目录中运行的命令 vs 系统范围的命令）
- 提供命令解释和建议

### 3. 安全特性
- **破坏性命令警告**：对于如rm、mv、dd等命令要求额外确认
- **临时目录隔离**：鼓励在临时目录中进行实验
- **依赖安装限制**：在某些模式下限制npm、pip等安装
- **输出清理**：防止敏感信息在命令输出中泄露
- **执行时间限制**：防止长时间运行的命令消耗资源

### 4. 只读和安全模式
- 专门的只读模式用于规划/探索（类似于Claude Code的协调者模式）
- 沙盒环境用于不受信任的代码执行
- 临时目录隔离用于安全实验，自动清理

### 5. 改进的错误处理
- 更详细的错误消息，带有修复建议
- 命令执行前的验证反馈
- 执行后的清理和资源释放
- 详细的日志记录用于审计和故障排除

## 实现方法

这个技能提供了一个如何实现这些增强功能的蓝图。实际的实现需要修改pi agent的核心bash工具。

然而，这个技能可以通过以下方式使用：
1. 作为参考文档，用于了解应该实现什么
2. 作为教学工具，帮助用户理解增强的bash功能
3. 作为原型，这些增强功能可以在此基础上进行构建

## 权限决策框架

每个bash命令都会经过这个决策过程：

1. **命令解析**：识别命令及其参数
2. **意图分析**：确定命令是只读还是修改性质的
3. **路径验证**：检查所有路径是否在允许的范围内
4. **环境检查**：验证所需的环境变量和上下文
5. **危险评估**：评估潜在风险（数据丢失、系统修改等）
6. **权限检查**：根据用户角色和策略检查权限
7. **确认要求**：对于高风险操作要求额外确认
8. **执行和监控**：执行命令并监控资源使用
9. **后处理**：清理资源并记录结果

## 使用示例

### 示例1：安全的文件操作
用户输入：删除文件tmp/test.log

增强bash响应：
```
命令：rm tmp/test.log
风险评估：低风险（临时文件删除）
路径验证：tmp/test.log 在允许的临时目录内
执行中...
文件 tmp/test.log 已成功删除
```

### 示例2：需要确认的危险操作
用户输入：递归删除项目目录中的node_modules

增强bash响应：
```
命令：rm -rf node_modules
风险评估：高风险（可能删除重要的依赖文件）
路径验证：node_modules 在当前项目目录中
意图分析：这是一个修改操作，可能影响项目构建
警告：此命令将永久删除node_modules目录及其所有内容
        这可能会破坏项目的构建和依赖。
        确定要继续吗？(y/n)
```

### 示例3：只读模式操作
在规划模式下，用户输入：列出src目录中的所有TypeScript文件

增强bash响应：
```
命令：find src -name "*.ts"
模式检查：只读模式 - 允许列出操作
路径验证：src目录在允许范围内
执行中...
src/components/User.ts
src/services/api.ts
src/utils/helpers.ts
```

### 示例4：依赖安装限制
用户输入：通过npm安装新依赖

增强bash响应：
```
命令：npm install lodash
模式检查：标准模式 - 允许依赖安装但带有警告
意图分析：这是一个修改操作，将修改package.json和node_modules
建议：考虑使用项目的依赖管理流程而不是直接安装
警告：直接修改依赖可能导致版本冲突和构建问题
确定要继续吗？(y/n)
```

## 与pi agent的集成

要将这些增强功能集成到pi agent中：
1. 修改核心bash工具以实施权限决策框架
2. 添加命令语义分析能力
3. 实施路径验证和限制系统
4. 添加破坏性命令警告和确认提示
5. 实施只读和安全模式
6. 改进错误处理和日志记录

此技能作为实施这些更改的规范和参考。
