# 网络和网络工具 (network-tools)

## 功能概述
这个技能展示了如何增强pi agent的网络能力，通过提供网络工具来提供：
1. WebFetch工具 - 用于从网络获取资源
2. WebSearch工具 - 用于在网络上搜索信息
3. MCP（模型上下文协议）工具 - 用于与外部AI服务和模型通信
4. 其他网络相关工具和功能
5. 与现有架构和工具的集成
6. 安全性和权限考虑

## 当前限制
pi agent目前的网络能力有限：
- 没有内置的网络获取工具
- 没有网络搜索能力
- 没有与外部AI服务的标准通信协议
- 依赖于bash工具进行网络操作（如curl、wget），但缺乏集成和抽象
- 网络操作缺乏错误处理、超时控制和结果处理
- 没有网络操作的缓存机制
- 缺乏网络访问的权限控制和审计

## 增强功能

### 1. WebFetch工具
提供从网络获取资源的能力：
- **HTTP/HTTPS GET请求**：获取网页、API响应、文件等
- **POST/PUT/DELETE等其他HTTP方法**：支持完整的RESTful操作
- **自定义头部**：支持自定义请求头（认证、用户代理等）
- **查询参数支持**：自动处理URL查询参数
- **响应处理**：自动处理不同的内容类型（JSON、XML、文本等）
- **错误处理**：超时、网络错误、HTTP错误状态码等
- **重定向处理**：自动跟随HTTP重定向（可配置）
- **超时控制**：可配置的连接和响应超时
- **缓存支持**：可选的响应缓存以提高重复请求的性能
- **流式处理**：支持大文件的流式下载和处理
- **认证支持**：基本认证、Bearer令牌、API密钥等
- **代理支持**：通过HTTP/HTTPS代理进行请求

### 2. WebSearch工具
提供在网络上搜索信息的能力：
- **多搜索引擎支持**：Google、Bing、DuckDuckGo等（通过API或解析）
- **自定义搜索查询**：支持复杂的搜索语法和操作符
- **结果过滤和排序**：按日期、相关性、域名等过滤和排序结果
- **结果提取**：自动提取标题、摘要、URL等关键信息
- **页面内容获取**：可选地获取搜索结果页面的完整内容
- **去重和噪声过滤**：移除重复结果和低质量结果
- **语言和地区设置**：支持不同的语言和地区偏好
- **安全搜索**：可选的成人内容过滤
- **结果数量控制**：可配置返回的结果数量
- **搜索建议**：提供搜索词自动完成建议

### 3. MCP（模型上下文协议）工具
提供与外部AI服务和模型通信的标准方式：
- **标准化通信**：使用MCP协议与外部AI服务通信
- **多提供商支持**：支持不同的AI服务提供商
- **上下文传递**：在请求中传递相关的上下文信息
- **模型选择**：能够指定使用的特定模型或版本
- **参数配置**：配置温度、最大令牌数等生成参数
- **流式响应**：支持流式接收生成的内容
- **错误处理**：处理API错误、速率限制、服务不可用等
- **认证和授权**：支持API密钥、OAuth等认证方式
- **成本追踪**：可选地追踪和报告API使用成本
- **响应缓存**：可选地缓存相同请求的响应以提高性能
- **批处理操作**：支持批量请求以提高效率

### 4. 其他网络相关工具
提供其他有用的网络功能：
- **网络诊断工具**：ping、traceroute、端口扫描等（受权限限制）
- **下载管理器**：断点续传、多线程下载等
- **网页抓取工具**：结构化地从网页提取数据
- **API客户端生成**：根据OpenAPI/Swagger规范生成客户端代码
- **网络事件监听**：监听特定的网络事件或webhook
- **网络可视化**：展示网络请求和响应的时间线和详情

### 5. 与架构和工具的集成
- 与协调者-工作者模式集成：
  - 网络工具可以用于规划代理获取最新信息和文档
  - 验证代理可以使用网络工具验证外部依赖和API
  - 工作者可以使用网络工具执行需要网络访问的任务
  - 网络操作可以作为任务执行
- 与技能系统集成：
  - 技能可以使用网络工具获取最新的最佳实践和标准
  - 网络工具可以用于下载和更新技能本身
  - MCP工具可以让技能利用外部AI服务增强功能
- 与现有工具集成：
  - WebFetch结果可以馈送到编辑工具中
  - WebSearch结果可以增强搜索和探索能力
  - MCP工具可以增强代理的决策和生成能力
  - 网络工具结果可以用于任务的输入和输出

### 6. 安全性和权限考虑
- **网络访问控制**：集成权限系统以控制网络访问
- **目标白名单/黑名单**：限制可访问的网络端点
- **数据验证和清理**：防止注入攻击和恶意内容
- **文件类型验证**：验证下载文件的安全性
- **递归下载限制**：防止无限递归下载
- **外部内容隔离**：在沙盒中处理外部获取的内容
- **认证信息保护**：安全地存储和传输认证凭据
- **日志和审计**：记录网络访问和操作的详细信息

## 实现方法

这个技能提供了一个如何实现这些增强功能的蓝图。实际的实现需要：
1. 创建WebFetch工具核心组件
2. 创建WebSearch工具核心组件
3. 创建MCP工具核心组件
4. 添加其他网络相关工具和功能
5. 实施网络访问控制和安全特性
6. 与现有架构（协调者-工作者模式）和工具集成
7. 提供用于配置网络行为和选项的界面
8. 确保适当的错误处理和后备机制

然而，这个技能可以通过以下方式使用：
1. 作为参考文档，用于了解应该实现什么
2. 作为教学工具，帮助用户理解网络工具的好处
3. 作为原型，这些增强功能可以在此基础上进行构建

         let result = [];
         for (let i = 0; i < data.length; i++) {
           if (data[i] > 0) {
             result.push(data[i] * 2);
           }
         }
         return result;
       }

参数：
- 温度：0.7
- 最大令牌数：500

响应：
建议：
1. 使用更现代的数组方法：
   const result = data
     .filter(item => item > 0)
     .map(item => item * 2);
   
2. 添加输入验证：
   if (!Array.isArray(data)) {
     throw new TypeError('Expected array');
   }
   
3. 考虑早期返回：
   if (data.length === 0) {

可使用 /network-tools get-mcp-response 查看详细建议
