Performs exact string replacements in files.

Usage:
- You must use your `Read` tool at least once in the conversation before editing. This tool will error if you attempt an edit without reading the file.
- When editing text from Read tool output, preserve the exact indentation (tabs/spaces) AFTER the line number prefix. Prefix format: line number + colon + space (e.g. `1: `). Never include any part of the line number prefix in oldString or newString.
- ALWAYS prefer editing existing files in the codebase. NEVER write new files unless explicitly required. No emojis in files unless the user explicitly requests them.
- The edit FAILS if `oldString` is not found ("oldString not found in content"), or if it appears multiple times ("Found multiple matches for oldString"). For multiple matches, provide more surrounding lines to make it unique, or use `replaceAll: true` to change every instance (useful for renames).
