- Fetches content from a specified URL (takes a URL and optional format; converts the content to the requested format, markdown by default). Use when you need to retrieve and analyze web content.

Usage notes:
  - IMPORTANT: if another tool offers better web fetching, is more targeted to the task, or has fewer restrictions, prefer that tool instead.
  - The URL must be a fully-formed valid URL; HTTP URLs are automatically upgraded to HTTPS. Formats: "markdown" (default), "text", "html".
  - Read-only: does not modify any files. Results may be summarized if the content is very large.
