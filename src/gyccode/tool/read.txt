Read a file or directory from the local filesystem. If the path does not exist, an error is returned.

Usage:
- The filePath parameter should be an absolute path.
- By default, this tool returns up to 2000 lines from the start of the file; the offset parameter (1-indexed) sets the start line — call again with a larger offset to read later sections.
- Use the grep tool to find specific content in large files or files with long lines; use the glob tool to look up filenames by pattern if unsure of the correct path.
- Contents are returned with each line prefixed as `<line>: <content>` (e.g. "1: foo"). Directory entries are one per line without line numbers, trailing `/` for subdirectories.
- Any line longer than 2000 characters is truncated.
- Call in parallel when reading multiple known files; avoid tiny repeated slices — read a larger window instead.
- Can read image files and PDFs and return them as file attachments.
