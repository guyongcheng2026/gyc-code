Schedule a recurring or one-shot prompt using a cron expression.

Usage:
- cron: Standard 5-field cron expression in local time (M H DoM Mon DoW).
  Examples: "*/5 * * * *" = every 5 minutes, "30 14 28 2 *" = Feb 28 at 2:30pm.
- prompt: The prompt to enqueue at each fire time.
- recurring: true (default) = fire on every cron match until deleted. false = fire once then auto-delete.
- durable: true = persist to disk and survive restarts. false (default) = in-memory only, dies when session ends.

The scheduled task enqueues a new user prompt into the session at the scheduled time.
Use recurring=false for one-shot reminders ("remind me at X").
Use durable=true only when the user explicitly asks the task to survive across sessions.
