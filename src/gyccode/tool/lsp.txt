Interact with Language Server Protocol (LSP) servers to get code intelligence features.

Supported operations:
- goToDefinition / findReferences / goToImplementation: symbol definition, references, implementations
- hover: documentation and type info for a symbol
- documentSymbol: all symbols (functions, classes, variables) in a document
- workspaceSymbol: project-wide symbols matching a query string (empty string requests all)
- prepareCallHierarchy / incomingCalls / outgoingCalls: call hierarchy at a position

All operations require:
- filePath: The file to operate on
- line / character: 1-based position, as shown in editors

workspaceSymbol also accepts query; filePath is not sent in the LSP workspace/symbol request — it is used by gyccode to select and start the matching LSP server.

Note: LSP servers must be configured for the file type. If no server is available, an error will be returned.
