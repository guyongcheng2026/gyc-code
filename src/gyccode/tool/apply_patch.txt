Use the `apply_patch` tool to edit files. Your patch language is a stripped‑down, file‑oriented diff format designed to be easy to parse and safe to apply. Envelope:

*** Begin Patch
[ one or more file sections ]
*** End Patch

Each operation MUST start with one of three headers (a header stating your intended action is required):
*** Add File: <path> - create a new file. Every following line is a + line (the initial contents; prefix new lines with `+` even when creating a new file).
*** Delete File: <path> - remove an existing file. Nothing follows.
*** Update File: <path> - patch an existing file in place (optionally with a rename via `*** Move to:`).

Example patch:

```
*** Begin Patch
*** Add File: hello.txt
+Hello world
*** Update File: src/app.py
*** Move to: src/main.py
@@ def greet():
-print("Hi")
+print("Hello, world!")
*** Delete File: obsolete.txt
*** End Patch
```
