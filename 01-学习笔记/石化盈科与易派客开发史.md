## 二、石化盈科与易派客的关系 🔬

- **石化盈科是易派客的开发商/承建方**（TechWeb 2015-12-03 明确记载"电商开发商石化盈科"）
- **2015年与阿里云合作**：报道"今年1月，电商开发商石化盈科与阿里…"——易派客平台技术底座依托**阿里云**
- **架构特征（🔬 阿里云开发者社区文章标题）**：《中国石化易派客：90天，137亿元成交额，背后的架构秘密》——采用**"厚平台、薄应用"模式 + 共享服务中心（中台思想）**
- **成绩**：2015年上线后"90天成交137亿元"（公开报道口径），早于2016.4.18正式商业运营

## 三、易派客开发过程时间线 🔬（基于公开报道梳理）

```
2002.7    石化盈科成立（中石化 × 电讯盈科 合资）
   ↓
2015.1    石化盈科与阿里云合作，基于阿里云构建易派客电商平台
   ↓
2015.4    易派客平台（前身：中国石化电子化采购系统升级）上线试运营
   ↓
2015下半年  90天成交137亿元（验证平台架构成熟度）
   ↓
2016.4.18  易派客正式商业运营（SC2B模式，对外公开）
```

**关键认知**：易派客不是中石化自研，而是**由旗下IT子公司石化盈科开发、技术底座依托阿里云**的工业品电商平台。对比国网ECP由国网自身（国网信通等）主导开发——易派客是"央企 + 合资IT公司 + 互联网云厂商"的**混合开发模式**。

## 五、易派客平台详细开发历程 🔬（一手权威来源）

> **核心来源**：刘依群（石化盈科信息技术有限公司 互联网部副总经理）2016年4月20日云栖大会·深圳峰会《企业级互联网架构专场：如何快速复制阿里巴巴互联网架构》演讲稿（安科网转载自阿里云云栖社区，2016-05-03）。以下均为演讲原文提炼，可信度最高。

### 5.1 项目启动与团队（🔬 演讲原文）

- **2014年12月**：中石化决定与阿里合作开展互联网应用
- **2015年1月4日**：团队正式入驻，组建工业品电商团队（石化盈科 × 阿里 联合）
- **2015年4月1日**：易派客平台正式上线（上线后一年累计成交137.12亿元）
- **2016年4月18日**：中石化正式向社会公开推介平台
- **开发周期**：从团队入驻到上线 **90天**（原计划6个月压缩至3个月）
- **迭代节奏**：基本上 **两周发版一次**

### 5.2 建设总体思路（🔬 演讲原文）

中石化互联网+电商按 **"大平台、大系统、大安全、大运维"** 总体思路，建设统一电子商务及客户关系管理平台，做到四点：
1. **统一平台**：建立中石化统一电子商务及客户关系管理平台
2. **标准一致**：数据标准、技术标准、集成标准、安全标准
3. **信息共享**：集团层面客户/供应商/基础数据/大数据共享
4. **专业特色**：各业务板块基于平台进行专业特色应用建设

采用 **"厚平台、薄应用"** 设计理念（消化吸收阿里建设思路）：
- IP 层的非业务组件层形成**一些中心**
- SP 层建立 **20几个中心**
- 在中心之上建立应用

### 5.3 平台模块与架构（🔬 演讲原文 — 含精确数字）

**8个网站应用（共79个模块）**：
| 应用 | 说明 |
|------|------|
| 网站门户 | 平台入口 |
| 电子超市 | 类京东自营式采购 |
| 专业市场 | 行业垂直市场 |
| 易生活 | 生活服务 |
| 供应链金融 | 金融增值 |
| 运营后台 | 管理端 |
| 移动应用 | APP/移动端 |
| 大数据 | 数据分析 |

**6个共享服务中心（中台核心）**：
| 中心 | 职责 |
|------|------|
| 会员中心 | 用户/企业会员 |
| 商品中心 | SKU/类目 |
| 订单中心 | 交易订单 |
| 搜索中心 | 检索 |
| 支付中心 | 交易支付 |
| 集成中心 | 系统集成总线 |

> 所有应用基于这6个共享服务搭建，印证"高可复用性、高稳定性、高可扩展性"的中台价值。

**9个集成系统（内外部）**：
ERP、ES5.0、MDM（主数据）、供应商管理、BM、BCS、银行、第三方支付、第三方物流

> 注：ES5.0/BM/BCS 为中石化内部系统代号（ERP、主数据管理、供应商管理等）。

### 5.4 业务模式与生态（🔬 演讲原文）

- **SC2B 模式**：Supply Chain to Business，贯通企业内外部供应链的供应链电商
- **三个核心能力**：专家采购、行家运营、管家服务
- **供应链金融**（依托电商）：基于交易及信用体系，提供应收/应付/存货类融资；连接银行贷款与保险公司保险
- **对外开放**：外部企业也可通过平台采购
- **其他电商方向**：化工品销售电商、润滑油电商

### 5.5 技术架构范式（🔬 演讲原文）

- **云底座**：阿里云（公有云 + 物理服务器混合），保障可靠性/安全性/可扩展性
- **核心理念**："成功的电商 = 平台 + 电子商务运营经验 + 持续的系统建设经验"
- **架构价值**：统一安全防控、统一硬件/运维/故障管理、统一业务监控和风控预警、统一基础数据
- **大数据**：传统企业套件做促销分析需20+小时，迁至阿里云后 **1小时内**完成

### 5.6 平台运营数据（🔬 演讲披露，2016年4月时点）

| 指标 | 数值 |
|------|------|
| 采购商 | 1180家（含中石化内部；外部已下单215家） |
| 采购商用户 | 13653个 |
| 供应商 | 31120家 |
| 供应商用户 | 32050家 |
| 累计有效订单 | 17473单 |
| 累计总金额 | 137.12亿元 |

## 六、易派客后续演进（🔬 公开报道检索补充）

> 以下为 2016 年演讲后的公开演进节点（来源：网易订阅、东方财富号、腾讯文库等公开报道摘要，2026-07-17 检索）。

### 6.1 一企一面（🔬 网易订阅 2018-11-23）

- **易派客执行董事沈中祥**在 2018年11月23日 会议发表主旨演讲《一企一面，助力升级》
- "一企一面"= 面向大型集团客户的**定制化供应链门户**（将采购/寻源/招标/金融/物流按企业组织架构封装，一个企业一套界面）—— 对应笔记 3.2 章
- 标志易派客从通用平台向**集团客户深度定制**演进

### 6.2 供应链金融实体化（🔬 腾讯文库 / 工商检索）

- 成立 **中石化易派客商业保理有限公司**（供应链金融独立法人实体）
- 金融产品：基于交易及信用体系的**应收/应付/存货类融资**，连接银行信贷 + 保险公司保险
- 技术支撑：大数据分析、电子发票（腾讯文库《主导模式下供应链金融平台分析——以中石化易派客平台为例》）

### 6.3 区块链电子发票（🔬 东方财富号 / 公开报道）

- **百望云携手易派客等12家企业共建产业数字新生态**（区块链电子发票平台）
- 标志易派客财务/税务链路向**区块链化**演进

### 6.4 零信任安全架构（🔬 东方财富号 2025 安全文章）

- 中石化体系后期引入 **"零信任安全接入网关子系统" / "零信任认证中心"**
- 特征：运维操作 100% 审计、内网攻击面减少 70%（央企安全架构演进方向）
