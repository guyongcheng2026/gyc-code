## 一、平台定位与核心价值

> 易派客 Slogan：**"让采购更专业"**

易派客是中国石化集团推出的工业品电商平台，2016 年正式商业化运营，定位为**面向工业企业的供应链综合服务平台**，核心服务对象是能源、化工、制造等行业的 B 端采购商与供应商。

### 平台四大理念（首页"理念愿景"板块）

| 理念 | 内涵 | 量化支撑 |
|------|------|---------|
| **专家采购** | 1.5 万名资深采购专家精选优质资源 | 1.5 万采购专家 |
| **行家招标** | 1 万名资深评标专家，全流程电子化招投标 | 1 万评标专家 |
| **管家服务** | 数百万种商品上线推广，一站式服务 | 数百万商品 |
| **大家共享** | 共享优质资源，多领域价值增值 | 生态共享 |

### 三个"致力于"（发展使命）

- 致力于让**中国石化企业**采购更专业
- 致力于让**工业制造企业**采购更专业
- 致力于让**平台关联企业**采购更专业

## 二、平台业务架构（"易系列"生态）

易派客不是单一商城，而是一套**多子站、全链路**的工业互联网平台。从官网导航与页面实测，业务架构如下：

### 2.1 主站门户（www.epec.com）

纯导航门户，所有业务跳转到子站。提供：
- 业务直通车入口
- 资讯公告（通知公告 / 招投标采购资讯滚动）
- 投诉曝光台（异议投诉 / 处理公告 / 违约曝光 / 监督举报）
- 关于我们（了解易派客 / 联系我们 / 加入我们）

## 三、易派客核心特色机制

### 3.1 易标准（供应商信用与质量体系）

易派客独创的**供应链标准评价体系**，是平台区别于普通电商的核心：
- **法人信用认证**：企业资质、履约信用评分
- **产品质量评价**：基于检测数据的质量分级
- **创新能力评价**：供应商技术研发能力

评价结果形成"易标准指数榜"，直接驱动 MRO 专区供应商排序。

### 3.2 一企一面（供应链管理一站式解决方案）

针对大型集团客户的**定制化供应链门户**，将采购、寻源、招标、金融、物流能力按企业组织架构封装，实现"一个企业一套界面"。

### 3.3 供应链阳光行动

易派客倡导的**透明化采购倡议**（首页导航"综合服务"下），强调采购全流程可追溯、可监督，对应首页"投诉/曝光台"的异议投诉、违约曝光、监督举报机制。

### 3.4 易派客工业云

面向工业企业的**数字化采购基础设施**（SaaS 化供应链管理能力输出），与"数字化采购解决方案""采购供应链管理咨询"并列在"企业数字化解决方案"板块。

## 五、与国网 ECP 的对标分析（重点）

| 维度 | 易派客（中石化） | 国网 ECP（国网商城） |
|------|----------------|---------------------|
| 运营主体 | 中国石化 / 易派客电商公司 | 国网 / 国网电商公司 |
| 平台定位 | 工业品电商 + 供应链综合服务 | 国网统一电子商城（交易前台） |
| MRO 能力 | ✅ 成熟（7 大类目、明码标价、超市式） | 🔶 国网 MRO 专区（mall.epec.com 同源参考） |
| 招标寻源 | ✅ emall 独立招投标平台 | ✅ 与 SG-Mall/ERP 集成 |
| 供应商评价 | ✅ 易标准（信用/质量/创新三维） | 🔶 需对标建设 |
| 金融增值 | ✅ 易保理/易权通/易支付 | 🔶 供应链金融待扩展 |
| 国际化 | ✅ EPEC Global 多语言 | 🔶 暂无 |
| 特色机制 | 一企一面、阳光行动、工业云 | DAP-S 后台管控互补 |

**对 ECP 产品规划的启示**：
1. **MRO 超市化**是成熟路径——长尾 SKU 标准化 + 明码标价 + 自助下单
2. **供应商信用评价体系**（易标准）值得 ECP 引入，强化"信用/质量"双维度排行
3. **"易系列"服务延展**（金融/物流/保险/商旅）展示了采购平台向供应链生态演进的方向
4. **阳光采购**（投诉曝光台 + 监督举报）是央企电商的合规刚需，ECP 应内置类似监督机制
