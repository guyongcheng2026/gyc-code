## 三、核心特色机制（🔬 机制已实测，⏳ 细则待补）

### 3.1 易标准（供应商信用与质量体系）🔬 实测完整

易派客独创的**供应链标准评价体系**（"易派客标准"），是平台区别于普通电商的核心壁垒。体系含**四大子体系**，已实测验证其中两大核心：

#### 3.1.1 法人信用认证 🔬（实测来源：epecStandard?pageName=bzLegalCertification）

- **评价机构**：商业信用中心（独立第三方）
- **评价维度**：基本资质、经营绩效、财务状况、信用记录
- **原则**：独立公正、客观科学
- **等级确定**：大数据支撑 + 现场考察 + 定性定量考评 + 一审/二审/三审/合规审查 → 评级专家委员会确定
- **费用**：首年信用评级 **15400元**；第二/三年跟踪评级各 **1000元**；有效期 **3年**
- **动态性**：持续跟踪，级别随企业经营状况调整；一年后未申请跟踪评级则证书失效
- **门槛**：合法存续企业均可申请（无论规模，从2-3人贸易公司到十几万人生产企业）
- **不可通用**：评价模型融入工业品电商采购管理理念，与其他机构评级不通用
- **应用**：AAA级一般为重要行业龙头/管理规范/技术实力强/财务出色企业

#### 3.1.2 产品质量评价（EQE，EPEC Quality Evaluation）🔬（实测来源：epecStandard?pageName=bzProductEvaluate）

- **定位**：易派客标准体系四大子体系之一，对产品质量依据 EQE 标准分级评价
- **四大评价内容**：
  1. **质量经营能力**：资质等级、装备水平、生产能力、财务状况、经营业绩、售后服务
  2. **质量监管能力**：质保体系、质保人员、过程控制、检验测试能力
  3. **质量发展能力**：研发能力、标准化水平、国际竞争力
  4. **实物质量水平**：产品各项性能指标测试，量化评价
- **招标评分应用（关键）🔬**：在中国石化采购中，完成 EQE 评价 **AAA 得 1.5 分**；每降 1 等级降 0.15 分；**C 级得 0.3 分**；未参与不得分
- **费用**：生产企业 = 现场审查费（3年内只付1次，**2.7万元**）+ 产品检测费；非生产企业仅现场审查费（按石化物料大类 **2.7万/大类**）
- **有效期**：**3年**，第四年重新评价
- **性质**：自愿性评价（非强制）
- **成果**：EQE 证书（标明质量等级+限制范围）+ 详细检测报告（仅生产企业）
- **EQE 联盟**：联合政府机构/权威评价机构/跨国公司/行业协会，实现标准与结果互认
- **与其他认证区别**：普通认证仅判合格/不合格，EQE 在合格基础上进一步分级；多从用户角度考量可靠性/耐久性/环保节能

#### 3.1.3 创新能力评价 + 指数榜 🔬机制

- 创新能力评价：供应商技术研发能力（体系四大子体系之三，细则待补抓）
- 评价结果形成 **"易标准指数榜"**，直接驱动 MRO 专区供应商排序 🔬（实测正星科技 92.19 / 中密控股 91.95 等上榜）

## 八、数据抓取通道现状（2026-07-17 技术探查记录）

- ❌ **Nuxt payload.js**：子页为 CSR 模式，无静态 payload（404）

- **突破条件**：用户提供 epec 账号登录态 token，即可用 curl + sso-token header 直调所有业务 API 抓 JSON（绕过浏览器封锁）
