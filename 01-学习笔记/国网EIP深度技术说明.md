# 国网EIP（电工装备智慧物联平台）深度技术说明

> 本文是五E一中心深化系列第二篇，聚焦EIP的技术架构、数据采集机制、质量管控模式及对远光ECP的启示。
> 元信息：创建时间2026-07-20，🔬实测部分基于公开信息汇总与专利分析

## 一、业务架构深度

### 1.1 EIP定位与核心能力

EIP（Electric Power Equipment Intelligent Platform，电工装备智慧物联平台）是国家电网面向**电工装备制造企业**的统一质量数据接入与协同平台，核心定位为**"质量数据网关"**。

**三大核心能力**：
1. **数据采集**：通过标准化网关，从制造企业生产设备/检测设备/ERP系统自动采集生产质量数据
2. **质量监控**：实时监控产品生产进度、出厂试验结果、原材料质量，实现"出厂即合格"目标
3. **数据协同**：将质量数据同步给ECP（物资采购端）、ESC（供应链运营端），形成从采购→生产→交付→运行的全链条质量闭环

### 1.2 接入企业规模（🔬实测）

| 指标 | 数据 | 时间 | 来源 |
|------|------|------|------|
| 接入企业数 | 1100+家 | 2026年数据（更新早期6000+为包含下属分厂） | 国网公开新闻 |
| 接入产线数 | 2000+条 | 同上 | 同上 |
| 采集数据项 | 2500+项 | 同上 | 同上 |
| 覆盖范围 | 变压器、开关柜、电缆、互感器、保护装置等主要一次/二次设备 | — | 推断 |

### 1.3 业务流程

```
供应商生产ECP订单产品
    ↓（EIP数据采集网关自动采集）
生产进度数据 → EIP实时记录（排产→投料→组装→调试→试验→入库）
质量试验数据 → EIP自动采集（出厂试验报告、型式试验报告）
    ↓（数据同步）
ECP可查看 → 采购方在线核验质量数据，确认产品符合技术条件书要求
ESC可分析 → 供应链运营中心对质量趋势分析、供应商质量画像
    ↓（问题处理）
发现质量异常 → EIP推送预警 → ECP/ESC协同处理（退货/降级使用/限期整改）
```

## 二、技术架构深度

### 2.1 数据采集网关架构（基于专利公开信息）

EIP数据采集网关采用 **"边缘计算+云边协同"** 架构：

```
┌─────────────────────────────┐
│    制造企业现场             │
│  ┌─────────────────────┐   │
│  │  数据采集网关（边缘）  │   │
│  │  - 多协议适配层       │   │
│  │     (OPC UA/Modbus/   │   │
│  │      MQTT/S7/Profinet)│   │
│  │  - 数据预处理          │   │
│  │     (清洗/格式化/缓存) │   │
│  │  - 本地规则引擎        │   │
│  │     (阈值告警/质量控制) │   │
│  │  - 安全加密通道        │   │
│  └────────┬──────────────┘   │
│           │ 4G/5G/WAN        │
└───────────┼──────────────────┘
            ↓
┌─────────────────────────────┐
│  国网云端（国网信通云）      │
│  ┌─────────────────────┐   │
│  │  EIP核心平台         │   │
│  │  - 设备注册与管理     │   │
│  │  - 数据接收与存储     │   │
│  │  - 质量分析服务       │   │
│  │  - 数据开放接口(API)  │   │
│  └─────────────────────┘   │
└─────────────────────────────┘
```

### 2.2 核心技术特点

| 能力 | 实现方式 | 说明 |
|------|---------|------|
| **多协议适配** | 支持OPC UA、Modbus TCP/RTU、IEC 61850、MQTT、Profinet、S7等主流工业协议 | 兼容国内外主流PLC/检测设备 |
| **边缘预处理** | 在网关端完成数据格式化、缓存、基础计算 | 减轻云端压力，适应断网重连 |
| **国密加密** | 数据传输采用SM2/SM4加密，满足等保2.0要求 | 电网安全合规 |
| **断点续传** | 网络中断时数据缓存本地，恢复后自动补传 | 保障数据完整性 |
| **时钟同步** | 通过NTP确保网关与云端时钟一致 | 保障时序数据准确性 |

### 2.3 采集数据类型（推断）

| 数据类别 | 示例字段 | 数据量级 |
|---------|---------|---------|
| **生产进度** | 订单号、物料编码、排产日期、当前工序、计划完工日 | 每条订单约50个节点 |
| **质量试验** | 试验项目、试验值、上限/下限、判定结果、试验时间、试验设备ID | 每台产品约10-200项试验 |
| **原材料** | 原材料批次号、供货商、进场检验结果 | 每批约5-15项 |
| **工艺参数** | 关键工序的温/压/速等工艺参数曲线 | 高频采样（秒级/分级别） |

## 三、应用架构深度

### 3.1 功能模块

| 模块 | 功能 | 用户 |
|------|------|------|
| **设备管理** | 企业注册、设备注册、产线管理、网关管理 | 制造企业管理员 |
| **数据采集** | 实时数据监控、历史数据查询、异常数据标记 | 制造企业质检员 |
| **质量管控** | 质量统计（SPC）、不合格品管理、质量改进闭环 | 双方质量工程师 |
| **协同服务** | 检验数据开放（供ECP调用）、质量报告推送、问题在线协同 | 采购方 |
| **统计分析** | 供应商质量画像、产品批次合格率、行业质量趋势 | 国网物资部 |
| **标准管理** | 技术条件书管理、试验标准模板、判定规则配置 | 标准管理人员 |

### 3.2 用户角色

- **制造企业**：质量数据上传方，对真实性负责
- **采购专责**（使用ECP）：查看供应商质量数据，辅助到货验收决策
- **质检工程师**：深度分析质量数据，发现趋势性/系统性质量问题
- **物资管理**：基于质量统计优化供应商组合

## 四、数据架构深度

### 4.1 核心实体

```
制造企业（Manufacturer）
 ├─ 企业档案（统一代码、资质、生产范围）
 ├─ 设备/产线（设备编号、型号、校准有效期）
 └─ 网关（网关ID、部署位置、联网状态）

订单（ProductionOrder）
 ├─ ECP合同/PO号
 ├─ 产品型号/数量/技术条件书
 └─ 生产节点（时间、操作人、检测结果）

质量试验数据（TestData）
 ├─ 试验项目（耐压/局放/直流电阻/变比...）
 ├─ 试验值/结果
 ├─ 试验设备/时间/人员

原材料批次（MaterialBatch）
 ├─ 批次号/供应商
 ├─ 进场检验结果
 └─ 用于哪个订单/产品
```

### 4.2 与ECP的数据接口

| 接口方向 | 内容 | 协议 | 频率 |
|---------|------|------|------|
| ECP→EIP | 订单信息（物料、数量、技术条件书编号） | HTTP REST/JSON | 订单签署后 |
| EIP→ECP | 生产进度（排产/生产/完工/待检/已检） | HTTP REST/JSON | 状态变更实时 |
| EIP→ECP | 出厂试验报告（试验数据PDF/结构性数据） | HTTP REST/JSON | 试验完成后 |
| ECP→EIP | 到货验收结果（抽检合格/不合格项） | HTTP REST/JSON | 到货验收后 |

数据格式示例（推断）：
```json
{
  "orderNo": "2026-XXXX-001",
  "productCode": "SG-2026-YYYY-ZZZZ",
  "testItems": [
    {"code": "HV003", "name": "工频耐压", "value": "85.2", "unit": "kV", "lower": "80", "upper": "95", "result": "PASS", "testTime": "2026-07-15T09:30:00"}
  ],
  "conclusion": "PASS",
  "testReportUrl": "https://eip.sgcc.com.cn/reports/2026/07/15/abc123.pdf",
  "signatureId": "CA-2026-ABCDEF"
}
```

## 五、对远光ECP的启示

### 5.1 可直接借鉴的能力

1. **质量数据接入**：远光ECP若涉及实物类采购（如电网设备、工程物资），应建立类似EIP的质量数据对接通道
2. **生产进度透明**：供应商产线数据自动同步，采购方不需要再人工"催货"、"催报告"
3. **问题在线协同**：发现质量异常在线协同处理，替代传统的电话/邮件沟通

### 5.2 差异化机会（对远光ECP而言）

1. **中小企业适配**：EIP侧重大型设备制造企业，远光ECP可提供轻量化质量数据采集方案（Web填报+拍照上传+AI质检辅助），降低中小企业接入门槛
2. **与质量认证机构对接**：将第三方检测报告、体系认证状态在线核验，替代人工接收证照
3. **供应商质量画像**：整合多源数据（生产质量+到货验收+运行故障+售后服务），形成全生命周期视角的供应商评价

### 5.3 集成架构建议（如远光ECP要对接EIP）

```
┌─ 远光ECP ──────────────────┐
│  1. 合同签署后→推送PO到EIP   │
│  2. 从EIP拉取生产进度→履约追踪 │
│  3. 从EIP获取试验报告→辅助验收 │
│  4. 验收结果回写EIP→质量闭环   │
└──────────────────────────────┘
┌─ EIP（国网）─────────────────┐
│  生产进度数据                   │
│  出厂试验数据                   │
│  原材料数据                     │
└──────────────────────────────┘
```
