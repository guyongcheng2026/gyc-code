## 二、ECP（电子商务平台）

### 2.1 业务架构（🔬 ECP 2.0公开功能）

```
ECP业务域
├── 招标采购
│   ├── 公开招标：公告发布、投标、开标、评标、定标
│   ├── 邀请招标：供应商筛选、邀请、投标、评审
│   ├── 竞争性谈判：谈判邀请、报价、谈判、成交
│   ├── 询价采购：询价单、报价、比价、下单
│   └── 单一来源：论证、审批、谈判、合同
├── 供应商管理
│   ├── 供应商注册：资质提交、审核、入库
│   ├── 供应商评价：履约评价、绩效评分、等级管理
│   ├── 供应商分级：A/B/C/D分级、差异化策略
│   └── 黑名单管理：违约记录、禁用、解禁
├── 合同管理
│   ├── 电子合同：范本管理、在线签约、变更
│   └── 合同监督：履行跟踪、预警、终止
├── 订单管理
│   ├── 采购订单：生成、审批、跟踪、验收
│   └── 退货管理：质量不合格、退换货流程
└── 采购监督
    ├── 全流程留痕：操作日志、审计追溯
    └── 合规检查：资质合规、流程合规、价格合规
```

### 2.2 应用架构（📋 基于ECP 2.0通用架构推断）

```
应用层
├── 门户层
│   ├── 供应商门户（供应商注册、投标、合同、订单）
│   └── 采购方门户（招标、评标、合同、监督）
├── 业务应用层
│   ├── 招标管理应用
│   ├── 供应商管理应用
│   ├── 合同管理应用
│   ├── 订单管理应用
│   └── 监督审计应用
├── 服务层
│   ├── 工作流引擎：采购流程自动流转
│   ├── 规则引擎：供应商评价规则、合规检查规则
│   └── 消息引擎：通知、提醒、预警
└── 集成层
    ├── 与ERP接口：订单→采购凭证、合同→服务采购单
    ├── 与EIP接口：供应商产品质量数据
    ├── 与ELP接口：物流状态跟踪
    └── 与ESC接口：数据上报
```

### 2.3 数据架构（📋 推断）

```
数据域
├── 采购主数据
│   ├── 物料主数据（物资编码、规格、价格）
│   ├── 供应商主数据（资质、评级、联系人）
│   └── 合同主数据（范本、条款、签署记录）
├── 交易数据
│   ├── 招标数据（公告、标书、投标、评标）
│   ├── 订单数据（采购订单、变更单、验收单）
│   └── 履约数据（交付记录、质量记录、评价记录）
├── 参考数据
│   ├── 采购目录（品类树、价格库）
│   └── 标准条款库（合同范本、评标标准）
└── 审计数据
    ├── 操作日志（全流程留痕）
    └── 合规记录（资质审核、流程合规）
```

## 三、ERP（企业资源管理系统）

### 3.1 业务架构（📋 基于ERP与ECP协同推断）

```
ERP业务域
├── 财务管理
│   ├── 预算管理：采购预算编制、执行、调整
│   ├── 应付管理：供应商发票校验、付款、清账
│   └── 成本核算：项目成本归集、采购成本分析
├── 项目管理
│   ├── 项目立项：投资审批、WBS分解
│   └── 项目执行：进度跟踪、费用控制、竣工验收
├── 资产管理
│   ├── 固定资产：资产卡创建、折旧、盘点
│   └── 物资库存：入库、出库、盘点、调拨
└── 人资协同
    ├── 组织管理：部门架构、岗位
    └── 绩效考核：供应链人员KPI
```

### 3.2 应用架构（📋）

```
┌────────────────────────────────────────┐
│  应用层                                 │
│  FI/CO（财务）· PS（项目）· MM（物资）  │
│  AM（资产）· HR（人资）                 │
├────────────────────────────────────────┤
│  集成层                                 │
│  ← ECP接口（采购订单→采购凭证）         │
│  → ECP接口（预算校验→订单审批）         │
│  → ELP接口（运输成本→财务核算）         │
│  → ESC接口（经营数据→运营分析）         │
└────────────────────────────────────────┘
```

### 3.3 数据架构（📋）

```
数据域
├── 财务数据：预算、凭证、发票、付款、成本
├── 项目数据：立项、WBS、进度、费用、验收
├── 资产数据：资产卡、折旧、变动、盘点
├── 库存数据：入库、出库、库存、调拨
└── 主数据：会计科目、成本中心、利润中心、项目编码
```

### 3.4 技术架构（📋 SAP为核心？）

```
ERP可能基于SAP系统
├── 核心系统：SAP ECC / S/4HANA（📋 blog.csdn.net提及SAP电力行业应用）
├── 用户端：SAP GUI / Fiori Web界面
├── 集成方式：SAP PI/PO（Process Integration）
│   ←→ ECP：RFC/WebService接口
│   ←→ ELP：IDoc/API接口
│   ←→ ESC：ODATA/API接口
└── 部署：国网云 / 私有云
```

> ⚠️ ERP为国网最核心内部系统，技术选型属内部信息🏛️。SAP推断基于CSDN技术博客。

## 四、EIP（电工装备智慧物联平台）

### 4.1 业务架构（🔬 三大核心作用确认）

```
EIP业务域
├── 质量管控（在线质量管控——🔬 题库确认）
│   ├── 生产过程监控：工艺参数实时采集、异常告警
│   ├── 设备质量诊断：出厂试验数据自动分析、合格判定
│   └── 智能故障诊断：综合诊断报告生成、推送（🔬 2025实现）
├── 设备台账管理
│   ├── 设备档案：铭牌参数、生产批次、出厂编号
│   ├── 检修记录：历史检修、缺陷记录、状态评价
│   └── 负荷监控：实时负荷数据、运行状态（🔬 360搜索）
├── 远程监造
│   ├── 生产进度：工序完成进度、交期跟踪
│   └── 远程验收：视频/数据远程见证
└── 供应商协同
    ├── 数据接入：标准化接口配置、数据校验
    └── 问题整改：质量问题的闭环跟踪
```

### 4.2 应用架构（🔬 专利+公开描述推断）

```
┌────────────────────────────────────────────┐
│  EIP应用层                                  │
│  ├── 质量监控中心：质量看板、预警、诊断报告 │
│  ├── 设备管理中心：台账查询、检修计划、状态评价│
│  ├── 远程监造中心：生产进度、视频监控、远程验收│
│  └── 供应商协同中心：接入管理、数据校验、整改跟踪│
├────────────────────────────────────────────┤
│  EIP核心服务层                              │
│  ├── 数据采集服务：EIP对象模型数据采集网关   │
│  │   (🔬 国家电网专利：基于EIP对象模型的     │

│  ├── 数据校验服务：数据标准化、清洗、校验    │
│  ├── 诊断分析服务：质量评判、故障推理        │
│  └── 通知推送服务：预警、报告、整改推送      │
├────────────────────────────────────────────┤
│  集成层                                     │
```

### 4.3 数据架构（🔬 EIP已采集2500+数据项）

```
数据域（🔬 截至2024年，1100+家企业，2000+条产线，2500+数据项）
```

### 4.4 技术架构（🔬 专利+公开描述）

```
┌──────────────────────────────────────────────────┐

│  ├── 数据接入服务：协议转换、数据解析、对象映射   │
│  ├── 数据中台：数据存储(时序库+关系库)、清洗、融合 │

└──────────────────────────────────────────────────┘
```

## 五、ELP（电力物流服务平台）

### 5.1 业务架构（🔬 公开功能确认）

```
ELP业务域
├── 运输管理
│   ├── 运输计划：运输批次生成、承运商分配
│   ├── 运输监控：运输全过程可视化（GPS/北斗）（🔬）
│   ├── 运输路径规划：路线优化、成本最低（🔬）
│   └── 到货管理：到货预报、签收确认、异常处理
├── 物流资源管理
│   ├── 承运商管理：资质审核、评价、考核
│   ├── 车辆管理：车辆档案、调度、维护
│   └── 仓储管理：中转仓库、临时存储、调配
├── 地理信息服务
│   ├── GIS地图服务（🔬）：变电站/供应商/仓库地理位置
│   ├── 选址规划：仓库选址、配送范围优化
│   └── 地理信息共享：跨部门GIS数据共享
└── 物流协同
    ├── 与ECP协同：订单→运输批次
    ├── 与供应商协同：发货通知、物流单号
    └── 与ESC协同：物流状态上报
```

## 九、架构说明

- **标🔬部分**：有公开来源确认（考试题库、专利公告、新闻报道、搜索摘要）
- **标📋部分**：基于公开信息合理推断（参考ERP行业通用模式、ECP通用功能）
- **标🏛️部分**：此系统为国网内部核心系统，架构细节属内部信息
- **ECP前端**：Nuxt.js SPA（🔬），部署于国网云阿里组件环境（🔬 chinapower.com.cn）
- **ECP后端**：微服务框架（Spring Cloud / Dubbo 推断），阿里云ECS/RDS/RocketMQ/Redis
- **EIP数据采集**：1100+企业、2000+产线、2500+数据项（🔬 360搜索摘要）；专利"基于EIP对象模型的数据采集方法及网关"
- **ELP技术架构**：云化中台共融/云边协同共融/营配贯通共融/远近通信共融（🔬 2023论文《基于物联网技术的电力物流服务平台创新与实践》）
- **ESC可视化**：数字孪生、LED大屏（🔬 国网江苏物资智慧运营中心）
- **ESC-AI**：光明大模型覆盖电力生产/建设/管理/运营/科研/供应链六大领域45项应用，中国信通院+电子标准院双权威检测（🔬 北极星电力网2026.2）
- **ERP技术选型**：SAP S/4HANA可能性大（📋 2024年有"GTA ERPSAP S/4HANA实施项目"招标公告线索），但不确定为国网所属
