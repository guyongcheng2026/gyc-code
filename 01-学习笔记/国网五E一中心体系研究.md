## 一、概述

"五E一中心"是国家电网现代智慧供应链的核心平台体系。现代智慧供应链以"五E一中心"供应链平台为载体，以管理体系为支撑，推动生产组织体系变革、内外高效协同，促进供应链智慧运营。

- **定位**：国网现代智慧供应链信息化/数字化骨架
- **目标**：实现从物资采购到交付使用的全生命周期智慧管理
- **范围**：覆盖国家电网经营区域内27个省市和自治区
- **关联**：与光明电力大模型（2024.12发布）形成"AI+平台"双轮驱动

---

## 二、五E一中心组成（🔬 考试题库确认）

| 编号 | 平台 | 全称 | 核心职能 |
|------|------|------|----------|
| 1 | **ECP** | 电子商务平台（Electronic Commerce Platform） | 全流程采购 |
| 2 | **ERP** | 企业资源管理系统（Enterprise Resource Planning） | 业务协同贯通 |
| 3 | **EIP** | 电工装备智慧物联平台（Electrical Equipment Intelligent IoT Platform） | 在线质量管控 |
| 4 | **ELP** | 电力物流服务平台（Electrical Logistics Platform） | 运输统筹监控 |
| 5 | **e物资** | 掌上移动应用 | 移动端应用 |
| — | **ESC/中心** | 供应链运营中心（Supply Chain Operation Center） | 智慧运营决策 |

## 三、历史渊源与发展时间线

### 3.1 萌芽期（2010-2018）

- **2010年8月**：国家电网公司供应商服务中心成立，搭建与供应商有效沟通的平台（🔬 zhidao.baidu.com）
- **约2010年起**：ECP 1.0上线运行，实现基础电子化采购功能
- **2015-2018年**：国网逐步推进采购全流程电子化，ECP 1.0持续升级

### 3.2 体系构建期（2019-2020）

- **2019年1月**：ELP（电力物流服务平台）启动建设（🔬 hn.people.com.cn）——五E一中心体系化建设的起点
- **2019年7月15日**：ECP 2.0试运行上线（🔬 此前研究确认）
- **2019年**：EIP（电工装备智慧物联平台）推进供应商接入，电工装备制造企业开始接入平台
- **2020年7月底**：ECP 2.0正式单轨运行，标志电子商务平台完成代际升级
- **2020年10月15日**：供应链运营中心（ESC）首次召开智慧运营现场会（🔬 360搜索），标志着ESC从建设转向深度运营
- **2020年**：ELP正式上线运营，提供物流运输可视化、路径规划等服务

### 3.3 成熟运营期（2021-2025）

- **2021年**：五E一中心体系逐步成熟，各平台间数据贯通
- **2023年12月**：国网天津电力加快"绿色现代数智供应链"建设（🔬 360搜索）
- **2024年4月**：现代智慧供应链深化应用，依托五E一中心实现应急物资在线管理
- **2024年12月21日**：五E一中心一体化平台运行，以"ECP全流程采购、ERP业务协同贯通、EIP在线质量管控、ELP运输统筹监控、e物资移动应用、ESC智慧运营决策"为核心（🔬 shuashuati.com题库）
- **2024年12月19日**：光明电力大模型发布（千亿级多模态），赋能五E一中心智能化升级

### 3.4 深化发展期（2025-2026）

- **2025年3月27日**：ELP被确认为五E一中心重要建设成果（🔬 人民网）
- **2025年8月**：EIP平台实现变电站异响自动诊断——自动调取设备台账、历史检修记录、实时负荷数据，生成综合诊断报告（🔬 360搜索摘要）
- **2025年11月**：国网天津电力深化绿色现代数智供应链
- **2026年4月27日**：国网印发《2026年具身智能发展规划》，计划采购具身智能设备约8500台，总投资约68亿元，聚焦电力巡检（🔬 360新闻摘要）
- **2026年5月**：ELP平台在电力物流中持续发挥重要作用（🔬 360搜索）

## 四、各E/中心现状详析

### 4.1 ECP（电子商务平台）🔬

**定位**：五E一中心的"采购入口"，全流程采购的核心引擎。

**历史沿革**：
- ECP 1.0（约2010起）——基于供应商服务中心（2010.8成立）实现基础电子化采购
- ECP 2.0（2019.7试运行→2020.7单轨）——升级为现代智慧供应链采购平台，部署于国网云（阿里组件环境）

**功能模块**（📋 基于ECP2.0通用能力推断）：
| 模块 | 功能 |
|------|------|
| 招标采购 | 公开/邀请/竞争性谈判/询价采购全流程电子化 |
| 供应商管理 | 注册/资质审核/履约评价/黑名单管理 |
| 合同管理 | 电子合同签约、变更、终止全生命周期 |
| 订单管理 | 采购订单生成、审批、跟踪、验收 |
| 履约评价 | 供应商交货/质量/服务综合评价 |
| 采购监督 | 全流程留痕、审计追溯、合规检查 |

**与远光ECP的关系**：
- 国网ECP（五E一中心）≠ 远光ECP（国网商城）
- 前者为国网内部物资采购平台，面向国网供应商
- 后者为国网商城电子商城平台，面向B端企业客户
- 两系统存在数据交互——国网商城MRO商品标准库需与国网ECP物资编码体系对接

### 4.2 ERP（企业资源管理系统）📋

**定位**：五E一中心的"业务协同贯通"层，连接采购与财务/项目/资产。

**技术形态**：
- 国网ERP体系可能基于SAP系统（🔬 blog.csdn.net提及SAP在电力行业应用，"利用统一的集成式ERP管理系统，实现所有部门和职能的互联"）
- 但无法确认具体版本/模块——公开信息有限

**与ECP的协同**：
- ECP采购订单 → ERP生成采购凭证 → 财务预算校验 → 项目成本归集
- ECP合同 → ERP创建服务采购订单 → 供应商发票校验 → 付款
- 形成"采购→财务→项目"端到端数据闭环

**公开透明度**：ERP为国网最核心的内部系统之一，技术选型、部署规模、运维状态均属内部信息🏛️，无公开披露

### 4.3 EIP（电工装备智慧物联平台）🔬

**定位**：五E一中心的"生产质量前哨"——在线质量管控。

**技术架构**（📋 基于公开描述推断）：
```
供应商生产设备 → 数据采集终端 → 标准化接口(兼容IE/Modbus等)
    ↓
EIP统一数据交互中枢 → 数据校验/清洗/分发
    ↓
国网端应用：质量诊断/设备台账/生产进度/远程监造
```

**三大核心作用**（🔬 360搜索摘要）：
1. **打破信息孤岛，实现数据实时互联**——通过标准化接口兼容多协议（IE、Modbus等），打通供应商生产端到国网采购端的数据链路
2. **设备台账与生产进度实时掌控**——供应商接入EIP后，国网可实时获取设备生产进度、工艺参数、试验数据
3. **智能质量诊断**——2025年已实现变电站异响自动诊断：平台自动调取设备台账、历史检修记录、实时负荷数据，生成综合诊断报告，推送至调度/检修/营销等部门，故障处理平均用时大幅缩短

**供应商接入**：
- 鲁变电工等首批接入（🔬 360搜索摘要），2024-2025年加速推广
- 统一采集供应商侧业务数据和生产试验数据，统一保存、校验、分发
- 外部服务商（湖南鲸易信息科技等）提供EIP接入技术服务

**与ECP的联动**：
- ECP采购订单 → EIP获取对应供应商生产进度 → ECP根据EIP质量数据进行履约评价

### 4.4 ELP（电力物流服务平台）🔬

**定位**：五E一中心的"物流大动脉"——运输统筹监控。

**建设时间线**：
- 2019年1月：启动建设（🔬 人民网）
- 2020年：正式上线运营
- 2022年12月：已在省级公司落地——国网庆阳供电公司应用ELP进行物流运输抽检监控，保障变压器、水泥杆等重点物资运输安全（🔬 360搜索：finance.gscn.com.cn）
- 2025年3月：被确认为五E一中心重要建设成果
- 2026年5月：持续发挥作用

**功能模块**（🔬 360搜索摘要）：
| 功能 | 说明 |
|------|------|
| 物流运输可视化 | 运输全过程实时监控，支持GPS/北斗定位 |
| 运输路径规划 | 优化运输路线，降低物流成本 |
| 运输批次整合 | 多批次自动合并，提高运输效率 |
| 地理信息共享 | GIS地图服务，支撑选址/配送规划 |

**服务对象**：面向国网公司内外部用户——内部单位物流需求 + 供应商配送协同

**应用案例**（🔬 360搜索：finance.gscn.com.cn）：
- 国网庆阳供电公司2022年底已应用ELP平台
- 涉及物资：变压器、水泥杆等电力物资
- 应用场景：物流运输抽检监控，"从物资物流运输的源头把关"
- 效果：全链条质量追溯，运输过程风险管控

### 4.5 e物资（掌上移动应用）📋

**定位**：五E一中心的"移动入口"——移动端物资管理应用。

**功能**：
- 融合掌上电力、国网商城等线上业务
- 覆盖电费查询、业务变更、理财等功能
- 物资信息查询、订单跟踪、验收确认

**覆盖范围**：国家电网经营区域内27个省市和自治区

**与移动端的关系**：
- 非独立APP，融合于"掌上电力"或"网上国网"超级APP中
- 作为物资管理的移动端模块，与ECP/ERP联动

### 4.6 ESC（供应链运营中心）🔬

**定位**：五E一中心的"指挥室"——智慧运营决策。

**建设时间线**：
- 2020年10月15日：首次召开"供应链运营中心ESC智慧运营现场会"，贯彻国网公司建设具有中国特色国际领先的能源互联网企业战略（🔬 360搜索摘要）
- 2024年：被描述为"（ESC）智慧运营决策"核心，五E一中心一体化运行正式形成

**核心能力**（📋 基于公开描述推断）：
| 能力层 | 功能 |
|--------|------|
| 数据汇集 | 汇聚ECP/ERP/EIP/ELP/e物资五E全链路数据 |
| 可视化监控 | 供应链全链路可视化看板，物资/物流/质量一屏统览 |
| 风险预警 | 供应商违约预警、物流延迟预警、库存阈值预警 |
| 运营决策 | 数据驱动的采购计划/库存策略/供应商优化决策 |
| 应急调度 | 应急物资在线调配、全量资源统筹调度 |

**与光明大模型的结合**：ESC是光明大模型在供应链场景的核心落地场景——大模型赋能风险预警、决策分析和应急调度

## 五、核心机制：五E协同闭环（📋 基于公开描述推断）

```
采购端 ──→ 生产端 ──→ 物流端 ──→ 应用端 ──→ 决策端
 ECP        EIP        ELP       e物资      ESC/ERP
全流程采购  在线质量   运输统筹   移动应用    智慧运营
           管控       监控                 决策
```

- **ECP** 发起采购，生成订单
- **EIP** 监控供应商生产过程质量
- **ELP** 统筹运输配送，可视化追踪
- **e物资** 提供移动端应用入口
- **ERP** 实现财务/项目协同
- **ESC** 全局监控与决策支持

## 六、下一步发展计划

### 6.1 绿色现代数智供应链深化 📋

国网天津电力已明确提出"绿色现代数智供应链"建设方向，预计五E一中心将从"信息化"向"数智化"升级：
- 绿色化：供应链碳排放全过程可追溯
- 数智化：大数据+AI深度融合各E平台
- 智能化：光明大模型赋能ECP评审、EIP质量诊断、ELP路径优化

### 6.2 光明大模型融入各E平台 🔬

- 光明电力大模型（2024.12发布）六大场景45项应用正在各E平台落地
- 智能评审系统：对标ECP招标采购
- 物资编码智能化：对标e物资
- 综合诊断报告：已在EIP实现

### 6.3 具身智能投入 🔬

《2026年具身智能发展规划》：
- 采购各类具身智能设备约8500台
- 总投资约68亿元
- 聚焦电力巡检等场景
- 与ELP物流/供应链运营中心联动

### 6.4 应急物资管理智能化 📋

- 依托五E一中心实现应急物资需求在线实施
- 全量资源统筹调配
- 为应急物资保障提供技术支撑
- 已写入现代智慧供应链深化应用方案

## 七、与ECP（远光）的对照分析

| 维度 | 国网五E一中心 | 远光ECP（国网商城） |
