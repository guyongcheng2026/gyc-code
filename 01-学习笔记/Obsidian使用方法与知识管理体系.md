## 一、Obsidian 核心概念

### 1.1 仓库（Vault）
一个文件夹即一个知识库。所有笔记都是纯文本 `.md` 文件，可以随时用任何编辑器打开，**永不锁定**。

### 1.2 笔记即文件
每篇笔记 = 一个 Markdown 文件。这意味着：
- 可以用 Git 做版本管理
- 可以全文搜索（比任何数据库都快）
- 跨平台、跨工具迁移零成本

### 1.3 双向链接 `[[ ]]`
Obsidian 最核心的创新——用 `[[笔记名]]` 创建链接，点击即跳转，且自动生成反向链接面板。

### 1.4 图谱视图（Graph View）
`Ctrl+G` 打开。每个节点是一篇笔记，每条连线是一个 `[[双向链接]]`。可以：
- 一眼发现**核心枢纽节点**（被最多笔记引用的）
- 找到**孤立节点**（没有被任何笔记链接的）→ 需要补充关联
- 按颜色分组（按标签/文件夹）

## 二、系统性管理工作记录

### 2.1 每日记录（Daily Notes）

每次启动 Obsidian 直接 Ctrl+G（新建每日笔记）。模板：

```markdown
# 2026-07-02 工作记录

## 今日重点
1. 

## 完成事项
- [ ] 待办
- [x] 已完成

## 关键决策
- 

## 关联笔记
- [[]]
```

**配置路径**: `设置 → 核心插件 → 每日笔记`
- 格式: `YYYY-MM-DD`
- 文件夹: `05-工作随记/`
- 模板: `_templates/每日记录模板`

### 2.2 周/月回顾
用「工作随记」文件夹 + 标签 `#review/weekly` 做定期回顾。
方法：每周五花 15 分钟，回顾本周每日记录，提炼可沉淀的知识点写入对应领域文件夹。

### 2.3 会议纪要

```markdown
# 2026-07-02 XXX会议纪要

**参与人**: 
**时间**: 

## 议题
1. 

## 决议
- 

## 待办
- [ ] @责任人 

## 关联
- [[]]
```

## 三、系统性管理学习笔记

### 3.1 三层笔记法（借鉴 Zettelkasten）

| 层级 | 命名 | 内容 | 存放位置 |
|------|------|------|---------|
| **闪念笔记** | `YYYY-MM-DD_HHMM_主题` | 临时捕捉的想法/灵感 | `05-工作随记/` |
| **文献笔记** | `《书名》读书笔记` | 一本书/文章的核心提炼 | `01-学习笔记/` |
| **永久笔记** | `概念名` | 一个概念/原理的完整理解 | `01-学习笔记/` |

**流程**: 闪念 → 整理为文献/永久笔记 → 建立链接

### 3.2 输入流程

```
接收信息 → 写入知识库: <内容>
              ↓
       Hermes 提取核心观点
       → 结构化 Markdown
       → 添加 [[双向链接]]
       → 分类存入对应目录
              ↓
       Obsidian 图谱视图
       → 查看关联
       → 手动补充思考
```

### 3.3 渐进式总结（Progressive Summarization）

| 层级 | 方法 | 视觉标记 |
|------|------|---------|
| L1 | 原文摘录 | 普通文本 |
| L2 | **粗体**标注重点 | **加粗** |
| L3 | ==高亮==最核心的金句 | ==高亮== |
| L4 | 用自己的话写摘要 | 写在开头 |
| L5 | 关联到其他笔记 | [[双向链接]] |

## 四、知识体系组织原则

### 4.1 文件夹结构（当前配置）

```
E:\谷勇成的知识库\
├── 00-索引/          首页、导航、规则
├── 01-学习笔记/      书籍/课程/概念笔记
├── 02-ECP-产品规划/  工作项目知识
├── 03-项目管理/      方法论
├── 04-技术栈/        技术学习

├── 06-模板/          笔记模板
├── 99-归档/          旧笔记
├── _assets/          图片/附件
└── _templates/       Obsidian 模板
```

### 4.2 标签体系

| 标签 | 用途 |
|------|------|
| `#待整理` | 闪念/临时笔记，需进一步处理 |
| `#review/weekly` | 待周回顾 |
| `#参考` | 外部资料引用 |
| `#ECP` | ECP 项目相关 |
| `#管理/项目` | 项目管理类 |
| `#技术/后端` | 后端技术 |
| `#技术/前端` | 前端技术 |

### 4.3 PARA 方法适配

社区流行的 **PARA** 方法（Project / Area / Resource / Archive）：

| PARA | 知识库映射 |
|------|-----------|
| **P**roject（项目） | `02-ECP-产品规划/` |
| **A**rea（领域） | `04-技术栈/`、`03-项目管理/` |
| **R**esource（资源） | `01-学习笔记/` |
| **A**rchive（归档） | `99-归档/` |

## 六、进阶建议（后续可探索）

1. **安装社区插件**：通过 `设置 → 社区插件 → 浏览`，推荐：
   - Dataview — 用 SQL 查询笔记，自动生成统计看板
   - Calendar — 日历视图，管理每日笔记
   - Kanban — 看板视图，管理待办
   - Excalidraw — 手绘图表
   - Git — 自动版本管理

2. **Git 版本管理**：知识库目录可以 `git init` 做版本管理，配合 Gitee 私仓做云端备份

3. **模板自动插入**：新建笔记时用 `Ctrl+P` → `模板: 插入模板`，快速套用预设格式
