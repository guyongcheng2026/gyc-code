# 国网ECP2.0深度技术说明

> 本文是五E一中心深化系列的第一篇，聚焦ECP（电子商务平台，即新一代电子商务平台ECP2.0）的业务流程细节、技术实现细节、接口规范及对远光ECP的启示。
> 元信息：创建时间2026-07-20，来源自公开信息汇总与业务知识推断，🔬实测部分已标注

## 一、业务架构深度

### 1.1 采购全流程体系

ECP支持六大采购方式，按适用范围与流程复杂度排列：

#### 1.1.1 公开招标（最常用）
- **适用**：依法必须招标项目、达到规定金额标准的物资/服务采购
- **流程**：招标公告发布（≥20日）→ 供应商投标（使用投标工具U+，离线编制→加密上传）→ 开标（在线解密）→ 评标（专家库随机抽取，电子评标系统辅助）→ 定标 → 中标公告 → 合同签署
- **关键节点**：投标截止后系统自动截标，CA数字证书加密，开标时在线同步解密
- **EPC选型参考**：此流程是ECP最核心业务流程，远光ECP可参考其投标工具U+的离线+在线混合模式、CA证书加密策略

#### 1.1.2 竞争性谈判
- **适用**：技术复杂、紧急采购、供应商较少的情况
- **流程**：发布谈判公告 → 供应商提交初步响应文件 → 谈判小组评审 → 多轮谈判（价格谈判、技术澄清） → 最终报价 → 确定成交候选人
- **特点**：灵活性强，可多轮，通常3-5个工作日完成

#### 1.1.3 询价采购
- **适用**：标准规格、金额较小的物资
- **流程**：发布询价单 → 供应商在线报价 → 比价 → 确定成交
- **特点**：流程最短，可全流程在线完成

#### 1.1.4 单一来源采购
- **适用**：专利/专有技术、紧急抢修、原采购追加
- **流程**：论证单一来源理由 → 公示 → 谈判 → 签约
- **特点**：无需竞争性流程，但需严格审批

#### 1.1.5 竞价采购
- **适用**：价格竞争为主的通用物资（如办公用品、MRO类）
- **流程**：发布竞价公告 → 供应商报名 → 在线竞价（多轮反向拍卖） → 确定成交
- **特点**：全流程在线，适合电商式采购场景

#### 1.1.6 框架协议采购（协议库存）
- **适用**：需求频繁但单次不确定的物资（如标准设备、备品备件）
- **流程**：征集框架协议供应商 → 签订框架协议（含最高限价、交付条款） → 需求发生时下单/竞价 → 执行订单
- **特点**：中标供应商池可运营，分批下单减重复采购流程

### 1.2 供应商管理全流程

| 阶段 | 操作 | 说明 |
|------|------|------|
| **注册** | 供应商通过ECP门户提交注册信息（营业执照、资质证照、业绩材料） | 需CA证书认证 |
| **资质审核** | EC专员在线审核 → 退回补正/通过 | 通常3-5个工作日 |
| **产品资质报备** | 提交产品型式试验报告、3C认证、生产许可证等 | 与EIP质量溯源关联 |
| **绩效评价** | 按合同履约情况打分（交付准时率、质量合格率、服务水平） | 季度/年度评价，影响后续投标评分 |
| **分级管理** | AAA/AA/A/B/C五级，分级影响投标保证金比例、履约保证金比例 | 优质供应商享优惠政策 |
| **黑名单** | 严重违约/造假列入黑名单，全平台禁入 | 跨省联通 |

### 1.3 合同管理全流程

- **起草**：基于中标/成交结果自动生成合同草案（标准模板），可在线协商条款
- **审批**：ECP内多级审批流（经办→部门负责人→法务→分管领导），支持移动审批
- **签署**：CA电子签章，双方在线签署，签署后自动归档
- **执行跟踪**：到货计划→发货通知→到货验收→质量确认→付款申请
- **变更**：合同变更单在线提交、审批，变更历史可追溯
- **终止**：违约终止/协商终止，终止后自动触发清算流程

### 1.4 履约与验收

- **到货验收**：供应商发货后在ECP登记物流信息，仓库/项目现场到货后扫码确认
- **质量确认**：与EIP对接，生产环节质量数据自动同步，与到货抽检结果对照
- **结算支付**：验收合格后供应商提交发票（电子发票自动查验），财务确认后发起付款

## 二、应用架构深度

### 2.1 功能模块划分

| 一级模块 | 二级模块 | 用户群体 |
|---------|---------|---------|
| 采购管理 | 采购计划、采购方案、采购实施、结果管理 | 采购专责/主管 |
| 供应商管理 | 注册审核、资质管理、绩效评价、分级管理、黑名单 | 供应商/采购专责 |
| 合同管理 | 合同起草、合同签署、合同执行、合同变更、合同终止 | 合同专责/法务 |
| 专家管理 | 专家入库、抽取、评价、培训 | 专家管理专员 |
| 评标管理 | 评标室管理、在线评标、专家画像、评标报告 | 评标专家 |
| 监督监控 | 廉政风险预警、围标串标识别、采购全流程监控 | 监督/审计 |
| 统计分析 | 采购数据驾驶舱、供应商画像、价格趋势 | 管理层 |

### 2.2 供应商端工具

- **投标工具U+**（桌面客户端）：离线编制投标文件、加密上传、开标解密
- **供应商门户**（Web端）：日常业务办理（注册、资质维护、合同确认、发票提交、消息查看）
- **移动端**：招标消息推送、中标通知查看、简单业务确认（批注中功能）

### 2.3 企业端（采购方）工具

- **采购管理后台**（Web端）：全流程操作
- **评标系统**（Web/桌面）：独立子系统，与ECP主站数据隔离
- **移动审批**：合同审批、付款审批（集成i国网/钉钉）

## 三、数据架构深度

### 3.1 核心数据实体

```
供应商（Supplier）
 ├─ 基本信息（名称、统一代码、法人、注册资金、经营范围）
 ├─ 资质证照（营业执照、体系认证、生产许可证、特种证照）
 ├─ 业绩记录（近年项目清单、合同额、用户评价）
 └─ 绩效评分（交付/质量/服务/价格/hse 五维评分）

采购项目（ProcurementProject）
 ├─ 采购方案（方式、预算、分包方案、评审办法）
 ├─ 公告/文件（招标/谈判/询价文件）
 └─ 结果（中标/成交候选人、中标通知书）

合同（Contract）
 ├─ 主体条款（合同主体、标的、数量、金额、期限）
 ├─ 执行节点（到货、验收、付款、质保）
 └─ 关联单据（发货通知、验收单、发票）

物料主数据（MaterialMaster）
 ├─ 物料编码（23位ID + 短描述）
 ├─ 技术参数（规格型号、技术条件书）
 ├─ 分类属性（物资大类/中类/小类，参照国网物资分类标准）
```

### 3.2 关键数据流

```
采购计划 → 采购方案 → 采购公告 → 投标响应 → 开标 → 评标/谈判 → 定标
    ↓（ECP内部闭环） 
中标通知书 → 合同签署 → 订单/发货 → 到货验收 → 结算支付
    ↓（跨系统）                ↓（与EIP交互）
与ERP同步合同/PO           质量数据同步校验
与EIP同步履约进度          到货抽检结果比对
与ELP同步物流状态
```

### 3.3 数据治理要点

- **物料主数据**：国网物资分类标准（23大类、489中类、3387小类），MDM（主数据管理平台）统一维护
- **供应商主数据**：统一社会信用代码为唯一标识，跨省库共享
- **价格库**：按物料+区域+时间维度存储成交价，为后续采购提供参考价区间

## 四、技术架构深度

### 4.1 整体技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **前端** | Nuxt.js（SSR）+ Element UI | 服务端渲染，兼顾SEO与SPA体验 |
| **供应商端工具** | C#/.NET WinForms（投标工具U+） | 桌面客户端，支持离线编标 |
| **API网关** | Kong / 自研网关 | 统一认证、限流、日志 |
| **微服务框架** | Spring Cloud Alibaba | 服务注册/发现Nacos、配置中心Nacos、熔断Sentinel |
| **容器编排** | Docker + Kubernetes（国网云） | 部署在国网信通云平台，多可用区 |
| **数据库** | MySQL（Percona）分库分表 + Redis集群 + MongoDB | 事务数据MySQL，缓存Redis，档案类MongoDB |
| **消息队列** | RocketMQ | 异步解耦，库存同步/通知发送 |
| **搜索引擎** | Elasticsearch | 全文检索（招标公告、供应商信息） |
| **文件存储** | 阿里云OSS / 国网统一存储 | 投标文件、资质证照 |
| **安全** | CA数字证书（国密SM2/SM3）、SSL传输加密、审计日志、负载均衡WAF | 全链路安全 |
| **监控** | Prometheus + Grafana + ELK | 性能监控、日志分析 |

### 4.2 微服务架构（典型划分）

```
ecp-gateway             API网关（认证、路由、限流）
ecp-auth-service        认证授权服务（OAuth2 + SM2证书）
ecp-user-service        用户/组织管理服务
ecp-supplier-service    供应商管理服务
ecp-project-service     采购项目管理服务
ecp-bid-service         投标/开标服务
ecp-eval-service        评标管理服务
ecp-contract-service    合同管理服务
ecp-order-service       订单/履约服务
ecp-payment-service     结算支付服务
ecp-notify-service      消息通知服务（短信/邮件/站内信）
ecp-report-service      报表/统计服务
ecp-expert-service      专家管理服务
ecp-supervise-service   监督监控服务（预警/围串标识别）
ecp-file-service        文件存储服务（上传/预览/安全检测）
ecp-integration-service 集成服务（与ERP/EIP/ELP/ESC对接）
```

### 4.3 安全体系

- **身份认证**：CA数字证书+用户名密码双因素（供应商）；手机验证码+密码（内部用户）
- **权限控制**：RBAC角色权限模型，按模版分配（如采购专责、供应商代表、评标专家）
- **数据安全**：供应商间数据隔离（不可见对方投标信息）、合同内容加密存储
- **审计日志**：全操作留痕，关键操作（开标、定标、合同签署）需双人确认
- **合规**：满足《电子招标投标办法》、《网络安全等级保护2.0》等

## 五、与其他中心的集成

### 5.1 ECP ↔ ERP

| 集成场景 | 方向 | 交互内容 | 触发时机 |
|---------|------|---------|---------|
| 合同同步 | ECP→ERP | 采购订单（PO）创建、变更、关闭 | 合同签署后 |
| 到货确认 | ERP→ECP | 到货数量、验收结果 | 仓库收货确认后 |
| 发票校验 | ERP→ECP | 发票校验结果、付款状态 | 财务处理发票后 |
| 物料主数据 | MDM→ECP | 物料编码、分类、技术参数 | 物料新增/变更时 |

### 5.2 ECP ↔ EIP

| 集成场景 | 方向 | 交互内容 | 价值 |
|---------|------|---------|------|
| 生产进度 | EIP→ECP | 订单生产状态（排产中/生产中/完工待检） | 合同履约透明化 |
| 质量数据 | EIP→ECP | 出厂试验报告、型式试验数据 | 到货验收可在线核验 |
| 供应商评估 | ECP→EIP | 履约评价结果共享 | 全生命周期的供应商画像 |

### 5.3 ECP ↔ ELP

| 集成场景 | 方向 | 交互内容 | 价值 |
|---------|------|---------|------|
| 发货通知 | ECP→ELP | 发货清单、到货地址、预计到货时间 | ELP调度运输资源 |
| 物流状态 | ELP→ECP | 在途位置、预计到达、签收确认 | 采购方实时掌握物流 |

### 5.4 ECP ↔ ESC

| 集成场景 | 方向 | 交互内容 | 价值 |
|---------|------|---------|------|
| 采购执行数据 | ECP→ESC | 采购交易额、履约进度、供应商绩效 | ESC运营监控大屏 |
| 风险预警 | ESC→ECP | 供应商异常（经营异常、失信被执行）、价格异常 | ECP可触发预警流程 |

## 六、对远光ECP的启示

### 6.1 借鉴点

1. **投标工具U+模式**：远光ECP可考虑提供离线+在线混合的投标客户端，适应网络不稳定场景
2. **框架协议采购**：ECP支持的先签框架后下单模式，适用于电力行业高频复购物资
3. **CA证书全链路**：从注册到合同签署全程CA认证，确保法律效力
4. **全流程监控**：采购全过程可追溯、可审计，适合央企合规要求
5. **与EIP质量联动**：生产质量数据直接用于到货验收，减少人工核验环节

### 6.2 差异化机会

1. **轻量化投标工具**：相比ECP的桌面客户端，远光ECP可提供Web版投标工具，降低部署门槛
2. **移动端优先**：ECP的移动端较弱，远光ECP可强化移动审批、移动投标
3. **AI辅助评标**：ECP尚未大规模使用AI，远光ECP可引入智能评标（资质自动对比、围串标识别）
4. **电商式采购体验**：对MRO类物资提供类似京东的企业采购体验（搜索→加购→下单→审批→配送跟踪）
5. **供应商自服务门户**：提供更好的供应商自助服务体验（一键式资质维护、智能客服）
