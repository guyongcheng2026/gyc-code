# SKU（Stock Keeping Unit）概念

## 什么是 SKU？
SKU 是 **库存保管单元**（Stock Keeping Unit）的缩写，用于唯一标识一种具体商品的最小可售单元。它不仅区分商品的 **品牌、型号、规格、颜色、包装方式**，还能直接关联库存、价格、促销等业务属性。

## SKU 的组成与编码规范
- **长度**：≤ 64 字符，避免出现空格或特殊符号。
- **结构**：常采用 `类目-品牌-规格-属性` 的层级编码，例如 `ECP-000123-CPU-3.2GHz-8C` 表示国网商城的 **CPU 8核 3.2GHz** 规格商品。
- **唯一性**：在库表上应设置 **唯一约束**（PK 或唯一索引），防止重复。

## SKU 的核心作用
| 功能 | 说明 |
|------|------|
| **库存管理** | 精确统计每种规格的在库、在途、在售数量。 |
| **订单匹配** | 订单中记录 SKU，后端直接定位商品信息（价格、属性、图片）。 |
| **价格/促销** | 不同 SKU 可拥有独立的价格、折扣、促销标签。 |
| **数据分析** | 以 SKU 为粒度进行 **销量、毛利、转化率** 等统计分析。 |

## 最佳实践
1. **统一前缀**：业务维度（类目、品牌、属性）在编码中保持固定顺序，便于解析。
2. **避免冲突**：使用业务层唯一的 **SKU 生成服务**，在写入数据库前先检查唯一性。
3. **文档化**：在知识库中维护 SKU 编码规则文档，供研发、运营、供应商统一参考。
