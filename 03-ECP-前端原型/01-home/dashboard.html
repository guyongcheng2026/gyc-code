业务场景
平台运营方需要实时掌握电子商城核心运营指标，本页面实时展示采购总额、订单数、供应商数、商品数、已支付金额、执行中合同、预算执行率、供应商均分、准时交付率、验收合格率、待处理预警、招标项目数等12项核心KPI，月度趋势、采购方式占比，以及供应商TOP10、实时预警、部门/品类采购统计、订单状态分布、合同执行、预算执行、供应商评价排名、招标项目定标、物流配送跟踪等10个维度的运营数据。本页面是B2B运营支撑体系的数据看板。适用于运营经理、分管副总掌握运营全局。
业务价值
  • 12项核心KPI一屏掌握（采购总额/订单数/供应商数/商品数/已支付金额/执行中合同/预算执行率/供应商均分/准时交付率/验收合格率/待处理预警/招标项目数）
  • 月度趋势可视化，运营变化一目了然
  • 采购方式占比分析，支撑采购策略优化
  • 采购节约率分析，量化各采购方式的降本成效
  • 10个维度运营数据页签切换（供应商TOP10/实时预警/部门采购/品类采购/订单状态/合同执行/预算执行/供应商评价/招标项目/物流配送）
  • 实时预警（合同异常/预算超支/资质到期/物流超时），问题早发现
  • KPI卡片和列表行支持下钻，点击即可跳转对应查询页或单据页
详细操作步骤
  1. 查看KPI：页面顶部展示采购总额、订单数、供应商数、商品数、已支付金额、执行中合同、预算执行率、供应商均分、准时交付率、验收合格率、待处理预警、招标项目数等12项核心KPI卡片
  2. 查看趋势：月度趋势图表展示采购金额的变化趋势
  3. 查看占比：采购方式占比展示公开招标/邀请招标/竞争性谈判等占比
  4. 查看节约率：采购节约率分析展示各采购方式的降本成效
  5. 查看TOP10：供应商采购额TOP10排名，识别核心供应商
  6. 查看预警：实时预警页签展示合同异常、预算超支、资质到期、物流超时等预警信息
  7. 查看统计：部门/品类采购统计表格展示各部门、各品类的采购金额
  8. 查看订单状态：订单状态分布页签展示各状态订单数量及金额占比
  9. 查看合同执行：合同执行情况页签展示各合同的执行进度和完成率
  10. 查看预算执行：预算执行情况页签展示各部门预算使用和预警情况
  11. 查看供应商评价：供应商评价排名页签展示供应商分级和评分
  12. 查看招标项目：招标项目定标页签展示各项目的中标结果
  13. 查看物流配送：物流配送跟踪页签展示各发货单的物流状态
  14. 下钻明细：点击KPI卡片或列表行，跳转至对应查询页/单据页查看明细
指标计算公式
  1. 采购总额 = ∑（各采购订单含税金额）
  2. 订单总数 = COUNT（状态≠已取消的采购订单）
  3. 入驻供应商 = COUNT（状态=有效的供应商档案）
  4. 在售商品数 = COUNT（上架状态=在售的商品SKU）
  5. 已支付金额 = ∑（付款状态=已付款的付款单金额）
  6. 执行中合同 = COUNT（合同状态=执行中且未到期）
  7. 预算执行率 = 已使用金额 ÷ 预算总额 × 100%
  8. 供应商均分 = ∑（供应商综合评分） ÷ 供应商评价总次数
  9. 准时交付率 = 实际签收日期 ≤ 约定交货日的订单数 ÷ 已签收订单总数 × 100%
  10. 验收合格率 = 验收结论=合格的次数 ÷ 验收总次数 × 100%
  11. 待处理预警 = COUNT（预警状态=待处理 或 处理中）
  12. 招标项目数 = COUNT（本年度招标项目，状态≠已废标）
  13. 采购节约率 =（预估金额 − 实际成交金额） ÷ 预估金额 × 100%
下钻说明

本看板支持从宏观指标到明细数据的穿透查询。点击KPI卡片、列表行或占比项，即可跳转至对应查询页或单据页。

一、KPI卡片下钻（点击卡片跳转）

  • 采购总额 → 订单列表（order_list.html）— 查看构成采购总额的订单明细
  • 订单总数 → 订单列表（order_list.html）— 查看全部订单及状态
  • 入驻供应商 → 供应商列表（supplier_list.html）— 查看供应商档案
  • 在售商品数 → 商品列表（product_list.html）— 查看在售商品详情
  • 已支付金额 → 付款列表（payment_list.html）— 查看付款记录
  • 执行中合同 → 合同列表（contract_list.html）— 查看执行中合同
  • 预算执行率 → 暂无独立页面（预算管控分散在各业务模块）
  • 供应商均分 → 供应商评价列表（evaluation_list.html）— 查看评价明细
  • 准时交付率 → 发货列表（shipment_list.html）— 查看物流交付情况
  • 验收合格率 → 采购入库页（purchase_storage.html）— 查看验收记录
  • 待处理预警 → 暂无独立页面（预警分散在各业务模块）
  • 招标项目数 → 招标项目列表（bid_project_list.html）— 查看项目详情

二、采购方式占比 / 采购节约率下钻（点击名称跳转）

  • 采购方式名称 → 招标项目列表（bid_project_list.html）— 查看该采购方式的项目
  • 节约率方法名 → 中标结果列表（bid_result_list.html）— 查看定标节约情况

三、列表行下钻（点击表格行跳转）

  • 供应商采购额TOP10 → 供应商列表（supplier_list.html）
  • 实时预警 → 应急采购页（emergency_purchase.html）
  • 各部门采购统计 → 订单列表（order_list.html）
  • 品类采购统计 → 商品列表（product_list.html）
  • 订单状态分布 → 订单列表（order_list.html）
  • 合同执行情况 → 合同单据（contract_bill.html）
  • 预算执行情况 → 订单列表（order_list.html）
  • 供应商评价排名 → 评价列表（evaluation_list.html）
  • 招标项目定标 → 中标结果列表（bid_result_list.html）
  • 物流配送跟踪 → 发货单据（shipment_bill.html）
