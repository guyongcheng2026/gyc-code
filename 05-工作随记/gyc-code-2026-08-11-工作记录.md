## 一、现象

- gyc TUI 运行时底部 Braille spinner 与中文状态文本不断闪烁乱码（conhost 用 936/GBK 解码 UTF-8 字节流）
- 保存 API key（如 alibaba）后，provider 列表仍不可用 / 模型不可选（provider.list 只有 env 命中的 13 个）

## 二、排查结论

- 乱码根因：`SetConsoleOutputCP(65001)` 已存在但旧 dist 未重建生效；输入代码页仍为 936，中文输入/粘贴也会乱码
- provider 不可用根因（架构脱节）：`Auth.set` 只写 `auth.json`，而 `catalog.available()` 基于 `integration.connections`（SQLite `credential` 表）判定 → 两边数据源不一致，credential 表 0 行

## 三、修复（commit `81b5226`）

1. `src/tui/terminal-win32.ts`：`SetConsoleOutputCP` + `SetConsoleInputCP` 同时切换 UTF-8（65001）
2. `src/gyccode/auth/index.ts`：`Auth.set/remove` 同步写/删 SQLite `credential` 表（type="api" → Credential.Key），node 依赖追加 `Credential.node`
3. `src/gyccode/provider/provider.ts`：已认证 provider（auth.json 有凭据）不受 `enabled_providers` 过滤限制，`disabled_providers` 仍硬排除
