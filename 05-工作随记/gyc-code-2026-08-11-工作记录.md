## 七、内存与存储深度分析（2026-08-11 傍晚）

### 内存 473MB 分析（实测）
- bun 空进程基线 rss ≈ 49MB；`gyc debug v2`（完整 provider 全量加载 + catalog 构建）进程峰值 ≈ 30MB → **provider 目录不是内存大头**
- models.json 缓存 3.46MB（183 providers / 6253 models），解析常驻 ≈ 19MB
- 结论：473MB 主要来自 TUI 渲染栈（opentui/Solid）+ JSC 堆预分配 + 实时事件流，属 Windows bun TUI 正常水平
- 已有机制：`--smol` 低内存模式、TUI 会话数据上限（20 session / 100 message）、tool-output 7 天自动清理、日志轮转
- 优化空间有限：渲染引擎与 JSC 堆为固有成本，不建议高风险改动
