# gyc-code 2026-08-18 工作记录

> 主题：gyc TUI 发送提示词失败根因修复（actor 工具未接线致工具列表含 undefined）

---

## 一、现象（谷总反馈）
- gyc GUI（TUI）会话界面发送消息后，总是提示「发送提示词失败」，无法继续使用。

## 二、排查与根因
1. 报错文本定位：`src/tui/component/prompt/index.tsx` L1162「发送提示词失败」toast，来自 `sdk.client.session.prompt` 请求失败。
2. 运行日志（`~/.local/share/gyccode/log/gyccode.log`）抓到真凶：
   - `ERROR TypeError: Cannot read properties of undefined (reading 'id')`
   - 堆栈：`ToolRegistry.tools → Array.filter → SessionTools.resolve → SessionPrompt.run`
3. 根因：`src/gyccode/tool/registry.ts` 的 builtin 工具数组引用了 `tool.actor`，但 `Effect.all` 初始化列表遗漏 `actor` 键（`actor` 工具由最近提交 5500147「compose 模式完整能力」引入，接线时漏了初始化），导致 `builtin` 数组含 `undefined`，`ToolRegistry.tools` 的 filter 读 `tool.id` 即崩溃，所有 prompt/command 提交必失败。

## 三、修复
- `src/gyccode/tool/registry.ts` 三处补齐（与 swarm 同模式）：
  1. `import { ActorTool } from "./actor"`
  2. `const actor = yield* ActorTool`
  3. `actor: Tool.init(actor)` 加入 `Effect.all`
- 重建 dist（谷总实际运行 `node dist` 产物）。

## 四、验证
- `bun test src/gyccode/tool/actor.test.ts`：19 pass / 0 fail
- `bun src/gyccode/index.ts debug agent build`：正常输出 tools，含 `"actor": true`，无 TypeError
- `node dist/index.js debug agent build`（重构后 dist）：同样通过
