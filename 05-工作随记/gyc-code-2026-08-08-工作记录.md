## 六、429 retry-after 导致 run 挂死 13 小时修复 + 目录对齐 Claude Code（commit `ec47d6b`）
### 现象
- `gyc run` 无 key 模型必 429，进程 150s+ 不退出（"大计划执行一半退出"根因）
- 日志显示 `stream error` 后无 `exiting loop`、无 `disposing instance`
### 根因（双重）
1. `retry.ts` 的 `delay()` 无条件遵循响应头 `retry-after`，且 `RETRY_MAX_DELAY` 原为 24.8 天。opencode 免费模型 429 返回 `retry-after: 46666`（≈13 小时）→ `Effect.retry` sleep 13 小时
2. 放弃重试路径 `Effect.gen` 内 `return Cause.done(...)` 是成功值而非调度停止信号（effect 4 beta Schedule 报 `Invalid Input: undefined`）
### 修复
- `RETRY_ABANDON_AFTER_MS = 5min`：retry-after 超限视为非瞬时限流，放弃重试直接报错
- `RETRY_MAX_DELAY_WITH_HEADERS = 60s` 硬上限；`Cause.done` 移到 step 函数同步返回；`MAX_RETRY_ATTEMPTS = 5` 兜底
- 验证：429 场景 8.2s 退出，错误清晰显示 `Rate limit exceeded. Please try again later.`
### 目录对齐
- 新增 9 个顶层门面文件（main/context/history/commands/Tool/Task/QueryEngine/tools/setup）+ `src/STRUCTURE.md` 能力映射（37 行）
- 附带省 token 措施落地：token 估算/tool 路径 relativize/聚合预算/skills 精简/压缩熔断等
