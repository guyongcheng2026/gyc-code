| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | TUI 空白屏 | `@opentui/core-win32-x64` 未在直接依赖中 | `package.json` 加入 `@opentui/core-win32-x64@0.4.5` + `build.mjs` 增加 tui worker 入口 |

| 6 | 品牌合规 | TUI/CLI 界面残留 opencode 字眼 | 终端标题 `GycCode`（app.tsx 4 处）；删除「Open docs」菜单（原打开 opencode.ai/docs）；tips / providers / github 帮助文案移除 opencode；升级链接显示「Go to the official website」（跳转保留）；opencode provider 显示名改 `GYCCODE` |
