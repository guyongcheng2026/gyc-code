## 四、前端原型资源去重（P2）

### 4.1 现状

`03-ECP-前端原型/` 下 11 个子目录，每个都包含独立的 `css/` 和 `js/`：

```bash
01-home/css/
01-home/js/
02-procurement/css/
02-procurement/js/
...
```

每个子目录下的 `element-ui.css`、`vue.min.js`、`echarts.min.js` 等是相同的文件。

### 4.2 优化方案

```
03-ECP-前端原型/
├── css/              ← 公共CSS（一级目录）
├── js/               ← 公共JS（一级目录）
├── 01-home/
│   └── index.html    ← 引用 ../css/ 和 ../js/
├── 02-procurement/
│   └── index.html    ← 引用 ../css/ 和 ../js/
...
```

**收益**：减少约 2MB 冗余存储 + 更新前端框架版本时只需改一处。

**前提**：所有 HTML 里 `./css/` 改为 `../css/`，涉及 100+ 页面。此项改动量较大，建议按需分批进行。
