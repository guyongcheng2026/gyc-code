## 一、现象（谷总反馈）
- http://127.0.0.1:4096/ 启动后页面空白

## 二、排查与根因
1. 首页 HTML 正常返回（200），但 `/assets/index-*.js`、`.css` 请求返回的是 index.html（Content-Type: text/html，395 字节）
2. 服务进程 `node dist/index.js web`（PID 6772），dist 构建于 08-19 08:57
3. 根因：`scripts/build-webapp.mjs` 生成的 `src/gyccode/server/generated/opencode-web-ui.gen.ts` 清单在 dist 构建时嵌入旧 hash（index-CeEt578Z.js / index-CbiSdrM7.css），而 src/webapp/dist 在 08-19 16:53 重新构建后入口 hash 已变（index-BVSD271u.js / index-CTVbJ6kK.css）；`serveEmbeddedUIEffect`（shared/ui.ts）按清单 key 匹配，找不到资源时回退 index.html → JS/CSS 加载失败 → 空白页

## 三、修复
- `bun run build` 重建 webapp + 重新生成 opencode-web-ui.gen.ts（97 个文件）并重新打包 dist
- 重启 gyc web（node dist/index.js web）
