# CodeBuddy 任务栏图标空白修复指南

## 问题原因
Windows 任务栏图标缓存损坏，导致 CodeBuddy（YgsoftAIStudio）图标显示为空白。

## 解决方案（按优先级排序）

### 方案一：重建图标缓存（推荐，无需重启）

1. **关闭 CodeBuddy**（如果正在运行）

2. **以管理员身份运行 CMD**，执行以下命令：

```cmd
taskkill /f /im explorer.exe
cd /d %userprofile%\AppData\Local
del IconCache.db /a
start explorer.exe
```

3. **重新启动 CodeBuddy**

---

### 方案二：清理任务栏快捷方式缓存

1. **取消任务栏固定的 CodeBuddy 图标**（右键 → 从任务栏取消固定）

2. **删除快捷方式缓存**：
   - 按 `Win + R`，输入：`shell:User Pinned\TaskBar`
   - 删除 CodeBuddy/YgsoftAIStudio 相关的快捷方式

3. **重新固定到任务栏**：
   - 找到 `E:\Program Files (x86)\YgsoftAiStudio\YgsoftAIStudio.exe`
   - 右键 → 固定到任务栏

---

### 方案三：重建所有图标缓存（彻底方案）

1. **以管理员身份运行 CMD**，执行：

```cmd
taskkill /f /im explorer.exe
cd /d %userprofile%\AppData\Local\Microsoft\Windows\Explorer
del iconcache* /a
del thumbcache* /a
start explorer.exe
```

2. **重启电脑**（可选，但建议）

---

### 方案四：检查快捷方式目标

如果以上方法无效，检查快捷方式属性：

1. 右键任务栏 CodeBuddy 图标 → 右键「YgsoftAIStudio」→ 属性
2. 确认「目标」路径为：`E:\Program Files (x86)\YgsoftAiStudio\YgsoftAIStudio.exe`
3. 确认「图标」位置正确

---

## 预防措施

- 避免频繁强制关闭 CodeBuddy
- 定期清理系统临时文件
- 如果问题反复出现，考虑重新安装 CodeBuddy

---

## 技术说明

CodeBuddy 安装路径：`E:\Program Files (x86)\YgsoftAiStudio\`
主程序：`YgsoftAIStudio.exe`
图标资源：`resources\app\resources\win32\code_150x150.png`（远光软件 logo）

图标文件本身完好，问题出在 Windows 系统图标缓存层面。
