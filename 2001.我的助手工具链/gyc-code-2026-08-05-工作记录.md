# gyc-code 工作记录 2026-08-05

## 任务：gyc-cli 编程能力评估 + P0 测试修复

### 背景
用「编程Agent能力评估指标体系」评估 gyc-cli（C:\Users\谷勇成\gyc-cli），发现 4 fail / 2 errors 需修复。

### 发现的问题（3 个）
1. **benchmark.test.ts 3 个 spawn 测试超时**：Bun.spawn 启动 CLI 需 8-11s（冷启动加载 1056 文件），超过 bun:test 默认 5s 超时 → 误报失败
2. **jsxDEV 报错**：裸 `bun test` 不带 preload，solid 转换未生效（正确命令 `bun run test` 带 `--preload ./scripts/bun-solid-preload.ts`）
3. **goal.test.ts 第 1 行拼写错误**：`mport` 少了个 `i`，导致整个文件解析失败（Expected ";" but found "{"）

### 修复
- benchmark.test.ts：01/02/03 三个 spawn 测试加 `{ timeout: 30000 }`
- goal.test.ts：`mport` → `import`，顺带修正 CRLF

### 验证
- 修复前：46 pass / 4 fail / 2 errors（50 tests）
- 修复后：**79 pass / 0 fail / 0 errors**（72→79 tests，jsxDEV 中断的测试也恢复了）

### 关键经验
- CLI 冷启动 8-11s 是**正常行为**（非性能 bug），测试需按实际耗时设置超时
- 跑测试必须用 `bun run test`（package.json 脚本带 preload），裸 `bun test` 会缺 solid 转换插件
- CLI 类 spawn 测试默认给 30s 超时是安全值

### 评估结论更新
- 可靠性 6.5 → 8（测试全绿）
- 综合分 8.0 → **8.3**（反超 opencode 8.0，仅次于 Claude Code 8.7）
